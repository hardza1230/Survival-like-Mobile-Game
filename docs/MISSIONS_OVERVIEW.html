ภารกิจหลัก Combat Situations

v8.3.23: ใช้ทุกด่าน Story (C1–C3) แทน Fill the Meter / Survive the Swarm · เล่นซ้ำด่านที่ผ่านแล้วยังใช้ระบบ Replay เดิม

ขั้นตอนทั่วไปของทุก Situation คงไว้

  1. ก่อนเข้าด่าน การ์ดพรีวิวบอกชื่อ Situation ของแต่ละเวฟ
  2. เริ่มเวฟ: ป้ายชื่อ + คำใบ้วิธีเล่นขึ้นด้านบน
  3. ศัตรูมาตามรูปแบบ (pattern) ของ Situation
  4. ทำเป้าโบนัสสำเร็จ (ล้มทั้งกลุ่มทันเวลา / ล้มหัวหน้า / ไม่โดนพื้นอันตราย) = ได้ EXP ก้อน
  5. พลาดเป้า = ไม่มีโทษ เล่นต่อได้ตามปกติ
รูปแบบขั้นตอนเป้าสถานะ
Ambush1) ศัตรูโผล่จากอุโมงค์รอบตัว 2) ล้อมเป็นวง 3) ฝ่าออกด้านหนึ่งแล้วไล่ล้มpackคงไว้
Fortress1) แนวโล่ตั้งด้านหน้า 2) ตัวยิงอยู่ด้านหลัง 3) อ้อมไปตีจากข้าง/หลังpackคงไว้
Barrage1) ตัวยิงยืนไกล 2) ระดมยิงเป็นชุด 3) เข้าประชิดตีระหว่างช่วงพักpackคงไว้
Stampede1) ฝูงตั้งแถว 2) วิ่งชนเป็นแนว 3) Dash ผ่านช่องว่างแล้วตีหลังpackคงไว้
Pincer1) มาสองฝั่งพร้อมกัน 2) อย่าติดตรงกลาง 3) ฝ่าออกด้านหนึ่งpackคงไว้
Commander1) หัวหน้าเกิดพร้อมลูกน้อง 2) ลูกน้องเร็วขึ้นเมื่ออยู่ใกล้หัวหน้า 3) ล้มหัวหน้าก่อนleaderคงไว้
Hazard Shift1) พื้นอันตรายไหลผ่าน 2) เดินหลบตลอด 3) ไม่โดนจนจบdodgeคงไว้
Hunter Pack1) นักล่าเร็ววิ่งไล่ 2) หันกลับไปสู้ อย่าวิ่งตรงpackคงไว้
Last Stand1) คลื่นใหญ่ 2) อยู่ขอบฝูง ตีจากด้านนอกpackคงไว้
Root Lure (จาก Lure the Crown Root)1) รากราชันมุดตาม 2) ยืนข้างหินสมอ 3) หลบตอนเตือน ให้มันพุ่งชนหิน 4) ทุบหินครบ = มันอ่อนแรงleaderของใหม่

แบบใหม่ใน C2–C3 · ทำแล้ว v8.3.23 · C2 เปิด Spore Bloom / Splitters / Elite Duo · C3 เปิด Sniper Nest / Shield Carrier / Shrinking Arena

แบบที่เสนอขั้นตอนเหมาะกับ
Spore Bloom1) ศัตรูตายแล้วทิ้งดอกเห็ด 2) ดอกพองแล้วระเบิดใน 2 วิ 3) ดึงฝูงไปตายห่างตัวC2 Mycelium Marsh
Splitters1) ตัวใหญ่ตายแล้วแตกเป็นตัวเล็ก 2 ตัว 2) ตัวเล็กเร็ว 3) ใช้ท่าวงกว้างเก็บC2 Nectar Hive
Sniper Nest1) ตัวยิงซ่อนหลังกำแพงหนาม 2) เส้นเล็งแดงก่อนยิง 3) อ้อมกำแพงไปเก็บC3 Glass Greenhouse
Shield Carrier1) ตัวถือโล่ให้เกราะทุกตัวในวง 2) ล้มตัวถือโล่ = เกราะหายC3 Seed Vault
Elite Duo1) Elite 2 ตัว 2) อยู่ใกล้กัน = บัฟกัน 3) แยกแล้วล้มทีละตัวC2/C3 เวฟก่อนบอส
Shrinking Arena1) ขอบสนามค่อย ๆ หด (พื้นพิษ) 2) ล้มฝูงก่อนพื้นที่เหลือน้อยC3 ด่านท้าย

ภารกิจรอง วัตถุในแมพ

กติการ่วม: วัตถุอยู่ในแมพทั้งด่าน · เดินไปเหยียบ = เริ่ม · ทำได้ทีละอัน · ทำต่อข้ามเวฟได้ · ไม่ทำก็ไม่มีโทษ

🎯 Hunt the Threat ≈ Rogue Exile / Bounty ย้าย → ภารกิจรอง

  1. Elite ที่มีเป้า 🎯 เกิดในแมพ
  2. เข้าใกล้ = มันกระพริบหนีไปไกลและวางกับดักไว้ที่เดิม
  3. ไล่ตามไปตีจนล้ม
  4. สำเร็จ = ได้ Gear 1 ชิ้น
แผน: จากภารกิจทั่วไปประจำเวฟ เปลี่ยนเป็นวัตถุภารกิจรองในแมพ

🕳️ Hunger Crack ≈ Abyss ย้าย → ภารกิจรอง

  1. แตะรอยแยกเรืองแสง
  2. รอยแยกวิ่งไปหลุมถัดไป ทิ้งรอยไว้
  3. แต่ละหลุมระเบิดเป็นมอน + ของ
  4. เคลียร์หลุมสุดท้าย = จบ ได้รางวัลใหญ่
แผน: เปลี่ยนเป็นภารกิจรอง

🫧 Clear the Fog ≈ Delirium ย้าย → ภารกิจรอง + ปรับ

  1. (ตอนนี้) เก็บฟองอากาศดี
  2. หมอกพิษปกคลุม เดินในหมอกเสียเลือด
  3. ไปช่วยเพื่อนที่ติดในหมอก
  4. ช่วยครบ = จบ
แผน: 1) ตัวเปิดภารกิจ = Wisp สีดำ 2) แตะแล้วมี animation Wisp บินมาที่หน้าจอ → จอมืด → หมอกลง 3) เพิ่ม Monster เงา (ย้ายมาจาก Mirror Path) เป็นศัตรูประจำภารกิจนี้

🌱 Creeping Roots ≈ Blight ย้าย → ภารกิจรอง + ปรับ

  1. รากหลายแบบ (เร็ว/หนา/แตกตัว) คลานไปหาดอก nectar
  2. ไปยืนบนแม่รากเพื่อตัดเส้นทาง
  3. กันไม่ให้รากถึงดอกจนหมดเวลา
แผน: 1) ตัวเปิด = ดอกไม้เหี่ยว ดูน่ากลัว 2) Animation รากค่อย ๆ งอกออกมา ช่วงยาวขึ้น 3) Monster ที่ออกมาถึกเป็นพิเศษ

🌳 Shake the Hollow Trees ≈ Strongbox ปรับ

  1. (ตอนนี้) ยืนในวงใต้ต้นไม้จนต้นสั่น
  2. สุ่มได้ ผลไม้ / รังผึ้ง / ต้นทอง / ต้นไม้ปลอม
แผน: เอาวงออก · ผู้เล่นเดินชน/แตะต้นไม้ → ต้นสั่น → มอนออกมา บางครั้งทยอยออก บางครั้งโผล่ออกมาทีเดียว

📯✦♨❄🗿 ภารกิจรอง C1 (แบบย่อของ League) คงไว้ (รอตัดสินเรื่องความยาว)

  1. เดินไปเหยียบวัตถุ
  2. ศัตรูที่มีจุดสีเกิดรอบวัตถุ 3–4 ตัว (Grandma’s Pot = ยืนในวง 7 วิ)
  3. มีเวลา 20 วิ
  4. สำเร็จ = Sugar 22–30

ภารกิจเฉพาะด่าน

🕯️ Escort the Wisp ≈ Escort ย้าย → ภารกิจเฉพาะด่าน

  1. Wisp ลอยไปทีละแกนต้องสาป
  2. ต้องอยู่ใกล้ Wisp ไว้
  3. ตัวแดงพุ่งไล่ล่า Wisp ต้องดักล้มก่อน
  4. ถึงแกนสุดท้าย = สำเร็จ
แผน: ไม่อยู่ในสำรับทั่วไปแล้ว ผูกกับด่านเดียว (รอเลือกด่าน)

🗝️ Vault Altar ≈ Ultimatum ฉบับย่อ ปรับ

  1. (ตอนนี้) 2 รอบ แต่ละรอบเลือกคำสาป
  2. สู้ผ่านรอบนั้นภายใต้คำสาป
  3. จบรอบ เลือกรับของ หรือเสี่ยงต่อ
แผน: เป็น popup ให้ผู้เล่นกดเลือกคำสาปเอง · ระหว่างเลือก เวลาในด่านหยุด + VFX แบบ Ultimatum (วงพิธี/จอมืดรอบ ๆ)

🍲 Grandma’s Pot ≈ Ritual ปรับ

  1. ก้าวเข้าวงหม้อเพื่อเริ่มพิธี
  2. โมจิหิวเกิดในแสง ล้มทีละคอร์ส
  3. จบคอร์ส ได้ "รส" สะสม
  4. ใช้รสซื้ออาหาร/รางวัลที่โต๊ะคุณยาย
แผน: วงใหญ่กว่าเดิม · ในวงมีพายุฝุ่น/ควัน หรือปรากฏการณ์ธรรมชาติ (เช่น ลมหมุน ฝนผลไม้)

League ภารกิจใหญ่

🗿 Grandma’s Golem ≈ Metamorph ออกแบบใหม่

  1. (ตอนนี้) ศัตรูถือรสหล่นชิ้นส่วนโกเลม (✨ ชิ้นทองแรงกว่า)
  2. เดินไปเก็บ แล้วนำไปอบที่เตา (ขั้นต่ำ 2–3 ชิ้น)
  3. โกเลมเกิด ได้สกิลตามชิ้น: Cake Head ยิงแยม · Pretzel Arms ทุบพื้น · Baguette Legs พุ่งเร็ว · Lollipop Tail เรียกลูกน้อง · Jelly Heart ฮีล
  4. ล้มโกเลม = รางวัล (ชิ้นเยอะ = ยากขึ้น รางวัลดีขึ้น)
แผนใหม่ (แบบ Metamorph เต็ม):
  1. ชิ้นส่วนดรอปจาก Monster / Miniboss / Boss · ระดับต่างกันตามแหล่ง
  2. ชิ้นส่วนเป็นของตกพื้น ไม่ดูดเข้าตัว เหมือน EXP ต้องเดินไปเก็บเอง
  3. เดินเข้าหม้อ → popup ใส่วัตถุดิบที่เก็บมา
  4. สูตรที่ผสมกำหนด Monster ที่จะออกมา (หลายแบบ)
  5. สกิลของ Golem มาจากสกิลของบอสหลายตัวผสมกัน ตามชิ้นที่ใส่

🧊 Frozen Pantry ≈ Legion คงไว้

  1. เดินไปเปิดโหลน้ำตาล (ปุ่ม Open the Jar)
  2. กองทัพโมจิแช่แข็งผุดขึ้น เวลานับถอยหลัง
  3. เดินผ่านตัวไหน = ทาสีให้ตื่น ลังแช่แข็งทาสีแล้วจะแตกเป็นของ
  4. ล้ม 👑 Captain ก่อน (ลูกหมู่อ่อนลง)
  5. หมดเวลา: ทุกตัวแตกพร้อมกัน ตัวที่ไม่ได้ทาสีหายไป · ล้มได้มาก = รางวัลท้ายดีขึ้น

🖐️ Hunger’s Mouth ≈ Breach คงไว้

  1. แตะมือของ Hunger → เปิด breach เป็นวงขยาย
  2. มอนจาก breach ทะลักออกมา
  3. ฆ่าในวง = วงเปิดนานขึ้น
  4. ข้างในมี splinter และหีบ รอจนวงปิด

📯 Hunger Herald ≈ Harbinger คงไว้

  1. Herald (แตะต้องไม่ได้) ปรากฏ ประตูเปิด
  2. มันยิงพลังใส่มอน → มอนถูกบัฟ
  3. ล้มตัวที่ถูกบัฟ ตัวฮีล ตัวบูสต์ และตัวสิง
  4. ล้มครบ = Herald ถอย ประตูปิด

🏰 Siege of the Hunger ≈ Legion 5-Way คงไว้ (Delve)

  1. ห้องพิเศษใน Delve (ชั้น 3+) ยืนในวง
  2. 5 ประตูเทมอนเข้า
  3. ฆ่าในวง = เติมหม้อ
  4. กัน 💣 sapper และเก็บ 📦 supplies

🪨 Hunger’s Domain ≈ Breach Domain คงไว้ (Delve)

  1. ใช้ Hunger Stone
  2. ทั้งถ้ำถูกดึงเข้า breach รอดคลื่นมอน
  3. สู้ Breachlord

⚖️ Sugar Crown Trial ≈ Ultimatum คงไว้ (Delve)

  1. ห้อง Trial ใน Delve
  2. 4 รอบ คำสาปซ้อนกันทุกรอบ
  3. จบแต่ละรอบ เลือกรับกองรางวัล หรือเสี่ยงต่อ
  4. แพ้ = เสียครึ่ง

Environment Event สภาพแวดล้อมพิเศษ (สุ่ม)

🌦️ Seasonal Harvest ≈ Harvest ปรับ → Environment Event

  1. (ตอนนี้) เก็บกลีบจากมอน → เหยียบศาลเรียกฤดู → เติมครบ 4 ฤดู
แผน: ซับซ้อนเกิน → เปลี่ยนเป็นสภาพแวดล้อมพิเศษที่สุ่มเจอได้ หลังเล่น C2-4 เป็นต้นไป (เช่น ทั้งด่านเป็นฤดูหนึ่ง มีผลกับสนาม)

✨ Golden Wave คงไว้

  1. 5% ต่อเวฟ
  2. เวฟเป็นสีทอง
  3. รางวัลเวฟนั้น ×2

🌀 Seed Rift (เหตุการณ์สุ่ม) ≈ Breach คงไว้

  1. ด่าน 6+ โอกาส 15–35% ในวินาทีที่ 8–20 ของเวฟ
  2. เตือน 1.5 วิ
  3. รอยแยกดูดผู้เล่น 20 วิ ต้องจับตัวขนเมล็ด

บอส ลูกเล่นบอส คงไว้

  1. ด่าน C2–C3 เลือดบอสเหลือ 60% และ 30% = ลูกเล่นเริ่ม 15 วิ
  2. แบบ: 🌱 Root Surge · 🌰 Seed Rain (เหยียบเมล็ดก่อนฟัก 3 วิ) · 🍎 Falling Fruit · 🌑 Frenzy Dark (มอนเร็ว ×1.3) · 🪞 Boss Shadows (เงา 3 ตัว)
  3. รอดจนจบ = Sugar + กล่องรางวัล
