## 1. เสาหลัก 3 ข้อ
| # | เสาหลัก | ผู้เล่นรู้สึกอะไร | วัดยังไง (ตัวเลขจาก Supabase / มือถือเจ้าของ) |
|---|---|---|---|
| 1 | **บิลด์โตจนโหด** (แบบ PoE) | ค่อย ๆ เก่งขึ้นทีละ Chapter · **Chapter 1–3 = โหมดเริ่มต้น** ให้รู้ว่าเกมเล่นยังไง ระบบทำอะไร เนื้อเรื่องเป็นยังไง · **การฟาร์มและ juice ของจริงเริ่มหลังจบเนื้อเรื่อง ใน Endgame (Delve / Temple / Forge) = จุดที่สนุกที่สุด** | Chapter: เล่นจบได้ไม่ติด · % คนที่ไปถึง Endgame · Endgame: ความลึก Delve · จำนวนวันที่กลับมาฟาร์ม |
| 2 | **น่ารักแต่วุ่นวาย** | โมจิน่ารัก ๆ แต่ตีแล้วสะใจ (เลขเด้ง จอสั่น เสียงตุ้บ) | เจ้าของเล่นแล้วยิ้ม · 🐞 "Looks wrong" น้อยลง · FPS ไม่ตก |
| 3 | **เล่นสั้นจบในรอบเดียว** | 1 ด่าน ~8–10 นาที เปิดเล่นตอนว่างได้ จบแล้วได้ของไปอัปตัว | เวลาเฉลี่ยต่อด่าน · คนเลิกกลางด่าน (quit) น้อย · D1 ≥ 35% |

ตัวเลือกสำรอง (ถ้าเจ้าของอยากเปลี่ยนข้อไหน):
- **ทุกด่านมีเรื่องให้ทำ** — ภารกิจประจำด่าน (Creeping Roots, Frozen Pantry …) ทำให้แต่ละด่านไม่ซ้ำ
- **ฮีโร่ 6 ตัว เล่นต่างกันจริง** — Momo / Mint / Cocoa / Taro / Yuzu / Sesame × 3 Build

## 2. ลูปหลัก (1 ประโยค)
> **เดินหลบ → ศัตรูตายเอง → เก็บขนม → เลเวลอัปเลือกการ์ด → บิลด์โหดพอฆ่าบอส → เอารางวัลไปอัปตัว → ด่านถัดไป**

**ผลต่อการทำงาน (จากเสาหลัก 1):** Chapter ต้อง **เนียนและสอนดี** (ไม่ต้องยาก ไม่ต้องลึก) · ความลึก/ความท้าทาย/รางวัลใหญ่อยู่ที่ Endgame · หลัง Closed test งานขัดเกลา Endgame มาก่อนเพิ่มของใหม่

## 3. ชนะ / แพ้
- **ชนะด่าน:** ผ่านเวฟครบ (เวฟภารกิจต้องทำภารกิจให้จบ) แล้วล้มบอส → หน้าสรุป + รางวัล (ดูโฆษณา ×2 Sugar ได้)
- **แพ้:** HP เหลือ 0 → ฟื้นได้ 1 ครั้งด้วยโฆษณา (HP 50%) · ไม่ฟื้น = จบด่าน ได้รางวัลตามที่เก็บ
- **จบเกม (ช่วงแรก):** Chapter 1–3 ครบ 15 ด่าน → เปิด end game (Delve / Temple / Forge) · **กฎเหล็ก: ยิ่งยาก รางวัลยิ่งดี**

## 4. สิ่งที่จะไม่ทำ (cut list · จนกว่าจะเปิด Closed test และมีตัวเลขผู้เล่นจริง)
| ไม่ทำ | เหตุผล |
|---|---|
| **ฟีเจอร์ใหม่ / ด่านใหม่ทุกชนิด** (เจ้าของ 14 พ.ย.) · ใบสั่งอาร์ต/เสียงสำหรับของที่มีแล้วยังเขียนได้ | ขัดเกลาของที่มีให้เนียนก่อน |
| ฮีโร่ใหม่ (เกิน 6 ตัว) · Build ใหม่ | ตัวที่มีอยู่ยังบาลานซ์/เทสไม่ครบ |
| โหมดใหม่ / ระบบ endgame ใหม่ (Mine, Patrol ขั้นต่อไป, League ใหม่) | ผู้เล่นใหม่ไม่เจอในวันแรก (บทเรียน 7) |
| ซื้อด้วยเงินจริง (IAP) · กาชาเงินจริง | กฎ 4: รายได้ = โฆษณา rewarded อย่างเดียว |
| เล่นหลายคน / PvP / แชต | ต้องมีเซิร์ฟเวอร์ · ไม่ใช่เสาหลัก |
| หลายภาษา (นอกจากอังกฤษ) · พากย์เพิ่ม | ขยายเมื่อมีคนเล่นจริงในประเทศนั้น |
| 3D · engine ใหม่ | Phaser 2D พอสำหรับเสาหลักทั้ง 3 ข้อ |
| สกุลเงิน/ทรัพยากรใหม่ | มีเยอะพอแล้ว ผู้เล่นใหม่งงง่าย |
| อาร์ตให้ระบบที่ยังไม่เคยเล่นจริง | บทเรียน 2: ทำของปลอมก่อน |
