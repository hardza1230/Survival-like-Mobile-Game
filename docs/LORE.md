# 🍓 Mochitopia — Story & Encounter Bible

## อัตลักษณ์ตัวละคร — หนึ่งชีวิต สองร่าง

ชาว Mochitopia ไม่ใช่มนุษย์จากโลกอื่น แต่เกิดจาก **Mochi Core** — หัวใจโมจิที่เก็บรสชาติ ความทรงจำ และบุคลิกของเจ้าของเอาไว้ เมื่อ Core ยอมรับความกลัวและความปรารถนาของตนได้ จะปลุก **Awakened Form** ร่างนักสู้คล้ายมนุษย์ที่ขยายตัวตนภายในออกมา

- **Core Form** — ก้อนโมจิเด้งดึ๋ง ใช้ในบ้าน เมือง เนื้อเรื่อง มินิเกม และเป็นมาสคอตคู่หู
- **Awakened Form** — นักสู้แบบคน ใช้ในสนามรบ ภาพเต็มตัว คัตอิน สกิน และตัวละครสะสม
- ทั้งสองร่างคือคนเดียวกัน ไม่ใช่สัตว์เลี้ยงกับเจ้าของ
- ทรงผม เสื้อผ้า อาวุธ และเอฟเฟกต์ของร่าง Awakened ต้องสืบจากรสชาติ ไส้ สี และเนื้อสัมผัสของ Core เสมอ
- เมื่อบาดเจ็บหนัก ร่าง Awakened อาจคืนเป็น Core ชั่วคราว จึงยังใช้ความ “เด้งดึ๋ง” เป็นทั้งมุกและกลไกเกมได้

**โมโม่** คือผู้พิทักษ์คนแรกที่ปลุกร่างสำเร็จ: Mochi Core ไส้สตรอว์เบอร์รีกลายเป็น Strawberry Fighter ผมชมพู ชุดแดง–ขาว และพลังเกล็ดน้ำตาล จึงเป็นสะพานระหว่างภาพจำ Mochi Mayhem เดิมกับทิศทางตัวละครแบบคน

## แก่นของเรื่อง

โลก Mochitopia ไม่ได้กำลัง “เปรี้ยว” โดยบังเอิญ แต่กำลังถูกบางสิ่งกิน **รสชาติ ความทรงจำ และความอยากมีชีวิต** ไปทีละชั้น เชฟขม (The Bitter Chef) สร้างเครื่องจักรคำสาปเพื่อส่งรสชาติทั้งหมดให้เจ้านายที่แท้จริง — **The Great Hunger** ความหิวดึกดำบรรพ์ที่ไม่มีวันอิ่ม

โมโม่ นักสู้สตรอว์เบอร์รี ตกผ่านรอยแยกใต้ตู้กับข้าวและต้องไต่จากโลกใต้ครัวขึ้นสู่ต้นตอ ทุกด่านคือชั้นหนึ่งของเครื่องจักรคำสาป และทุกบอสมีเหตุผลของตนเอง ไม่ใช่เพียงสัตว์ประหลาดที่รอถูกกำจัด

## บทที่ 1 — ทางขึ้นจากใต้ครัว

| ด่าน | พื้นที่ | ปมเรื่อง | บอส |
|---|---|---|---|
| 1 | รังมดเปรี้ยวใต้พื้น | ผลึกกรดบิดเบือนอาณาจักรมด ราชินียอมรับใช้เชฟขมเพื่อรักษาไข่ของตน | จักรพรรดินีมดกรดมรกต |
| 2 | ท่อระบายฟองเน่า | กรดจากรังปลุกกองทัพน้ำเสียและสิ่งมีชีวิตจากเศษท่อ | คลอกมอว์ จ้าวแห่งท่ออุดตัน |
| 3 | ห้องเครื่องพริกเพลิง | เตาหลอมเปลี่ยนกรดเป็นพลังงานคำสาป | มิสเตอร์เตาปิ้ง |
| 4 | คุกเย็นน้ำตาล | วิญญาณรสหวานถูกแช่แข็งไว้เป็นเชื้อเพลิง | โกเลมไอศกรีม |
| 5 | เตาอบราชันขม | โมโม่พบว่าเชฟขมเป็นผู้รับใช้ ไม่ใช่ต้นกำเนิด | The Bitter Chef |

### เส้นเรื่องด่าน 1

1. **รอยแยก** — โมโม่ตกลงในถ้ำโกโก้ใต้ตู้กับข้าว พบทางเดินที่มีผลึกสีเขียวเติบโตสวนแรงโน้มถ่วง
2. **วรรณะบิดเบือน** — มดงานยังคงขนอาหาร, มดสอดแนมล่าเหยื่อ, มดพ่นกรดปกป้องผลึก และมดทหารปิดเส้นทาง ทุกตัวมีหน้าที่ของรัง
3. **ด่านคัดเลือก** — ราชองครักษ์เขี้ยวทับทิมสร้างกรงผลึกและเรียกหน่วยสอดแนม เพื่อทดสอบว่าผู้บุกรุกเป็นภัยต่อไข่หรือไม่
4. **ห้องราชินี** — WARNING ดังขึ้น กล้องพาผู้เล่นเห็นราชินีมุดจากหลุมและคำราม รังทั้งรังตอบสนองต่อคำสั่งของนาง
5. **ความจริงหลังศึก** — เมื่อราชินีล้มลง ผลึกหยุดเรืองแสงชั่วคราว โมโม่พบตราเตาอบบนเสาหิน: เชฟขมส่งกรดมาแลกกับยาที่ประคองไข่ทั้งรัง ประตูชีวภาพเปิดทางขึ้นสู่ท่อระบาย

### เส้นเรื่องด่าน 2 — ท่อระบายฟองเน่า

1. **กรดไหลย้อน** — ประตูจากรังพาโมโม่ขึ้นสู่ระบบท่อ กรดมรกตถูกสูบผ่านวาล์วและหมักจนเกิดฟองมีชีวิต
2. **ฝูงประจำท่อ** — ฟองเน่า, อสูรกระแสไหลย้อน, ฟองพ่นน้ำเสีย, ถุงแรงดันหมัก และปูตะแกรงเกราะเป็นสิ่งมีชีวิตคนละสายพันธุ์และคนละบทบาท ไม่ใช้ศัตรูด่านอื่นมาย้อมสี
3. **วาล์วเดือด** — วาล์วมอว์ ผู้เฝ้าแรงดัน ใช้วงล้อมและกระสุนฟอง เพื่อสอนผู้เล่นให้ออกจาก telegraph ก่อนวาล์วปิด
4. **ห้องแรงดัน** — คลอกมอว์ จ้าวแห่งท่ออุดตัน โผล่จากตะแกรงแตก ใช้แรงดูด, ฟองกักตัว, บ่อน้ำเสีย และคลื่นน้ำล้นเปลี่ยนสนามตามเฟส
5. **ร่องรอยห้องเครื่อง** — เมื่อแรงดันดับ โมโม่พบว่าท่อไม่ได้กำจัดกรด แต่ส่งกรดที่หมักแล้วไปเป็นเชื้อเพลิงให้ห้องเครื่องพริกเพลิง

## กฎภาพและธีม — The Rotting Drain

- โลหะท่อสีน้ำเงินเทาและน้ำเสียเขียวมินต์เป็นสีหลัก เพื่อแยกจากดินโกโก้ของรังมด
- ศัตรูทุกชนิดต้องมี silhouette และสีบทบาทชัด: เร็ว=ฟ้า, ยิงไกล=เขียว, ระเบิด=เหลือง, ถึก=น้ำเงินเข้ม
- ฟองคือสิ่งมีชีวิตจากการหมักกรด ไม่ใช่ศัตรูขนมแบบสุ่ม
- กลไกหลักคือแรงดัน: ดูดเข้าศูนย์กลาง, ขังให้ช้าลง และคลื่นที่ต้องลอดช่อง ไม่ใช้เพียงการเพิ่ม HP
- มินิบอสสอนฟองกักตัวและวงล้อมก่อน Final boss ใช้แรงดันทั้งหมดร่วมกัน
- ฉากใช้พื้นหินเปียก โลหะขึ้นสนิม ร่องน้ำเสีย และตะแกรงระบายแบบ top-down โดยเว้นพื้นที่กลางให้การต่อสู้อ่านง่าย

## กฎภาพและธีม — Sour Ant Colony

ทุกศัตรูด่าน 1 ต้องอ่านว่าเป็นสิ่งมีชีวิตจากอาณาจักรเดียวกัน:

- เปลือกไคตินสีน้ำตาลโกโก้
- ดวงตาหรือจุดเรืองแสงสีชมพูแดง
- กรดและผลึกสีเขียวมรกต
- รูปทรงลูกกวาด/ขนมยังหลงเหลืออยู่ เพื่อเชื่อมกับโลก Mochitopia
- อุปกรณ์และสิ่งปลูกสร้างเกิดจากดิน น้ำตาลตกผลึก ไข่ และฟีโรโมน ไม่ใช่อุปกรณ์ครัวแบบสุ่ม

| วรรณะ | บทบาทเกม |
|---|---|
| มดงานโกโก้ | ศัตรูพื้นฐาน เดินเป็นฝูง |
| มดสอดแนมทับทิม | วิ่งเร็ว/พุ่งตัดทาง |
| มดพ่นกรด | รักษาระยะและยิงกรด |
| มดทหารเกราะหนา | ถึก ช้า บีบพื้นที่ |
| มดโดรนปีก | Elite เคลื่อนที่กดดัน |
| ราชองครักษ์ | Mini-boss: พุ่งชน กรงผลึก เรียกลูกน้อง |
| จักรพรรดินี | Final boss: ควบคุมรังทั้งหมด |

## เสาหลักการออกแบบบอส

1. **ประกาศภัย** — WARNING กลางจอก่อนการควบคุมกล้อง
2. **การมาถึงที่เล่าเรื่อง** — บอสต้องเข้าฉากด้วยแอนิเมชันเฉพาะพื้นที่
3. **อ่านได้ก่อนเจ็บ** — ทุกท่าแรงมี telegraph และช่องให้หลบ
4. **สนามรบเปลี่ยนตามเฟส** — ไม่ใช่แค่เพิ่ม HP/ความเร็ว
5. **ตัดกำลังได้** — ไข่ ผลึก เสาฟีโรโมน หรือกองเพาะต้องทำลายได้
6. **มีจังหวะหายใจ** — หลังท่าใหญ่มีหน้าต่างให้ผู้เล่นสวนกลับ

### จักรพรรดินีมดกรดมรกต

- **เฟส 1 — ปกป้องรัง (100–68%)**: สแลม, พ่นกรด, วางไข่ที่ฟักได้, พุ่งเป็นเส้น
- **เฟส 2 — รังแตก (68–35%)**: ปลุกผลึกยิงและเสาฟีโรโมน, เพิ่ม Acid Crown Nova
- **เฟส 3 — ราชินีคลั่ง (35–0%)**: สร้างกองเพาะลูกน้อง, บ่อกรดหลายจุด, Nova สองชั้น
- ผู้เล่นเลือกได้ว่าจะเร่งตีบอสหรือหยุดทำลายวัตถุเพื่อเอาพื้นที่ปลอดภัยกลับคืนมา

## โครงเรื่องระยะยาว

### บทที่ 2 — สวนหมักพิษ
ตามรากผลึกขึ้นสู่สวนขนมที่เชื้อราหมักเปลี่ยนพืชให้มีสติ โมโม่พบกลุ่มต่อต้านกลุ่มแรก และเริ่มสงสัยว่าคำสาปอาจรักษาบางชีวิตไว้ด้วย

### บทที่ 3 — โรงงานไร้รส
เครื่องจักรผลิตอาหารไร้รสจำนวนมหาศาล หุ่นยนต์เชื่อว่าการลบรสชาติคือการลบความขัดแย้ง โมโม่ต้องเลือกระหว่างทำลายโรงงานหรือปลดปล่อย AI ผู้ควบคุม

### บทที่ 4 — นครน้ำตาลแตกสลาย
อาณาจักรขนมเกิดสงครามกลางเมือง ฝ่ายหนึ่งต้องการใช้พลังของ The Great Hunger เพื่อต่อชีวิตเมือง อีกฝ่ายยอมเสียสละเมืองเพื่อหยุดวงจร ผู้เล่นได้เห็นผลของการตัดสินใจในบทก่อน

### บทที่ 5 — งานเลี้ยงแห่งความหิว
เชฟขมกลับมาในฐานะพันธมิตรที่ไม่น่าไว้วางใจ โมโม่เข้าสู่โต๊ะเลี้ยงนอกโลกและพบว่า The Great Hunger เติบโตจากความอยากที่ไม่มีขอบเขต บทสรุปชี้ว่าชัยชนะไม่ใช่การทำให้โลกหวานตลอดไป แต่คือการยอมรับทุกรสโดยไม่ปล่อยให้รสใดกลืนกินทั้งหมด

## บทส่งท้าย — Endgame: ครัวเที่ยงคืน (The Midnight Kitchen)

> ต่อจากบทที่ 5 หลังโมโม่ "ยอมรับทุกรส" แล้ว The Great Hunger **ไม่ตาย** — เพราะความหิวเป็นสิ่งที่ดับไม่ได้ มีแต่ต้องเลี้ยงดูมันไปเรื่อย ๆ
> นี่คือคำตอบของคำถาม "ทำไมยังต้องเล่นต่อไม่รู้จบใน Endgame"

### แนวคิดหลัก — ความหิวที่ดับไม่ได้
The Great Hunger ไม่ใช่ศัตรูที่ฆ่าให้ตายได้ แต่คือ **แรงพื้นฐานของจักรวาล Mochitopia** เหมือนความหิวในสิ่งมีชีวิตจริง เมื่อโมโม่หยุดมันได้ครั้งหนึ่ง มันเพียง "หลับ" ไม่ได้หายไป — ทุกคืน มันตื่นและกลืนรสชาติของโลกอีกครั้ง

ผู้พิทักษ์จึงไม่ได้ "ชนะแล้วจบ" แต่กลายเป็น **ผู้เฝ้าครัวเที่ยงคืน (Midnight Cooks)** — คนที่อาสายืนหยัดในห้วงความหิวทุกคืน เพื่อปรุงรสให้โลกอยู่รอดจนถึงเช้า นี่คือเหตุผลเชิง lore ที่ผู้เล่นกลับมาเล่นซ้ำไม่รู้จบ: **การป้องกันไม่มีวันจบ มันคือหน้าที่ ไม่ใช่ภารกิจ**

### สามโหมด Endgame (ผูกกับระบบที่มีจริง)

1. **Midnight Kitchen Endless** — ห้วงที่ The Great Hunger กลืนทุกด่านเข้าเป็นครัวเดียว ศัตรูจากทุกบทหลอมรวมกัน ยิ่งอยู่นาน ความหิวยิ่งเข้มข้น (สเกลไม่รู้จบ) ผู้เล่นดูว่าจะยืนได้ถึง "รอบ" (cycle) ที่เท่าไร — สื่อว่า *ไม่มีใครกันความหิวได้ตลอดไป มีแต่กันได้นานที่สุด*
2. **The Echo of Hunger** (ทุก 3 รอบ) — เสียงสะท้อนของบอสที่เคยล้ม กลับมาในร่างที่ความหิวปั้นขึ้นใหม่ (echo) เพราะความทรงจำของพวกมันถูกความหิวเก็บไว้และเล่นซ้ำ — ธีม: อดีตที่ไม่ยอมหายไป
3. **Ascension (ก้าวข้าม)** — ผู้พิทักษ์ที่ยอมสละพลังสะสมทั้งหมดเพื่อ "ก้าวข้าม" ขึ้นชั้นใหม่ ได้รสที่ลึกกว่าเดิมกลับมา — สื่อว่า *การเสียสละคือวิธีเดียวที่จะแข็งแกร่งขึ้นในสงครามที่ไม่มีวันจบ* (loop เชิงพลังที่หล่อเลี้ยงการเล่นซ้ำ)

### ทำไมผู้เล่นถึงเล่นต่อ (แรงจูงใจเชิง lore + ระบบ)
- **Lore:** โลกจะเปรี้ยว/ไร้รสอีกครั้งถ้าไม่มีใครเฝ้า — ผู้เล่นคือแนวป้องกันสุดท้าย ทุกคืน
- **ระบบ:** Ascension คืนพลัง, Endless ให้ leaderboard/สถิติ, Echo ให้ของหายาก → ทั้งสามป้อน meta progression (Rank/Ascendancy/Gear) ที่ไม่มีเพดานจริง
- **อารมณ์:** เปลี่ยนจาก "เอาชนะ" เป็น "ดูแล" — ธีมอบอุ่นแบบโมจิ ไม่ใช่การพิชิตแบบฮีโร่ทั่วไป

### เชื่อมกับ Ascendancy (Awakened Path)
Ascendancy = ผู้พิทักษ์ยอมรับ "ด้านหนึ่ง" ของ Core ตัวเองอย่างเต็มที่เพื่อรับมือความหิว (ดู `docs/ASCENDANCY_DESIGN.md`) — การเลือก Path คือการเลือกว่าจะเผชิญความหิวด้วยตัวตนแบบไหน จึงเป็นการตัดสินใจเชิงเรื่องราว ไม่ใช่แค่ build

## กติกาความต่อเนื่อง

- ตัวละครหลักและรูปลักษณ์ของบอสเดิมต้องคงเอกลักษณ์ แม้เพิ่มเฟรมแอนิเมชัน
- Monster ใหม่ต้องมี faction, หน้าที่ในระบบนิเวศ และเหตุผลที่อยู่ในแผนที่นั้น
- Mini-boss ทุกตัวต้องสอนกลไกอย่างน้อยหนึ่งอย่างที่จะกลับมาใน Final boss
- เมื่อบอสล้ม แก่นรสของพื้นที่จะตกผลึกเป็นกล่องความทรงจำ ให้ Sugar หรือของสวมใส่ แล้วผู้เล่นกลับไปเลือกเส้นทางถัดไปจากแผนที่บท
- เริ่มด่านใหม่โดยไม่มี Skill/Passive จากด่านก่อน เพื่อให้แต่ละพื้นที่มี build และจังหวะของตนเอง
- ระบบเมตาเรียกว่า **สายใยรสชาติ**: CORE (ชีวิต), FLAVOR (พลังรส), BOND (คำสัตย์ปกป้อง) และเลื่อนจากเศษรสแรกตื่นไปสู่ Flavorbound
- ตาโร่เป็น Awakened Explorer ผู้ตามรอยความทรงจำด้วย Echo Step; งาดำเป็น Awakened Ward Architect ผู้สะท้อนคำสาปด้วย Mirror Glaze
- ข้อความเปิดเวฟต้องเล่าเหตุการณ์ของพื้นที่นั้นเสมอ ไม่ใช้ชื่อเชิงระบบหรือข้อความฝูงแบบสุ่ม
