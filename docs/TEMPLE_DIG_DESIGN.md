# ⛏️ Temple Depths — ห้องลับใต้วิหาร Flavor Weave

มินิเกม "ขุดหาสมบัติ" ใต้วิหาร · ลุ้นทุกครั้งที่ขุด · ของที่ได้ต่อเข้าระบบเดิม (แก่น 3 อัน + Rank Perks)

## 1. วงจรหลัก
```
เล่นด่าน → ได้ ⛏️ พลั่ว → ขุดกระดาน 5×5 (ลุ้น) → ได้ของ
   ↑                                             ↓
แรงขึ้น ← อัปแก่นขั้นพิเศษ (หินแก่น) / ปลด Perk ลับ (คัมภีร์)
```

## 2. กติกา
| หัวข้อ | ค่า |
|---|---|
| กระดาน | 5×5 ต่อชั้น · สุ่มใหม่ทุกครั้งที่ลงชั้น · เซฟค้างไว้ข้ามการปิดเกม |
| ขุด 1 ครั้ง | ใช้ ⛏️ 1 อัน |
| หินแข็ง | ต้องขุด 2 ครั้ง (ครั้งแรกแค่ร้าว) |
| พลั่วเริ่มต้น | ของขวัญ 5 อัน (ครั้งแรก) · ฟรีวันละ 1 |
| แหล่งพลั่วในด่าน | จบด่าน ปกติ 1 / ยาก 2 / นรก 3 (กฎเหล็ก) · มินิบอส 25% +1 · บอส +1 · Perk Treasure Sense |

### ของในกระดาน (น้ำหนักสุ่ม · ชั้นลึกของดีขึ้น)
| ของ | ผล |
|---|---|
| 🍬 เศษ Sugar | Sugar 15–40 × (1 + ชั้น×0.15) |
| 🔶 หินแก่น (แดง/ส้ม/ฟ้า = CORE/FLAVOR/BOND) | ใช้อัปแก่นขั้นพิเศษ |
| 📜 ชิ้นส่วนคัมภีร์ | ครบ 4 = ปลด Perk ลับ 1 ตัว |
| 🏺 หีบโบราณ | สุ่ม: Sugar ก้อนใหญ่ / currency 2–4 / หินแก่น 2 / คัมภีร์ 1 |
| 💎 อัญมณีแห่งชั้น | มี 1 เม็ดต่อชั้น · เจอแล้วลงชั้นถัดไปได้ |
| 🪤 กับดัก | เสียพลั่วเพิ่ม 1 (ถ้ามี) — เบา ๆ ไม่ลงโทษหนัก |
| 🕳️ ทางลับ (หายาก ~8%) | ข้ามลงไป 2 ชั้น + ชั้นลับของดี |
| (ว่าง) | ดิน/เศษเล็ก ๆ |

**รอยใบ้:** ช่องที่มีของหายาก (หินแก่น/คัมภีร์/หีบ/ทางลับ) มีโอกาส 60% แสดงประกายจาง ๆ บนผิวหิน

## 3. ผูกระบบเดิม
### 3.1 แก่นขั้นพิเศษ (Overcap)
- แก่นปกติ Lv1–3 ต่อยศ (ของเดิม ไม่แตะ)
- เพิ่ม **Overcap +1…+6 ถาวร** ต่อแก่น (ไม่รีเซ็ตตอนเลื่อนยศ)
- ค่าอัป +N = หินแก่นสีนั้น N ก้อน + Sugar 150×N
- แต่ละขั้นเท่ากับ 2 เลเวลของแก่นนั้น (บวกเข้า `talTotal`)

### 3.2 Perk ลับ (ชั้นที่ 4 ของผัง Rank Perks — "Ancient")
ปลดด้วยคัมภีร์ 4 ชิ้นเท่านั้น (RP ใช้ไม่ได้) · เลือกเองว่าจะปลดตัวไหนก่อน
| id | ชื่อ | ผล |
|---|---|---|
| echoDash | Echo Dash | Dash ครั้งที่ 3 ติดกันใน 2.5 วิ ปล่อยคลื่นกระแทกรอบตัว |
| treasureSense | Treasure Sense | ฆ่ามอนมีโอกาส 0.5% ได้ ⛏️ (สูงสุด 3/ด่าน) |
| secondWeave | Second Weave | เลเวลอัพครั้งแรกของด่านได้เลือกการ์ด 2 รอบ |
| ancientGuard | Ancient Guard | โดนตีจนตายครั้งแรกของด่าน รอดที่ 1 HP + อมตะ 3 วิ |
| sugarVein | Sugar Vein | Sugar จากการฆ่า +20% |
| deepRoots | Deep Roots | Max HP +8% · ฟื้น HP +0.6/วิ |

## 4. อนิเมชัน (โค้ดล้วน ไม่ต้องรออาร์ต)
