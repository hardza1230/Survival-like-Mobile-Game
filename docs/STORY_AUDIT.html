เรื่องย่อปัจจุบัน

  1. บทเปิด: ผู้ปลูกคนแรกวางมงกุฎแห่งรสเพื่อไม่ให้ใครหิว → ทุกคนกลายเป็นโมจิ มงกุฎกินรสชาติ (= ความทรงจำ) · Strawberry ตกรอยแยก เจอเมล็ดหัวใจ กลับเป็นคน · พบ Ruby ภูตแยมของคุณยาย
  2. บท 1 ใต้ครัว: รังมด → ท่อ → ห้องเครื่องพริก → คุกน้ำตาล (เจอคุณยายแช่แข็ง) → เตาอบ (สู้ปากของ Hunger ที่ปลายราก) · ปลดเพื่อนทีละคน
  3. บท 2 สวนหมัก: รากหนีลงสวน ปั้นร่างใหม่จากความทรงจำ · ดอกตูม → หนองเห็ด → รังผึ้ง → เรือนกระจก 4 ฤดู → บัลลังก์ราก
  4. บท 3 ทุ่งเมล็ด: ทุ่งไหม้ → สวนกลวง → เรือนกระจกแก้ว → ห้องเก็บเมล็ด → ผู้ปลูกคนแรก
  5. ตอนจบ: ผู้ปลูกถอดมงกุฎ · ปลูกเมล็ดหัวใจ · คำสาปแตก · Hunger หลับ → Endgame
