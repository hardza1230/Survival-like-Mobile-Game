## E. การ์ดพิเศษ (ใบ 80 · v8.1.137–138)
- [ ] Build Path: การ์ดภาพวาดพลิกหงายทีละใบ · แตะ = ซูม + อ่าน · แตะซ้ำ = เลือก · ภาพตรงสาย (Mint Glacier = พายุหิมะ / Barrage = หนามน้ำแข็ง)
- [ ] Mutation: สมุดสูตร ตัวหนังสือในหน้ากระดาษอ่านออก
- [ ] Relic: ห้องสมบัติ · Evolution: ทั่งตีเหล็ก
- [ ] การ์ดในกองไม่ซ้ำกัน (Yuzu "+1 Minion" มีใบเดียว)
