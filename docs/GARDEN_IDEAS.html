แทน Expedition · Idle ไม่ทับเกมหลัก · คนทำงานเปิดแวะดูสั้น ๆ ได้ · ร่าง 27 พ.ย. 2026

กฎร่วมทุกแบบ

  1. เปิดหลังผ่าน C2-1 (ไม่เพิ่มภาระช่วงต้น ตาม GAME_PILLARS)
  2. ของที่ได้ = Sugar / Twist Cream / ของแต่งตัว / ของแต่งสวน · ไม่ให้พลังต่อสู้ตรง ๆ ที่หาไม่ได้จากเกมหลัก
  3. เวลาออฟไลน์มีเพดาน (8–12 ชม.) ไม่ต้องเข้าทุกชั่วโมง · มีจุดแดงเมื่อพร้อมเก็บ
  4. ห้ามขายเวลาเร่งด้วยเงินจริงจนกว่าจะมี Play Billing + เซิร์ฟเวอร์ (LAUNCH_RULES กฎ 4) · ช่วงทดสอบใช้โฆษณา rewarded เร่งได้วันละไม่กี่ครั้ง

A · 🌱 แปลงปลูก (Plant · Wait · Harvest) ต้นทุน ต่ำ

ปลูกเมล็ด → รอเวลาจริง → เก็บผล → อัปแปลง

Core loop
  1. เลือกเมล็ด (เมล็ดได้จากด่าน Story / ภารกิจ)
  2. ปลูกลงแปลง 3–6 แปลง · โตตามเวลาจริง 30 นาที–8 ชม. (ออฟไลน์ก็โต)
  3. กลับมาเก็บ → ได้ Sugar / Twist Cream / สีย้อมชุด
  4. ใช้ผลผลิตอัปแปลง (โตเร็วขึ้น · แปลงเพิ่ม)
ข้อดี
  • เข้าใจทันที คนทำงานเปิด 30 วิ เก็บแล้วปิด
  • สร้างง่ายสุด 1 หน้าจอ ใช้ระบบเวลาออฟไลน์อย่างเดียว
  • ผูกกับเกมหลักเบา ๆ (เมล็ดจากด่าน)
ข้อเสีย / ความเสี่ยง
  • ซ้ำ ๆ น่าเบื่อเร็ว ถ้าไม่มีอะไรใหม่
  • คล้ายเกมฟาร์มทั่วไป

อาร์ตที่ต้องสั่ง: อาร์ตแปลง 3 ขั้น × พืช 4–6 ชนิด + พื้นสวน

B · 🏡 หมู่บ้านโมจิ (Assign helpers) ต้นทุน กลาง

โมจิที่ช่วยไว้จากด่าน → ส่งไปทำงานในสวน → ผลิตของตามเวลา

Core loop
  1. เคลียร์ด่าน Story = ช่วยโมจิได้ 1 ตัว (มีนิสัย/ถนัดงานต่างกัน)
  2. วางโมจิในสถานี: เตาขนม / บ่อน้ำผึ้ง / แปลงผัก / โรงทอผ้า
  3. สถานีผลิตต่อเนื่อง (มีเพดาน 8–12 ชม.)
  4. โมจิเลเวลขึ้นตามเวลาทำงาน → ผลิตเร็วขึ้น · ปลดสถานีใหม่
ข้อดี
  • ผูกกับเรื่องหลักชัด (ช่วยเพื่อนคุณยาย) · มีของสะสม
  • ตัดสินใจเล็ก ๆ ทุกครั้งที่เข้า (ใครทำอะไร)
  • โตยาว เล่นได้หลายเดือน
ข้อเสีย / ความเสี่ยง
  • UI และระบบเยอะกว่า A
  • ต้องมีอาร์ตโมจิหลายตัว + สถานี

อาร์ตที่ต้องสั่ง: โมจิ 8–12 ตัว (นิ่ง + ทำงาน 2 เฟรม) + สถานี 4

C · 🍰 ร้านน้ำชา (Garden → Orders) ต้นทุน กลาง–สูง

สวนผลิตวัตถุดิบ → ลูกค้าโมจิสั่งขนม → ส่งออเดอร์รับรางวัล

Core loop
  1. สวนผลิตวัตถุดิบ 3–4 ชนิดตามเวลา
  2. มีออเดอร์ 3 ใบ รีเฟรชทุก 4 ชม. (เช่น เบอร์รี่ 5 + น้ำผึ้ง 2)
  3. ส่งครบ → รางวัล + ความสนิทของลูกค้า
  4. สนิทถึงขั้น → ปลดชุดแต่งตัว / เรื่องสั้นของตัวละคร
ข้อดี
  • มีเป้าหมายชัดทุกครั้งที่เข้า
  • ปลดของแต่งตัว/เรื่องราว = ไม่ขายพลัง
  • เข้ากับธีมขนมของเกมมาก
ข้อเสีย / ความเสี่ยง
  • ต้องจูนวัตถุดิบ–ออเดอร์ให้พอดี
  • ซับซ้อนกว่า A สองชั้น (ผลิต + ส่ง)

อาร์ตที่ต้องสั่ง: วัตถุดิบ 4 + ลูกค้า 4–6 + หน้าร้าน

D · 🌳 ต้นไม้วิญญาณ (Incremental tree) ต้นทุน ต่ำ

ต้นไม้ใหญ่ 1 ต้นเก็บน้ำค้างตลอดเวลา → ใช้น้ำค้างปลูกกิ่ง → กิ่งให้โบนัส QoL

Core loop
  1. ต้นไม้สะสม 💧 น้ำค้างต่อเนื่อง (เพดาน 12 ชม.)
  2. เข้ามาแตะเก็บ → ใช้ปลดกิ่ง (ต้นไม้ทักษะของสวน)
  3. กิ่งให้: เพดานเก็บนานขึ้น · Sugar รายวัน · ของแต่งสวน/ลอบบี้
  4. ต้นไม้โตเห็นภาพเปลี่ยนตามขั้น
ข้อดี
  • ถูกที่สุด หน้าจอเดียว
  • เปิด 10 วิ ก็ได้ของ
  • เห็นการเติบโตชัด
ข้อเสีย / ความเสี่ยง
  • ตื้นที่สุด ไม่มีการตัดสินใจ
  • ถ้ากิ่งให้พลังต่อสู้ = ผิดกฎห้ามขายพลังทางอ้อม → ต้องเป็น QoL/แต่งเท่านั้น

อาร์ตที่ต้องสั่ง: ต้นไม้ 4 ขั้น + กิ่ง/ใบ

E · 🧺 ทีมเก็บของในสวน (Expedition-lite) ต้นทุน ต่ำ

ส่งทีมโมจิไปเขตสวน 2/4/8 ชม. → กลับมาพร้อมของ + โปสการ์ดเรื่องสั้น

Core loop
  1. เลือกเขต (ป่าเบอร์รี่ / ลำธารน้ำผึ้ง / ถ้ำน้ำตาล)
  2. ส่งทีม 1–3 ตัว ตามเวลาที่เลือก
  3. กลับมาได้ของ + โปสการ์ด (สะสมเป็นอัลบั้มเรื่องราว)
ข้อดี
  • ใช้โค้ด/อาร์ต Expedition เดิมได้บางส่วน · เร็วที่สุด
  • สะสมโปสการ์ดได้
ข้อเสีย / ความเสี่ยง
  • ใกล้ของเดิมที่จะเปลี่ยนออก
  • ตัดสินใจน้อย

อาร์ตที่ต้องสั่ง: โปสการ์ด 10–15 ใบ + เขต 3

คำแนะนำของ AI

ผสม A + B (แปลงปลูก + โมจิผู้ช่วย) — เริ่มจาก A ให้ทันใช้ (หน้าเดียว ง่าย) แล้วเพิ่ม "โมจิที่ช่วยไว้จากด่าน" มาเป็นผู้ช่วยแปลง (B แบบเบา) ทีหลัง

  • ได้: loop ชัด 30 วิ/ครั้ง · ผูกเรื่องหลัก · ขยายต่อเป็น C (ร้านน้ำชา) ได้ภายหลัง
  • เสีย: ต้องสั่งอาร์ตใหม่ (แปลง/พืช/โมจิผู้ช่วย) · ใช้เวลา 2–3 รอบงาน
