# ⚫ Sesame — Mirror Network · เอกสารออกแบบ (ร่าง รอเจ้าของตอบคำถาม §10)

สถานะ: เจ้าของเลือกแนวทาง 21 ต.ค. 2026 — แก่น **1 Mirror Network** + สาย **12 Mirror Maze / 14 Reflect / 36 Phase Swap** + Unique **44 Glass World** · ยังไม่แก้โค้ด

## 1. แก่นของตัวละคร

**"ฝีมืออยู่ที่วางกระจกตรงไหน"** — ฮีโร่ตัวแรกที่ผู้เล่นจัดรูปทรงสนามเอง

- **กด Dash = ทิ้งกระจกไว้ตรงจุดที่ออกตัว** (ไม่มีปุ่มเพิ่ม เล่นนิ้วเดียวได้เหมือนเดิม)
- กระจกบนพื้นได้สูงสุด **3 บาน** · บานที่ 4 จะแทนบานเก่าสุด · บานหนึ่งอยู่ได้ **20 วิ**
- **Mirror Beam (โจมตีปกติ)** ยิงเองตามคูลดาวน์ จากงาดำไปบานที่วางเก่าสุด → บานถัดไป → … → บานล่าสุด แล้วยิงต่อจากบานล่าสุดไปหาศัตรูใกล้สุด (บอส/มินิก่อน)
  - ทุกช่วงของเส้นแสงทำดาเมจกับศัตรูที่ขวางทาง
  - ช่วงที่สะท้อนออกจากกระจกแรงขึ้น +15% ต่อการเด้ง (เด้ง 3 ครั้ง = +45% ที่ปลายทาง)
  - กระจกห่างจากงาดำเกิน 700px → ไม่นับในเส้น (กันเส้นยาวข้ามจอ)
- **ยังไม่มีกระจก = ยิงตรงไปหาศัตรูเหมือนตอนนี้** (คนเล่นใหม่ไม่มีวันยิงไม่ออก)
- **Passive Oath Focus (เสนอเปลี่ยน):** จาก "ยืนนิ่งแล้วแรงขึ้น" → **"+6% ดาเมจต่อกระจกบนพื้น"** (สูงสุด +18%) · เพราะสาย Phase Swap ต้องเคลื่อนที่ตลอด
- รอย Mirror Mark เดิม (โดน 5 ครั้งแตกระเบิด) คงไว้ — เข้ากับธีม
- ทุกด่านเริ่มโดยไม่มีกระจก

**ความรู้สึกที่ต้องการ:** นาทีแรกยิงธรรมดา · พอเริ่ม Dash เป็นจังหวะ เส้นแสงพาดเป็นรูปสามเหลี่ยม/ซิกแซกเต็มจอ · ตอนบอสต้องเลือกว่าจะวางกระจกตรงไหนให้แสงผ่านบอสหลายช่วง

## 3. สามสาย Build

ใช้ **id เดิม** (`prism` / `lens` / `sentinel`) ให้แต้ม Talent ที่ลงไว้ยังอยู่ · เปลี่ยนแค่ชื่อ/ผล

### 🌀 Mirror Maze (id เดิม `prism`) — กวาด / เคลียร์ฝูง

- กระจกทุกบาน **หมุนเองช้า ๆ** และยิงแสงสั้นของตัวเอง (ยาว 200px) กวาดเป็นวงรอบบาน 90°/วิ
- เส้นแสงหลักยังเด้งผ่านกระจกตามปกติ แต่ดาเมจหลัก ×0.8
- วางแล้วปล่อยทำงาน เหมือนสร้างเครื่องบดศัตรู → เหมาะยืนเฝ้าจุด

### 🛡️ Reflect (id เดิม `lens`) — สะท้อน / สู้บอส

- กระจกดูดกระสุนศัตรูที่เข้ามาในรัศมี 60px → เก็บเป็น **แต้มสะท้อน** (สูงสุด 20)
- ศัตรูที่เดินชนกระจกโดนผลักกลับ + ได้ 1 แต้ม (ด่านที่ไม่ค่อยมีคนยิงก็ยังได้ใช้)
- ท่าใหญ่ของบอสระเบิดใกล้กระจก = ได้ 5 แต้ม
- เส้นแสงหลักครั้งถัดไปแรงขึ้น **+5% ต่อแต้ม** (เต็ม 20 = ×2) แล้วแต้มหมด
- คงโบนัสเดิม +20% กับ elite/บอส · ยิ่งด่านโหดยิ่งแรง

### 💨 Phase Swap (id เดิม `sentinel`) — วาร์ป / เล่นเร็ว

- **Dash = วาร์ปไปที่กระจกเก่าสุด** (ภายใน 600px) แล้ววางกระจกใหม่ตรงที่จากมา
- ทุกครั้งที่วาร์ป ปล่อย **คลื่นแก้วรัศมี 110px** ทั้งจุดต้นทางและปลายทาง
- ไม่มีกระจกในระยะ → Dash ปกติ (และวางกระจกตามแก่น)
- คงโบนัสเดิม +25% ดาเมจกับศัตรูไกล (เข้ากับการวาร์ปหนี)

## 4. Unique — Glass World (แตะ · คูลดาวน์ 12 วิ เท่าเดิม)

แทน Prism Barrage เดิม

- **หยุดเวลา 2 วิ:** ศัตรูและกระสุนศัตรูหยุดนิ่ง และกลายเป็นแก้ว (สีจาง) · งาดำอมตะ แต่ยังเดินได้
- วางกระจกชั่วคราว **3 บานรอบกลุ่มศัตรูที่หนาแน่นสุด** (ไม่กินโควตา 3 บาน)
- พอเวลากลับมาเดิน เส้นแสงวิ่งผ่านกระจกทุกบาน (ของจริง + ชั่วคราว) ดาเมจ ×3 · ศัตรูแก้วที่โดนแสงแตกพร้อมกัน (×1.5)
- **ตามสาย:**
  - Maze: กระจกชั่วคราวหมุนกวาดต่ออีก 4 วิ
  - Reflect: กระสุนศัตรูทั้งจอถูกดูดเป็นแต้มสะท้อนเต็ม 20
  - Phase: งาดำวาร์ปไล่ผ่านกระจกทุกบาน ปล่อยคลื่นแก้วทุกจุด
- ระดับ Unique (Talent) ใช้แบบเดียวกับฮีโร่อื่น: ul2 แรงขึ้น · ul3 คูลดาวน์ลด · ul4 ปิดท้ายด้วยระเบิดแก้วทั้งจอ

### การ์ดสาย (5 ใบต่อสาย)

**Maze:** p_facet Prism Echo (เดิม: ทุก 4/3 ครั้งยิงซ้ำ 50%) · p_refract Refraction (เดิม +8%) · `s_spin` หมุนเร็วขึ้น +25%/lv · `s_twinray` แต่ละบานยิง 2 ทางตรงข้าม · `s_longray` แสงกวาดยาว +20%/lv

**Reflect:** p_lensbig Burning Lens (เดิม +15% vs elite/บอส) · p_steady Steady Hand (เดิม +10%) · `s_absorb` รัศมีดูด +20%/lv · `s_store` แต้มเพดาน +5/lv · `s_bounceback` 25%/lv โอกาสยิงกระสุนที่ดูดคืนทันที

**Phase:** p_longsight Longsight (เดิม +10% ไกล) · p_swift Retreat Shot (เดิม: หลัง Dash ลำถัดไป +30%/lv) · `s_shards` คลื่นแก้วใหญ่ขึ้น +20%/lv · `s_quickswap` วาร์ปแล้วคูลดาวน์ Dash −8%/lv · `s_slow` คลื่นแก้วทำให้ช้าลง 1 วิ

### Evolution รายสาย

- **Maze → Kaleidoscope Engine:** กระจก +1 บาน · แสงกวาดแตก 3 ทาง
- **Reflect → Perfect Reflection:** แต้มเพดาน ×2 · เต็มแล้วเส้นหลักเป็นแสงขาวใหญ่ ×3
- **Phase → Glass Walker:** Dash วาร์ปไล่ผ่านกระจกทุกบานในครั้งเดียว

### ⭐ Unique Mutation (2 ต่อสาย — ตอนนี้งาดำถูกปิดไว้)

- Maze: `maze_storm` (Glass World นาน +1 วิ) / `maze_keep` (กระจกชั่วคราวอยู่ต่อ 10 วิ)
- Reflect: `ref_nova` (จบ Glass World ปล่อยกระสุนที่ดูดเป็นวงรอบตัว) / `ref_guard` (หลัง Glass World ลดดาเมจที่โดน 30% 4 วิ)
- Phase: `ph_echo` (ทุกจุดวาร์ปทิ้งเงายิง 1 ครั้ง) / `ph_reset` (Glass World คืนชาร์จ Dash ทั้งหมด)

## 7. ประสิทธิภาพ (FPS)

- กระจกเป็น sprite ธรรมดา ไม่มี physics body · บนจอไม่เกิน **5 + 3 ชั่วคราว = 8 บาน**
- เส้นแสงคำนวณตอนยิงเท่านั้น (ไม่ทุกเฟรม) · Maze แสงกวาดเช็คดาเมจทุก 0.2 วิ
- Reflect เช็คกระสุนใกล้กระจกทุก 0.1 วิ (ไม่ทุกเฟรม)
- หยุดเวลา Glass World ใช้ค่าหยุดศัตรูเดิม (frozen) ไม่หยุด physics ทั้งโลก
- ป้าย source ใน Combat Meter: `sesame.beam` / `bounce` / `maze` / `reflect` / `swap` / `glass`
