เกมนี้ **มีอาร์ตจริงลงแล้วเยอะมาก** (ตัวละคร 5 ตัว, ศัตรู, บอส, ฉาก 5 โซน, VFX, ไอคอน) แต่ยังมีจุดที่ **ขาด/พัง/ใช้ emoji ชั่วคราว** งานของ AI อาร์ตคือ:

2. **เติมของที่ยังใช้ emoji**: ไอคอนสกิล/พรที่เหลือ, VFX บางตัว
3. **ยกระดับของเดิม** (ถ้ามีเวลา): มินิบอส, ฉาก, การ์ดตัวละคร
4. **ของใหม่ตาม roadmap**: ภาพประกอบ cutscene, achievement, daily reward ฯลฯ

**กติกาเหล็ก 5 ข้อ (จาก ART_BIBLE §0):**
1. ธีมขนมหวานน่ารัก กลมนุ่มเด้ง ไม่มีเหลี่ยมคม ไม่มีเลือด (ศัตรูโกรธได้แต่ยังน่ารักกวน ๆ)
2. ทุกไฟล์ **PNG พื้นโปร่งใส** ยกเว้น (ก) ฉากพื้นหลัง (ข) **VFX flipbook = พื้นดำสนิท** (ดู §2)

4. มุมมอง top-down เฉียงเล็กน้อย (¾) ตัวหันเข้ากล้อง มีเงาวงรีใต้ตัว

## 1. ข้อจำกัดทางเทคนิค (อ่านก่อนลงมือ)

- **เอนจิน:** Phaser 3.80.1 (เกมเว็บ HTML5) · โหลด asset ผ่าน `ASSET_IMAGES` (รูปนิ่ง), `ASSET_SHEETS` (สไปรต์ชีต), `ASSET_FX` (VFX flipbook) ใน `game.js`
- **ฟอร์แมต:** PNG เป็นหลัก (โปร่งใส) · ฉากพื้นหลังใช้ได้ทั้ง PNG/JPG/WEBP · เสียงเป็น WAV
- **โฟลเดอร์ปลายทาง:**
  - `assets/` = ไฟล์ตัวจริงที่เกมใช้
  - `assets/generated/` = ไฟล์ที่ผ่านสคริปต์ตัด/ประมวลผลแล้ว
  - `assets/raw/` = **โยนอาร์ตดิบมาที่นี่** (เจ้าของอัปผ่าน GitHub มือถือ) แล้วสคริปต์จะตัดลง `assets/`
  - `assets/character_cards/` = การ์ดตัวละครเต็มตัว
  - `assets/ui/` = UI · `assets/audio/` = เสียง
- **การตัด/ประมวลผล:** โปรเจกต์มีสคริปต์ตัดพื้นใส/ตัดสตริป/ตัด grid อยู่แล้ว (`scripts/cutout*.mjs/.cjs`, `cut_enemy_sheets.cjs` ฯลฯ) — **AI อาร์ตส่งภาพดิบตามสเปก แล้วให้ทีมโค้ดตัด** หรือส่งเป็นไฟล์ตัดแล้วก็ได้ถ้าทำตามสเปกเป๊ะ
- **retina:** ส่งภาพความละเอียดสูง (2× ของขนาดแสดงผล) เพราะจอมือถือ high-DPI
- **ขนาดไฟล์:** อย่าใหญ่เกินจำเป็น (เกมโหลดผ่านเน็ต) — บีบ PNG ให้เหมาะ

## 2. ⚠️ กฎเหล็กกันบั๊ก (สำคัญที่สุด — แยกตามชนิดงาน)

เกมนี้เคยเจอบั๊กจากอาร์ตหลายครั้ง กฎพวกนี้คือบทเรียนราคาแพง **ห้ามพลาด**

### 2.1 VFX Flipbook (เอฟเฟกต์อนิเมชัน เช่น ระเบิด/สายฟ้า/คลื่น)
- **พื้นหลังต้องดำสนิท (solid black #000000)** — ไม่ใช่โปร่งใส! เพราะเกมเล่นด้วย **additive blend** (พื้นดำหายไปเอง เหลือแต่แสงเรือง)
- เป็น **sprite strip แนวนอน** — เฟรมเรียงซ้าย→ขวา **ขนาดเท่ากันทุกเฟรม**
- มาตรฐาน **8 เฟรม** ต่อเอฟเฟกต์ (เว้นแต่ระบุอื่น)
- แต่ละเฟรมขนาด `fw × fh` (ไม่ต้องจตุรัส) — ดูตารางสเปกใน §3
- **ห้ามมีเส้นขาว/กรอบคั่นระหว่างเฟรม** (ถ้ามีจะตัดยาก) — เว้นระยะเฟรมเท่า ๆ กันบนพื้นดำ
- เอฟเฟกต์ควร "เรืองแสง" (glow) เข้ากับ additive — สีสว่างบนพื้นดำ
- **หมายเหตุ platform:** บาง platform ย่อ strip สูง ~3× (เฟรมโดนบีบแนวตั้ง) — ส่งไฟล์สัดส่วนถูกต้อง อย่าบีบเอง

### 2.2 สไปรต์ตัวละคร / ศัตรู / บอส (Sprite Sheets)
- **พื้นหลังโปร่งใส (alpha transparent)** — **ไม่ใช่ดำ ไม่ใช่ขาว!** (ตรงข้ามกับ VFX)
- จัดเป็น **grid เซลล์เท่ากัน** — ระบุ cols × rows ชัดเจน
- **ขนาดเซลล์ต้องเป๊ะ** ตามสเปก (เช่น 128px, 160px, 256px) — เกมหั่นตามขนาดนี้ ถ้าเพี้ยน = ภาพเลื่อน/ดำ
- ตัวละครยืนกลางเซลล์ (bottom-center) เว้นขอบเผื่อเงา
- **จำนวนเฟรมต้องครบตามที่ระบุ** — ⚠️ **ถ้า sheet บอกว่า 8 เฟรม ต้องมีอาร์ตครบ 8 ช่อง** ห้ามเว้นช่องว่าง (เฟรมว่าง = sprite ดำในเกม — บั๊กนี้เกิดกับบอสด่าน 2 มาแล้ว! ดู §6)

### 2.3 ฉากพื้นหลัง (Backgrounds)
- **ต้อง tile ได้แบบไร้รอยต่อ (seamless tileable)** — เกมปูเป็น TileSprite
- ขนาดมาตรฐาน **768×768px**
- ไม่ต้องโปร่งใส (เป็นพื้นเต็ม) · โทนสีตามธีมโซน (ดู ART_BIBLE §1.3)
- อย่าใส่รายละเอียดจัดจนแย่งสายตาจากตัวละคร/ศัตรู (ควรมืด/นุ่มลงเป็นฉากหลัง)

### 2.4 ไอคอน (Icons — สกิล/พร/UI)
- **PNG โปร่งใส ขนาด 128×128px**
- สไตล์ **2.5D confectionery fantasy** ชุดเดียวกันทั้งหมด (ให้ดูเป็นเซ็ตเดียว)
- **ห้ามมี checkerboard/พื้นเทา/ขอบ artifact** (เคยมีปัญหา alpha ไม่สะอาด ต้อง clean 2 รอบ)
- อ่านออกชัดในขนาดเล็ก (แสดงจริง ~40-64px) — silhouette ต้องชัด

### 2.5 การ์ดตัวละคร (Character Cards)
- **768×1024px PNG โปร่งใส** เต็มตัว (full-body) — ใช้ในหน้าเลือกตัวละคร/อุปกรณ์
- ตัวละครโพสท่าเท่ ๆ เห็นทั้งตัว มี alpha จริง (ไม่มีพื้น)

### 2.6 กระสุน / projectile
- PNG โปร่งใสเล็ก ๆ · เกมหมุน/ย่อ/ย้อมสีเองได้ (บางตัวเป็นสีขาวเพื่อ tint)

## 6. 🔴 ปัญหาที่ต้องแก้ (art ที่พังอยู่ตอนนี้)

### 6.1 บอสด่าน 2 (Clogmaw) — เฟรมหาย 4 ช่อง
- ไฟล์: `assets/generated/boss2_clogmaw_sheet.png` ขนาด **1024×512** (4 คอลัมน์ × 2 แถว = 8 เฟรม เซลล์ 256×256)
- **ปัญหา:** เฟรม 0-3 มีอาร์ต แต่ **เฟรม 4,5,6,7 ว่างเปล่า 100%** → เกมเรียกท่าเหล่านี้แล้วบอสกลายเป็น **sprite ดำ** (แก้ชั่วคราวในโค้ดด้วยการ map กลับไปเฟรม 0-3 แล้ว แต่ทำให้ท่าซ้ำ)
- **ต้องทำ:** วาดเฟรม 4-7 ให้ครบ เป็นท่าบอส (ตามลำดับที่เกมออกแบบไว้):
  - เฟรม 0 = idle (ลอยนิ่ง)
  - เฟรม 1 = emerge (โผล่)
  - เฟรม 2 = roar (คำราม)
  - เฟรม 3 = attack (โจมตี/พุ่ง)
  - **เฟรม 4 = prison (ปล่อยฟองกักตัว)** ← ต้องวาด
  - **เฟรม 5 = suction (ดูด แรงดัน)** ← ต้องวาด
  - **เฟรม 6 = overflow (น้ำเสียล้น)** ← ต้องวาด
  - **เฟรม 7 = enrage (เฟสคลั่ง วาล์วแตก)** ← ต้องวาด
- คงสไตล์/สัดส่วน/สีให้ตรงกับเฟรม 0-3 · เซลล์ 256×256 พื้นโปร่งใส · ธีม: ปีศาจท่ออุดตันขนมหวาน (ตามชื่อ Clogmaw จ้าวท่ออุดตัน)

### 6.2 ไอคอนสกิล/พรที่ยังเป็น emoji
- ดูใน `game.js` ตัวแปร `SKILL_ICON` และ `PASS_ICON` — คีย์ไหนที่ไม่ได้ map = ยังใช้ emoji
- ทำให้ครบเซ็ต 128×128 สไตล์เดียวกัน

### 6.3 ศัตรูด่าน 3-5 ยังย้อมสีของเดิม
- ควรมีชุดศัตรูเฉพาะธีม (เตาไฟ=พริก/ถ่าน, แช่แข็ง=น้ำแข็ง, เตาอบ=หุ่นเหล็ก/คำสาป)
