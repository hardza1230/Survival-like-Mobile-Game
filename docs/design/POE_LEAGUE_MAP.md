## 2. ยังไม่มี · ไอเดียที่เข้ากับเกม (เรียงตามความคุ้ม)
1. **Domination → ศาลเจ้าบัฟ (Shrines):** ศาลขนมโผล่ในด่าน เดินไปแตะได้บัฟ 10 วิ (โล่น้ำตาล / ยิงเร็ว / ดูดของ) · ง่าย ใช้ระบบภารกิจเดิม
2. **Essence → มอนติดคริสตัล:** Elite ถูกขังในก้อนน้ำตาล ผู้เล่นเลือกปลด = สู้ Elite ที่แรงขึ้น ได้ "แก่นรส" ใช้ Forge แบบกำหนดผล
3. **Archnemesis / Nemesis / Bloodlines → Monster Mods:** Elite มีคุณสมบัติสุ่ม (เร็ว / แยกร่าง / สะท้อน / ฟื้นเลือด) แสดงไอคอนบนหัว · ยิ่งหลายอย่างยิ่งดรอปดี (โน้ตเจ้าของใบ 4)
4. **Expedition → วางระเบิดขุดสมบัติ:** วางจุดระเบิดเป็นเส้น 4 จุด แล้วจุดชนวน ปลุกมอนที่ฝัง + เปิดหีบ · เข้ากับ Sweetstone Mine
5. **Beyond → ประตูลึกลับ:** ฆ่ามอนติดกันในที่เดียวเปิดประตู มอนจากอีกมิติออกมา (ยิ่งฆ่ายิ่งเปิดบ่อย) บางครั้งมีบอส
6. **Torment / Invasion → Event Monster:** วิญญาณ/บอสเร่ร่อนโผล่สุ่ม สิงมอนให้แรงขึ้น (โน้ตเจ้าของใบ 7)
7. **Sentinel → โดรนเสริมพลังศัตรู:** ส่งโดรนไปทำให้มอนกลุ่มหนึ่งแรงขึ้น แลกของดรอปเพิ่ม (เลือกเสี่ยงเอง)
8. **Incursion → ห้องวิหารข้ามรัน:** แต่ละด่านปลดห้องในวิหาร Temple ทีละห้อง ครบแล้วมีห้องรางวัลพิเศษ · ผูกหน้า Temple เดิม
9. **Heist / Betrayal:** ซับซ้อนเกินสำหรับมือถือ แนะนำข้าม
10. **Necropolis → หลุมฝังศพ:** เก็บศพมอนพิเศษ ใช้คราฟต์ของ · ข้ามได้ (ซ้ำกับ Forge)
11. **Mercenaries → จ้างฮีโร่ AI ช่วยรบ:** ทีมเพื่อนที่ปลดแล้วมาช่วย 1 ตัวต่อด่าน (Yuzu companions มีแนวนี้อยู่) · งานใหญ่
12. **Anarchy → ฮีโร่คู่แข่ง (Rival):** ฮีโร่ที่ถูก The Hunger สิงมาขวางทาง สู้แบบมินิบอส · เข้ากับเนื้อเรื่อง
