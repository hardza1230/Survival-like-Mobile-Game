# Mochi Mine (Dig) — เนื้อเรื่อง · ร่าง 1

## 1. เรื่องในหนึ่งย่อหน้า
ใต้ครัวหลวงของ Mochitopia มี **เหมืองหวาน (The Sweetstone Mine)** ที่ชาวเมืองขุดมาหลายร้อยปีก่อนเกิดความอดอยาก ดินที่นี่คือขนมโบราณที่ทับถมจนเป็นหิน แต่ละชั้นเก็บรสชาติของยุคหนึ่งไว้ · ตอนคำสาปเริ่ม เหมืองถูกปิดตาย และรากของ The Hunger ก็ชอนไชลงไปข้างล่างเพื่อกินรสเก่าที่ฝังอยู่ · **โมจิที่ผู้เล่นปลุกจาก Frozen Pantry** อยากตอบแทน จึงอาสาเป็นคนงานเปิดเหมืองอีกครั้ง โดยมี Ruby เป็นหัวหน้าคุมแผนที่ · ยิ่งขุดลึก ยิ่งเจอเศษความทรงจำของอาณาจักรก่อนถูกสาป และในที่สุดก็เจอปลายรากที่ The Hunger ใช้ดูดรสจากใต้ดิน

## 2. เข้ากับเรื่องหลักยังไง
- **ปลดล็อกหลัง C1-4 (คุกน้ำตาล):** ตอนนั้นผู้เล่นปลุกโมจิที่ถูกแช่แข็งครั้งแรก → พวกเขาคือคนงานกลุ่มแรก
- **คนงาน = โมจิที่ช่วยไว้ในด่าน:** ปลุกรูปปั้นใน Frozen Pantry / ปลดผู้พิทักษ์ / ชนะบอส → มีโมจิมาสมัครเป็นคนงานเพิ่ม (ช่วยคนในเกมหลัก = เหมืองโต แต่เหมืองไม่ส่งพลังกลับไปมาก)
- **ทำไมต้องขุด:** รสชาติเก่าที่ฝังอยู่คือ "ความทรงจำของอาณาจักร" ถ้าปล่อยไว้ รากของ The Hunger จะกินหมด · การขุดคือการเก็บความทรงจำคืนก่อนมันถูกกิน
- **ไม่ขัดกับตอนจบ:** หน้าสุดท้ายของตำรายังอยู่ในมงกุฎ (เหมืองไม่มีทางลัดไปปลดคุณยาย) · ใต้เหมืองเป็นแค่ราก ไม่ใช่ตัว The Hunger

## 4. ตัวละครในเหมือง
- **Ruby** หัวหน้าเหมือง ถือแผนที่ พูดตอนเจอของ/ชั้นใหม่ ("This layer is older than Grandma!")
- **หัวหน้าคนงาน "Pip"** โมจิถั่วแดงตัวเล็กที่ถูกแช่แข็งนานที่สุดใน Frozen Pantry เคยเป็นคนงานเหมืองจริง ๆ ก่อนถูกสาป จำทางเก่าได้ลาง ๆ · ยิ่งลึกยิ่งจำได้มากขึ้น (ปมเล็กของเหมือง: เขาเป็นคนปิดเหมืองวันคำสาปเริ่ม)
- **คนงานโมจิ** แต่ละตัวมีรสต่างกัน (ช็อก มัทฉะ สตรอว์ ฯลฯ) = ตัวละครเล็ก ๆ ที่สะสมได้ ไม่มีพลังต่อสู้
- **Taro (ไม่บังคับ)** นักสำรวจแผนที่ มาเยี่ยมทุก 10 ชั้น ให้เควสต์เล็ก ๆ "หาเส้นทางเก่า"

## 5. ของที่เจอ (ผูกเรื่อง + ไม่กระทบเกมหลัก)
- **ฟอสซิลขนม** ครบชุด = หน้าใหม่ใน **Memory Book** (ระบบเดิม) เล่าเรื่องยุคนั้น + ของแต่ง
- **บันทึก/จดหมาย** อ่านได้ในหน้า "Mine Journal" = เนื้อเรื่องเสริม
- **หีบเสบียงเก่า** = สกุลเงินจำนวนน้อย มีเพดานต่อวัน
- **เมล็ดลืมตา** (ชั้นราก) = ของแต่งต้นไม้/ตกแต่งหน้า Lobby

## 6. คำถามให้เจ้าของเลือก
1. ชื่อเหมือง: **The Sweetstone Mine** หรือ **Grandma's Deep Pantry** หรือชื่ออื่น
2. ปมของ Pip (เป็นคนปิดเหมืองวันคำสาป) — เอาไหม
3. บอสรายสัปดาห์ปลายราก — เอาเลย หรือรอหลังเปิดระบบขุดก่อน
