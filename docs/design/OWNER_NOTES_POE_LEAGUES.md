## 1. League จาก PoE

### Legion — มี 2 แบบ
**แบบ 5 Way (ยืนในวง)**
- มีวงให้ยืน มอนเกิดรอบตัว
- กำจัดมอนเพื่อสะสมรางวัล แล้วรางวัลระเบิดออกมาตอนจบ
- ยิ่งกำจัดได้มาก รางวัลยิ่งดี
- มีบอสสุ่มโผล่ออกมา

**แบบธรรมดา (Monolith)**
- เดินไปหา Monolith → มอนออกมาแข็งเป็นเสา ๆ (แช่แข็ง)
- ผู้เล่นเดินผ่าน/กดปุ่ม → มอนตื่นแล้วโจมตีผู้เล่น
- มีเวลาจำกัด ถ้าฆ่าไม่ทัน มอนหายไปพร้อมรางวัล

### Ritual
- สปอตไลต์ตรงกลาง รอบข้างมืด · พิธีกรรมอยู่กลางวง
- มอนบุกเข้ามา + มีภัยพิบัติ (disaster)
- ยืนในวง กำจัดไปเรื่อย ๆ แล้วรางวัลจะตกออกมา

### Bestiary → อัปเกรด Codex
- ใช้ Codex อัปเกรด · เก็บวิญญาณ (keep soul)

### Harbinger → มอนเกิดเป็นฝูง
- มีพื้นที่ที่มอนเกิด แล้วพุ่งเข้าหาผู้เล่น

### Metamorph → ผสมอวัยวะ
- ได้อวัยวะหลังฆ่า Elite / Boss / Event / Miniboss → ผสมเป็น Metamorph

### Blight (เปลี่ยนภารกิจ Nectar)
- เปลี่ยน Nectar ให้เป็นแบบ Blight
- ไม่มีการสร้างป้อม
- ศัตรูเกิดมาตามหลายเส้นทาง (Branches)
- แค่ป้องกันดอก Nectar

### Breach (ต่อยอด Capture zone)
- ยึดโซน → อัปเกรดเป็น Breach
- ยืนในวง → วงจะอยู่ได้ต้องฆ่ามอน
- ตอนจบวงหดกลับเข้ากลาง แล้วรางวัลระเบิดออกมา

## 2. ตีบวกและคราฟต์อุปกรณ์

### Reforge → ใช้สกุลเงินมากขึ้น
- mod แต่ละบรรทัดใช้สกุลเงินต่างกัน (ภาพร่าง: 4 บรรทัด แต่ละบรรทัดมีไอคอนสกุลเงินของตัวเอง)
- อัปเกรดแต่ละบรรทัดก็ใช้สกุลเงินต่างกัน
- **การลบ mod ใช้สกุลเงินเดียวกันทุกบรรทัด**

### Enchant
- ย้าย enchant 1 mod ไปใส่อุปกรณ์อีกชิ้น โดยใช้สกุลเงินเฉพาะ

## 3. Temple / Dig / Relic

### Dig → Temple
- กลายเป็นเกมในเกม
- จาก Minesweeper → Idle game
- เชื่อมเป็นระบบนิเวศ (ecosystem) กับเกมหลัก

### Temple Weaving → ตอนนี้มี 3 แกนอัปเกรดแรงก์
- ให้มีการตัดสินใจเลือก
- ให้มีได้-เสีย (up-side / down-side) มากขึ้น
- เอาของพิเศษออก

### Relic ถาวร
- ใช้ของบางอย่างเพื่อรับ Relic หรืออัปเกรด Relic

## 4. มอนสเตอร์และบอส

### Monster upgrade
- ความหลากหลาย · ฝูง · Mod · ขนาด · แอนิเมชัน
- สกิล 3 แบบ: Buff / Defense / Attack

### Event Monster
- ฆ่าแล้วได้รางวัล
- ยิ่งเล่นนานยิ่งแข็งแกร่ง รางวัลยิ่งมาก

### Boss
- รูปแบบการโจมตี · ฟื้นเลือด (Regen) · วัตถุในฉาก
- สกิลใหญ่ · ลูกน้อง · โต้ตอบกับฉาก

### Raid Boss
- มีแค่หัวข้อ ยังไม่มีรายละเอียด

## 5. รางวัล

### Wheel Bonus
- เพิ่มรางวัลเมื่อหมุนวงล้อซ้ำ (double wheel again)

## 6. การ์ดเลือกตอนเลเวลอัป

### Level picked → เทมเพลตการ์ดต่างกันตามประเภท
- การ์ด Relic / Normal / Mutation ตอนนี้ต่างกันแค่สี → ต้องทำให้ภาพต่างกันมากกว่านี้

## ตัดไปก่อน
- Talent subclass (ผสมสกิลข้ามตัวละคร)

# แผนทำ League missions (เจ้าของอนุมัติ 11 พ.ย. 2026)

## หลักที่ตกลงแล้ว
- ผู้เล่นเล็งเองไม่ได้ (ยิงอัตโนมัติใส่ตัวใกล้สุด) → ทุกภารกิจตัดสินใจด้วย **การเดิน** เท่านั้น
- กระจายไปทุก Chapter ตาม lore · แต่ละด่านเจอภารกิจไม่ซ้ำกัน
- Chapter 1 (ต้นเกมห้ามเพิ่มภาระ): เล่นครั้งแรก = **แบบเบา** (สั้น แพ้ไม่เสียอะไร ไม่มีบอสสุ่ม) · **แบบเต็ม** = เล่นซ้ำ / Delve / หลังจบ Chapter 2 · C1-1 โผล่หลังจบบทสอนเท่านั้น
- ชื่อทั้งหมดเจ้าของโอเค
