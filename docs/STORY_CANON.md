สถานะ: ร่าง 23 ต.ค. 2026 · รอเจ้าของอนุมัติ · เมื่ออนุมัติ ไฟล์นี้คือ **แหล่งเดียว** ของเนื้อเรื่อง (แทนส่วนเรื่องใน `docs/LORE.md`)

## 1. เรื่องในหนึ่งย่อหน้า

นานมาแล้ว **ผู้ปลูกคนแรก (The First Planter)** ปลูก **เมล็ดแรก** ที่ให้กำเนิดทุกรสชาติใน Mochitopia เขากลัวว่าสักวันจะมีใครหิว จึงสวม **มงกุฎแห่งรส (Flavor Crown)** ไว้บนต้นไม้ต้นแรก ให้มันดึงรสชาติมาเลี้ยงโลกตลอดไป แต่มงกุฎไม่รู้จักคำว่าพอ ความอยากของมันโตขึ้นจนกลายเป็น **The Great Hunger** — ความหิวที่กลืนรสชาติ ความทรงจำ และความอยากมีชีวิตของทุกคน
**Strawberry** ตกลงไปใต้ตู้กับข้าว เจอ **Ruby** ผู้เก็บตำราสูตรอาหารที่เสียรสชาติของตัวเองไป ทั้งคู่ไต่จากใต้ครัว ผ่านสวน ไปจนถึงต้นไม้ต้นแรก เพื่อเอารสชาติของโลกคืน

## 2. กฎของโลก (ต้องตรงกันทุกที่)

- ชาวโมจิเกิดจาก **Mochi Core** = หัวใจที่เก็บรส ความทรงจำ และนิสัย
- **ตื่น (Awaken)** = Core กล้าเผชิญความกลัวเพื่อปกป้องใครสักคน → ได้ร่างนักสู้ (ฮีโร่ที่เราเล่น) · ร่างโมจิกลมกับร่างนักสู้คือคนเดียวกัน
- คนที่ **ถูกกินรสชาติไป ตื่นไม่ได้** (Ruby เป็นแบบนี้)
- The Great Hunger **ฆ่าไม่ตาย** เพราะความหิวเป็นส่วนหนึ่งของการมีชีวิต ทำได้แค่ทำให้ "อิ่มแล้วหลับ" → เหตุผลของ Endgame
- **Battle Recipes** = ตำราต่อสู้ที่คุณยายของ Ruby เขียนไว้ สอนฮีโร่ให้สู้ได้หลายแบบ (= Build Path) · Ruby ถือได้ทีละสูตร จึงเลือกใหม่ทุกชั้น (= เลือก Build ทุกด่าน)

**ฮีโร่ที่มาร่วม** (ตรงกับ `CORE_UNLOCK_STAGE` / `HERO_INTROS`)

## 4. เรื่องรายด่าน

### Chapter 1 — ใต้ครัว: "รสชาติถูกขโมยไปไหน"
| ด่าน | เกิดอะไรขึ้น | Ruby ได้อะไรคืน |
|---|---|---|
| C1-1 รังมดเปรี้ยว | Strawberry ตกลงรอยแยก เจอ Ruby ซ่อนอยู่ ราชินีมดยอมรับใช้ The Hunger เพื่อแลกให้ไข่ปลอดภัย | ชื่อตัวเอง + ว่าเคยเป็นผู้เก็บตำรา |
| C1-2 ท่อเน่า | ตามขวดแยมของคุณยายที่ตกลงท่อ · ในขวดมี **Battle Recipes** → เริ่มเลือก Build ได้ | ความทรงจำครัวของคุณยาย |
| C1-3 ห้องเครื่องพริก | เครื่องจักรเผารสชาติที่ถูกขโมยเป็นเชื้อเพลิง · **Mint** มาร่วม | กลิ่นแยมของตัวเอง |
| C1-4 คุกน้ำตาล | ปลดวิญญาณรสหวานที่ถูกแช่แข็ง · เสียงหนึ่งคือ **คุณยาย** → วิญญาณคุณยายเข้าไปพักในอัญมณีของ Ruby | คุณยายยังอยู่ |
| C1-5 เตาอบมงกุฎ | สู้กับ **ปากของ The Hunger** ที่กินรสอยู่ในเตา · ชนะ แต่มันมุดลงรากหนีเข้าสวน ("I will wake again…") | รสชาติแท้ของ Ruby ยังอยู่ในตัวมัน |

### Chapter 2 — สวนหมัก: "The Hunger กำลังโตเป็นร่าง"
The Hunger หนีลงราก แล้วดูดรสจากสวนมาปั้นร่างใหม่ ผู้พิทักษ์สวนทุกตัวถูกบังคับให้รับใช้ (ไม่ใช่คนเลว)
| ด่าน | เกิดอะไรขึ้น |
|---|---|
| C2-1 เรือนยอดหมัก | ดอกตูม (ลูกของแม่ราก) พยายามปกป้องสวนแต่ถูกหมักจนคลั่ง ("Mother… I tried…") · **Cocoa** มาร่วม |
| C2-2 หนองเห็ดรา | สปอร์ของ The Hunger กระจายไปทั่ว อัญมณีของ Ruby หนักขึ้น |
| C2-3 รังผึ้งน้ำหวาน | ผึ้งที่เคยทำน้ำผึ้งให้ทั้งอาณาจักร ถูกบังคับให้เฝ้าน้ำหวานให้ The Hunger · **Taro** มาร่วม |
| C2-4 เรือนกระจก 4 ฤดู | เวลาติดค้างเหมือนสูตรที่ค้างอยู่ขั้นเดียว · Ruby จำได้ว่าคุณยายเคยเขียนถึงสวนนี้ |
| C2-5 บัลลังก์ราก | **แม่รากตัวจริง** คือหัวใจของร่างใหม่ · ก่อนล้มบอกว่า "คนที่ปลูกฉันรออยู่…" → ชี้ไปที่ผู้ปลูกคนแรก |

### Chapter 3 — ทุ่งเมล็ด: "จุดเริ่มต้นของทุกอย่าง"
ทางรากพาไปถึงทุ่งเมล็ดแรกของโลก ที่ที่ The Hunger เกิด
| ด่าน | เกิดอะไรขึ้น |
|---|---|
| C3-1 ทุ่งเมล็ดไหม้ | ทุ่งว่างเปล่าไม่เหลือแม้แต่เศษ · ยักษ์เกี่ยวข้าวเกี่ยวทุกอย่างให้ The Hunger · **Yuzu** มาร่วม |
| C3-2 สวนกลวง | ดอกไม้กลวงที่ไม่มีไส้ — สิ่งที่ถูกกินจนเหลือแต่เปลือก "สิ่งที่เห็นอาจไม่ใช่ของจริง" |
| C3-3 ซากเรือนกระจกแก้ว | คนสวนแก้วซ่อนความลับของผู้ปลูก · กระจกสะท้อนความกลัว · (**Sesame** มาร่วมตามแผน) |
| C3-4 ห้องเก็บเมล็ด | ผู้เฝ้าเมล็ดยอมยกเมล็ดรสแรกให้ "เอาไปปลูกให้ดี…" · Ruby ได้ยินรสของตัวเองเรียกอยู่ข้างหน้า |
| C3-5 บัลลังก์เมล็ดแรก | **ผู้ปลูกคนแรก** สวมมงกุฎ · ดูตอนจบด้านล่าง |

### ตอนจบ (หลังชนะ C3-5)
1. ผู้ปลูกรู้ตัวว่ามงกุฎไม่ได้เลี้ยงโลก แต่กินโลก ("Every flavor… maybe that is enough.") จึง **ถอดมงกุฎ**
2. มงกุฎแตก รสชาติที่ถูกขโมยไหลกลับคืนทุกที่ ทุ่งกลับมาเขียว
3. คุณยายในอัญมณีมอบ **หน้าสุดท้ายของตำรา** ให้ Ruby — สูตร "ทุกรสอยู่ด้วยกันได้ ไม่มีรสไหนต้องกินรสอื่น"
4. รสแยมทับทิมกลับเข้าตัว Ruby → **Ruby ตื่น** เป็นร่างนักสู้ครั้งแรก (ทางเลือก: ปลดเป็นฮีโร่ใหม่ในอนาคต)
5. The Great Hunger ไม่ตาย มันอิ่มแล้วหลับลงใต้รากลึก · ผู้ปลูกอยู่เฝ้าต้นไม้ต่อ คราวนี้แบ่งรสแทนการเก็บ

### Endgame — Delve / Pinnacle
- ทุกคืน The Hunger ขยับตัวใต้ราก ฮีโร่จึงต้องลงไปใน **Mochi Delve** (ถ้ำรากลึก) เพื่อให้มันหลับต่อ · ยิ่งลึก ความหิวยิ่งแรง รางวัลยิ่งดี (ตรงกฎเหล็ก)
- **Pinnacle** = ร่างแท้ของ The Hunger (ขากรรไกร/ลิ้น) ที่ตื่นขึ้นเป็นครั้งคราว
- ไม่มีชัยชนะถาวร — ฮีโร่คือคนเฝ้าครัวยามค่ำ ("ไม่ใช่การพิชิต แต่คือการดูแล")
