แนวคิดเจ้าของ: **คนในอาณาจักรถูกสาปให้เป็นโมจิมานานแล้ว · ผู้เล่นได้ของบางอย่างจึงกลับเป็นคน · ออกเดินทางปลดคำสาปให้ทั้งอาณาจักร**

## 1. เรื่องในหนึ่งย่อหน้า

อาณาจักร **Mochitopia** เคยเป็นเมืองของคน วันหนึ่งเกิดความอดอยาก **ผู้ปลูกคนแรก (The First Planter)** จึงสวม **มงกุฎแห่งรส** ไว้บนต้นไม้ต้นแรกแล้วอธิษฐานว่า *"ขออย่าให้ใครต้องหิวอีกเลย"* มงกุฎทำตามแบบผิด ๆ — มันสาปทุกคนให้กลายเป็น **โมจิ** ขนมที่ไม่ต้องกินอะไร จะได้ไม่มีใครหิว แล้วมงกุฎก็เริ่มกินแทน: กิน **รสชาติ** ของทุกคน ซึ่งก็คือความทรงจำและตัวตน ความอยากของมงกุฎโตขึ้นเรื่อย ๆ จนกลายเป็น **The Great Hunger**
หลายร้อยปีต่อมา โมจิสตรอว์เบอร์รีตัวหนึ่งตกลงรอยแยกใต้ตู้กับข้าว ไปเจอ **เมล็ดหัวใจ (Heart Seed)** เมล็ดสุดท้ายที่ยังจำได้ว่าทุกคนเคยเป็นใคร เธอกลับร่างเป็นคน — **Strawberry** — และออกเดินทางกับ **Ruby** เพื่อถอดมงกุฎและปลดคำสาปให้ทั้งอาณาจักร

## 2. กฎของโลก (ต้องตรงกันทุกที่)

- **ทุกคนใน Mochitopia คือคนที่ถูกสาปเป็นโมจิ** · ยังพูดได้ มีนิสัยเดิม แต่จำอดีตได้เลือนลาง
- **คำสาปกินรสชาติ:** ยิ่งถูก The Hunger กินรสไปมาก ยิ่งลืมตัวเอง · ถูกกินหมด = กลายเป็นโมจิจืดที่ไม่มีใจ (= ศัตรูทั่วไปในด่านบางตัว)
- **เมล็ดหัวใจ** จำรูปร่างจริงของทุกคนได้ · แตะใครด้วยพลังเมล็ด = คนนั้นกลับเป็นคนชั่วคราว
  - พลังเมล็ดโตขึ้นทุกครั้งที่ชนะบอส (บอสคืนรสที่ขโมยไป) → ปลดคำสาปเพื่อนได้ทีละคน (= ปลดฮีโร่ใหม่)
  - **อาวุธ Strawberry = Heart Seed Gun** (ชื่อนี้มีในเกมอยู่แล้ว) ยิงเมล็ดที่งอกจากเมล็ดหัวใจ
- **ฮีโร่ล้มในด่าน** = คำสาปกลับมาชั่วคราว ร่างคืนเป็นโมจิ → ต้องเริ่มด่านใหม่ (อธิบายว่าทำไมทุกด่านเริ่มจากศูนย์)
- **Battle Recipes** = ตำราต่อสู้ของคุณยาย ใช้พลังเมล็ดได้หลายแบบ (= Build) · ถือได้ทีละสูตร (= เลือกใหม่ทุกด่าน)
- The Great Hunger **ฆ่าไม่ตาย** (มันคือความหิว) ทำได้แค่ทำให้หลับ → เหตุผลของ Endgame

## 4. เรื่องรายด่าน

### Chapter 1 — ใต้ครัว: "เมล็ดหัวใจ"
| ด่าน | เกิดอะไรขึ้น |
|---|---|
| บทสอน | โมจิสตรอว์เบอร์รีตกรอยแยก เจอเมล็ดหัวใจ → **กลับร่างเป็นคน** · Ruby ออกมาจากที่ซ่อน |
| C1-1 รังมดเปรี้ยว | ราชินีมดยอมรับใช้ The Hunger แลกให้ไข่ปลอดภัย · ชนะ → พลังเมล็ดโตครั้งแรก |
| C1-2 ท่อเน่า | เจอขวดแยมของคุณยาย ในขวดมี **Battle Recipes** → เลือก Build ได้ |
| C1-3 ห้องเครื่องพริก | เครื่องจักรเผารสชาติของชาวเมือง · **ปลดคำสาป Mint** |
| C1-4 คุกน้ำตาล | ปลดโมจิที่ถูกแช่แข็ง · เจอ **คุณยาย** ยังเป็นโมจิ พลังเมล็ดยังไม่พอปลดเธอ · เธอบอกว่าหน้าสุดท้ายของตำราอยู่ที่ต้นไม้ต้นแรก |
| C1-5 เตาอบมงกุฎ | สู้กับ **ปากของ The Hunger** · ชนะ แต่มันมุดรากหนี ("I will wake again…") |

### Chapter 2 — สวนหมัก: "ร่างใหม่ของความหิว"
The Hunger หนีลงราก ดูดรสจากสวนมาปั้นร่างใหม่ · ผู้พิทักษ์สวนคือชาวเมืองที่ถูกกินรสจนลืมตัว
| ด่าน | เกิดอะไรขึ้น |
|---|---|
| C2-1 เรือนยอดหมัก | ดอกตูม (ลูกของแม่ราก) พยายามปกป้องสวนแต่คลั่ง ("Mother… I tried…") · **ปลดคำสาป Cocoa** |
| C2-2 หนองเห็ดรา | สปอร์ของ The Hunger กินความทรงจำ · Strawberry เริ่มจำบ้านเก่าได้ |
| C2-3 รังผึ้งน้ำหวาน | ผึ้งถูกบังคับให้เก็บน้ำหวานให้ The Hunger · **ปลดคำสาป Taro** |
| C2-4 เรือนกระจก 4 ฤดู | เวลาติดค้างตั้งแต่วันที่คำสาปเริ่ม |
| C2-5 บัลลังก์ราก | แม่รากคือหัวใจของร่างใหม่ · ก่อนล้ม "คนที่ปลูกฉันรออยู่…" → ชี้ไปที่ผู้ปลูก |

### Chapter 3 — ทุ่งเมล็ด: "ต้นไม้ต้นแรก"
| ด่าน | เกิดอะไรขึ้น |
|---|---|
| C3-1 ทุ่งเมล็ดไหม้ | ทุ่งว่างเปล่า ยักษ์เกี่ยวข้าวเกี่ยวทุกอย่างให้ The Hunger · **ปลดคำสาป Yuzu** |
| C3-2 สวนกลวง | ดอกไม้กลวงที่ถูกกินจนเหลือแต่เปลือก |
| C3-3 ซากเรือนกระจกแก้ว | กระจกเก็บภาพอาณาจักรก่อนถูกสาป · Strawberry เห็นตัวเองตอนเป็นคน · (**ปลดคำสาป Sesame** ตามแผน) |
| C3-4 ห้องเก็บเมล็ด | ผู้เฝ้าเมล็ดเห็นเมล็ดหัวใจ ยอมเปิดทาง "เอาไปปลูกให้ดี…" |
| C3-5 บัลลังก์เมล็ดแรก | **ผู้ปลูกคนแรก** สวมมงกุฎ · ดูตอนจบด้านล่าง |

### ตอนจบ (หลังชนะ C3-5)
1. ผู้ปลูกเห็นว่าคำอธิษฐานของเขาทำให้ทุกคนลืมตัวเอง ("Every flavor… maybe that is enough.") → **ถอดมงกุฎ**
2. Strawberry ปลูก **เมล็ดหัวใจ** ลงตรงที่ต้นไม้ต้นแรก · ต้นใหม่งอก ส่งรสชาติคืนทุกคน
3. **คำสาปแตกทั้งอาณาจักร** โมจิทุกตัวกลับเป็นคน · คุณยายกลับเป็นคน · ผู้ปลูกเองก็กลับเป็นคนแก่ธรรมดา
4. **Ruby ยังเป็นภูตแยม** (เธอไม่เคยถูกสาป) · กลายเป็นผู้เฝ้าต้นไม้ใหม่และตำราต่อจากคุณยาย
5. The Great Hunger ไม่ตาย มันหลับลงใต้รากลึก

### Endgame — Delve / Pinnacle
- ใต้รากยังมีชาวเมืองที่ถูกกินรสลึกเกินกว่าต้นไม้จะช่วยได้ และ The Hunger ขยับตัวทุกคืน → ฮีโร่ลงไปใน **Mochi Delve** เพื่อช่วยคนที่เหลือและให้มันหลับต่อ · ยิ่งลึกยิ่งยาก รางวัลยิ่งดี (กฎเหล็ก)
- **Pinnacle** = ร่างแท้ของ The Hunger ที่ตื่นขึ้นเป็นครั้งคราว

## 6. คำถามให้เจ้าของเลือก
1. ชื่อของที่ได้มา **Heart Seed (เมล็ดหัวใจ)** โอเคไหม (ผูกกับปืน Heart Seed Gun ที่มีอยู่แล้ว)
2. Ruby เป็น **ภูตแยมที่ไม่เคยเป็นคน** โอเคไหม หรืออยากให้เธอเป็นคนถูกสาปด้วย (แล้วตอนจบกลับเป็นคนในเรื่องแต่ไม่เป็นฮีโร่)
3. ฮีโร่ล้ม = **ร่างคืนเป็นโมจิ** เป็นภาพตอนแพ้ (ต้องมีภาพโมจิของฮีโร่ทุกตัว ซึ่งมีอยู่ส่วนหนึ่งแล้ว) เอาไหม
