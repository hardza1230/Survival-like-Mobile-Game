# 03 — ศัตรู Chapter 3 · batch `ch3_enemies`

## เรื่อง
Chapter 3 "Throne of the First Seed" = ดินแดนที่ Crown Seed ต้นแรกงอก · ความหิวกลายเป็น **ผู้พิทักษ์เมล็ด (Seedbound)** — ขนม/ผลไม้ที่ถูกรากทองม่วงกลืน
ลักษณะร่วม: ตัวขนมโมจิ/ผลไม้ + **รากทองเรืองม่วงพันตัว** + ดวงตาเรืองม่วง · โทนดิน-ขี้เถ้า + จุดทอง/ม่วง (#b98cff, #ffd166)
ใช้ชุดเดียวทั้ง 5 ด่านของ Chapter 3

## สเปก
- **Sprite sheet 4 เฟรม (เดิน/ขยับวน) · เฟรมละ 128×128 · แผ่น 512×128 · PNG โปร่งใส**
- ถ้าทำชีตไม่ได้ ส่งภาพนิ่ง 128×128 ได้ (ชื่อเดียวกัน) — เกมจะเด้งเจลลี่แทน
- หันหน้า **ขวา** (เกมพลิกเอง) · ground line กลางล่าง · ไม่มีเงา (เกมวาดเอง)
- ขนาดรูปทรงภายในเฟรม: basic ~60% · fast ~50% · shooter ~60% · bomber ~60% · tank ~85%

| key | บทบาทในเกม | ดีไซน์ |
|---|---|---|
| `c3_e_basic` | เดินเข้าหาธรรมดา | ก้อนโมจิขี้เถ้ามีหน่อรากงอกบนหัว เดินเตาะแตะ |
| `c3_e_fast` | วิ่งเร็ว/พุ่ง | เมล็ดทานตะวันมีขาเรียว วิ่งก้มตัว หางไฟทองเล็ก ๆ |
| `c3_e_shooter` | ยิงระยะไกล | ลูกแอปเปิ้ลกลวงมีปากปืนเป็นก้าน ยิงเมล็ด (ท่ายิงอยู่ในเฟรม 3) |
| `c3_e_bomber` | ระเบิดตอนตาย | ฝักเมล็ดพองบวม ผิวร้าวเรืองส้ม-ม่วง |
| `c3_e_tank` | ช้า ถึก | อัศวินลูกโอ๊กชุดเกราะเปลือกไม้ รากทองเป็นโล่ |

## ฝั่งโค้ด
- key ตรงกับของชั่วคราวใน `Boot.buildChapter3Placeholders()` → ใส่ใน `ASSET_SHEETS` (มี `frame:128` + `anim:{frames:4,rate:8}`) แล้วของชั่วคราวข้ามเอง
- ต้องจูน `baseScale`/`setCircle` ของ c3_e_* ใน spawnEnemy ให้ขนาดบนจอเท่า e_* เดิม (~40–70px)
