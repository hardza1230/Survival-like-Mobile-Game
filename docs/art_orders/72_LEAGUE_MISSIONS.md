## ระบบในเกม (อ้างอิง)
- ภารกิจเกิดกลางสนามระหว่างสู้ (มอนเยอะ ตัวละครสูงบนจอ ~100px) → ของทุกชิ้นต้อง **อ่านออกทันทีที่ขนาดบนจอ** และไม่กลืนกับพื้น
- ผู้เล่นเล็งเองไม่ได้ (ยิงอัตโนมัติ) → ทุกภารกิจเล่นด้วย **การเดินไปยืนใกล้ของ** ของที่ต้องเดินไปหาจึงต้องเด่น
- Lore: The Great Hunger (มงกุฎแห่งรสที่หิวไม่รู้จบ) กินรสชาติของชาวเมืองที่ถูกสาปเป็นโมจิ · ภารกิจเหล่านี้คือร่องรอยของมัน (ปาก ราก ทูต) และของคุณยาย (หม้อ ตำรา)
- ฉาก: Frozen Pantry = คุกน้ำตาล (C1-4 โทนฟ้าน้ำแข็ง) · Mouth = ท่อเน่า (C1-2 โทนน้ำเงินเทา) · Pot = ห้องเครื่องพริก (C1-3 โทนส้มแดง) · Herald = รังมด (C1-1 โทนน้ำตาลเขียว) · Roots = รังผึ้ง (C2-3 โทนเหลืองอำพัน) · ทุกอันโผล่ใน Delve ได้ด้วย
- ของที่ "ใช้แล้ว/ดับ" โค้ดทำให้จาง (alpha) เอง · สีที่โค้ดย้อม (tint) ให้วาดโทนขาว/กลาง

## ข้อห้าม
- ห้ามตัวหนังสือ/ตัวเลข/สัญลักษณ์ UI ในภาพ (การ์ดสูตรต้องว่างตรงกลาง)
- ห้ามน่ากลัว/เลือด · ปาก ราก ทูต ต้องเป็นสไตล์มอนขนมน่ารักแบบเดียวกับศัตรูเดิม
- ห้ามสีแดงสด/ม่วงเรืองแสงจัดเป็นสีหลักของของบนพื้น (ซ้ำกับกระสุนศัตรู) — ปาก/รากใช้ม่วงเข้มอมชมพู ไม่เรืองจ้า
- ของบนพื้น (mouth rim, gate) ต้องโปร่งตรงกลางพอให้เห็นตัวละครที่ยืนบน
- ห้ามเงาทอดยาว (โค้ดวาดเงาเอง) · ทูต (hh_herald) เป็นศัตรู → ไม่ต้องมีเงาในภาพ
- อนิเมชัน loop: ทรงหลักคงที่ทุกเฟรม ขยับแค่รายละเอียด (ไม่ให้ภาพ "เดือด" แบบใบสั่ง 34)

## โน้ตฝั่งโค้ด
- pack: `scripts/pack-league72.py` → `assets/art/league72/*.webp` · คีย์เข้า `ASSET_FX` (sheet) / `ASSET_IMAGES` · โหลด **stage-lazy** ตามด่านที่มีภารกิจ (C1-1 hh_* · C1-2 hm_* · C1-3 gp_* · C1-4 fp_* · C2-3 cr_*) + ทุกด่านใน Delve · ไอคอนสกุลเงิน F โหลดกลุ่มเมนูเดียวกับ `currency_twist_cream`

- Frozen Pantry (`fpSetup`/`fpOpen`/`fpWake`/`fpVanish`): `S.jar` 🫙 → `fp_jar` · รูปปั้น `q.t` 🍡/🗿 → `fp_statues` เฟรม 0/1 (setTint เทาตอนแช่แข็ง → clearTint ตอนสีเต็ม) · `fp_shatter` (ADD blend) ตอน `fpWake` และ `fpVanish`
- Hunger's Mouth (`hmSetup`/`hmTick`/`hmBurst`): `S.core` 👄 → `hm_mouth_core` anim · `S.ring` (circle) → `hm_mouth_rim` scale ตาม `S.R` (เก็บวงกราฟิกเป็น fill จาง) · `hm_snap_burst` ตอน `hmBurst`
- Creeping Roots (`crLane`/`crDraw`/`crTick`): `L.t` 🌱 → `cr_root_mother` เฟรม 0 → 1 เมื่อ `!L.open` · เส้น `S.laneG` → TileSprite `cr_root_vine` ต่อ segment (หมุนตามมุม) เก็บเส้นกราฟิกเป็น fallback
- Hunger Herald (`hhSpawn`/`hhTick`): ศัตรู Herald (elite) → overlay sprite `hh_herald` ตามตัว (ซ่อน sprite เดิม หรือแทน texture) · `G.t` 🌀 → `hh_gate` anim

- สกุลเงิน: `CURRENCY` asset `currency_honey_drop` / `currency_recipe_ink` (คีย์ตั้งไว้แล้ว ตอนนี้ fallback `prize_currency` + tint) · Berry Jam → `currency_wild_jam`, Star Sugar → `currency_wish_candy` (ของเดิม ผูกได้ทันที)
