## ระบบในเกม (อ้างอิง)
- **Lure the Crown Root (C2-5 · v8.2.81):**
  - หัวรากมุดดินไล่ผู้เล่น แล้วล็อกจุด มีรอยแตกเตือน 0.66–0.9 วิ จากนั้นรากพุ่งขึ้นจากพื้น
  - ล่อให้พุ่งชนหินสมอ 3 ก้อน ก้อนที่ 2 แตก = รากแยกเป็น 2 หัว
  - ก้อนสุดท้ายแตก = หัวรากมงกุฎติดพื้น 8 วิ ให้รุมตี
  - ตอนนี้ทั้งหมดเป็นวงรี/เส้นที่โค้ดวาด และหัวรากใช้รูปมอน tank ย้อมม่วง
- **Clear the Fog (C2 · v8.2.80):** จอมืดหมด เห็นแค่แสงรอบตัว รัศมี 150–200px
  - ขอบแสงหยักและขยับได้ มี "กรงเล็บความมืด" 7 อันยื่นเข้าหาตัว
  - ตอนนี้หมอกเป็นสีทึบ และกรงเล็บเป็นวงไล่สีที่โค้ดวาด
- **Hunger Crack (v8.2.48):** หลุมสุดท้ายปล่อย **Abyss Brute** ตัวถึกปิดท้าย · ตอนนี้ใช้รูปมอน tank ขยาย 1.4 เท่าแล้วย้อมม่วง
- **Seed Rift เหตุการณ์สุ่ม (v8.2.83):** รอยแยกเปิดกลางเวฟทันที ไม่มีอะไรเตือนก่อน → ขอภาพเตือน 1.5 วิก่อนเปิด
- **ป้ายผลการเล่น:** "Perfect dodge!" (หลบรากทัน) และ "Root combo ×N" (รากฆ่าหลายตัว) · ตอนนี้เป็นตัวหนังสือลอยเฉย ๆ → ขอป้ายพื้นหลัง โดยโค้ดเขียนตัวหนังสือ/ตัวเลขทับเอง

## ข้อห้าม
- ห้ามตัวหนังสือ ตัวเลข สัญลักษณ์ UI ในภาพ (ป้าย E ห้ามมีตัวหนังสือ)
- เฟรมขนาดเท่ากัน เรียงซ้าย→ขวา บน→ล่าง ไม่มีช่องว่าง · loop ต้องต่อเฟรมสุดท้ายกลับเฟรมแรกได้เนียน
- พื้นดำ #000 สนิทในไฟล์ที่ระบุ (โค้ดแปลงความสว่างเป็นความโปร่ง) · ไฟล์โปร่งใสต้องเป็น alpha จริง
- หัวรากมงกุฎกับ Abyss Brute ต้องน่ากลัวแบบน่ารัก (โลกขนม) ไม่ใช่สยองเลือด · ห้ามสว่างกว่าตัวฮีโร่
- `fg94_fog_tile` ห้ามเห็นรอยต่อตอนปูซ้ำ · ห้ามมีจุดสว่างที่ดูเหมือนของเก็บได้
- `cr94_warn_crack` ต้องอ่านออกว่า "จุดนี้อันตราย" บนพื้น Chapter 2 สีเขียว/น้ำตาล

## โน้ตฝั่งโค้ด
- **A:**
  - `drawCrownRoot` (st burrow/warn/strike) → ใช้ `cr94_burrow` / `cr94_warn_crack` / `cr94_strike` แทนวงรีและเส้น
  - `crownRootStrike` → ตอนชนหินเล่น `cr94_anchor_break`
  - `crownRootFinale` ตอนนี้ใช้ tank ย้อมสี (`e._crownHead`) → ซ่อน sprite เดิมแล้ววาง `cr94_crown_head` ไว้บนตัว · โดนตีเล่น `cr94_crown_hurt` · `crownRootFinTick` ตอนจบเล่น `cr94_crown_burst`
- **B:** ใน `cleanAirV2Fog`:
  - `rt.fill(0x1b2410)` → ปู `fg94_fog_tile`
  - แปรง `cleanAirDarkBrush` → `fg94_dark_claw` (หมุนให้ชี้เข้าหาผู้เล่น)
  - ขอบรู `wob` → erase ด้วย `fg94_lantern_edge`
- **C:** `hungerCrackBrute` ตอนนี้ใช้ `spawnEnemy('tank')` + `setTint` → ลงทะเบียนชีตตามแบบ `ASSET_SHEETS` ของมอน (actions idle/attack/hurt/death)
- **D:** `seedRiftEventStart` → เพิ่มช่วงเตือน 1.5 วิด้วย `sr94_rift_warn` ก่อนเปิดรอยแยกจริง (ไม่เปลี่ยนเวลา 20 วิของเหตุการณ์)
- **E:** `floatText` ของ Perfect dodge / Root combo → วางป้ายไว้หลังตัวหนังสือ
- ทุกไฟล์ stage-lazy ห้ามโหลดตอน boot · เก็บภาพเดิมที่โค้ดวาดไว้เป็น fallback เสมอ
- MANIFEST ต่อแถว: `key`, `file`, `bytes`, `sha256`, `width`, `height`, `frameWidth`, `frameHeight`, `frameCount`, `columns`, `loop`, `anchor`, `background` (`transparent`/`black`) · ป้าย E ระบุกรอบที่ว่างกลางป้าย `textBox` [x,y,w,h] · Abyss Brute ระบุแถวท่า `actions`
