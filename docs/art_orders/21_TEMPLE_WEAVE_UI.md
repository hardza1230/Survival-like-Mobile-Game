## กฎเหล็กของชุดนี้
1. **ห้ามมีตัวหนังสือ ตัวเลข หรือสัญลักษณ์ตัวอักษรใด ๆ ในภาพ** (ไม่มี "Back", "Weave Up", "703", "TIER 1", "No RP", "Locked" ฯลฯ) — โค้ดเขียนเอง
2. ชิ้น UI = **PNG32 พื้นโปร่งใสจริง (alpha)** ไม่ใช่พื้นดำ/ขาว · ไม่มีเงาตกนอกขอบเกิน 12px · ขอบคมไม่มี halo สีพื้น
3. พื้นหลัง = PNG ทึบ **1080×1920** (แนวตั้ง) · ต้องตัดกลางเป็น 16:9 แนวนอนได้โดยของสำคัญไม่หาย (ของตกแต่งหนักอยู่ขอบซ้าย/ขวา/ล่าง, กลางจอโล่งและมืดกว่าเพื่อให้ตัวหนังสืออ่านง่าย)
4. กรอบที่ยืดได้ = **9-slice**: มุมทั้ง 4 วาดลวดลายได้ แต่ **ขอบกลางและพื้นตรงกลางต้องเรียบ/ซ้ำได้** (ยืดแนวนอน 0.6–2.2 เท่าแล้วไม่เพี้ยน) · ระบุค่า slice `[left, top, right, bottom]` เป็น px ใน MANIFEST
5. สไตล์ตามภาพอ้างอิง: วิหารขนมแฟนตาซี โทนม่วงเข้ม `#2a1830` + ทองอุ่น `#e8c27a` + ชมพู `#ff7aa8` · ขอบทองนูนมีแสงสะท้อน · มุมโค้ง · มีดอกไม้ชมพู/ครีมเล็ก ๆ ตามมุม (ไม่บังพื้นที่ข้อความ)
6. ทุกชิ้นวาดที่ **2× ของขนาดบนจอ** ตามตาราง (โค้ดย่อลง)

## MANIFEST.json (ต่อไฟล์)
```json
{ "key": "temple_core_card_sheet", "file": "temple_core_card_sheet.png",
  "width": 1760, "height": 1200, "columns": 1, "rows": 3, "cellWidth": 1760, "cellHeight": 400,
  "background": "transparent", "nineSlice": [180, 90, 380, 90],
  "states": ["core_pink", "flavor_gold", "bond_blue"], "sha256": "..." }
```
- `nineSlice` = ระยะจากขอบ ซ้าย/บน/ขวา/ล่าง ที่ห้ามยืด (px ของไฟล์ต้นฉบับ)
- `states` = ชื่อแต่ละช่องเรียงตามลำดับในชีต (บน→ล่าง หรือ ซ้าย→ขวา)
- ชิ้นที่ไม่ใช่ 9-slice ใส่ `"nineSlice": null`
