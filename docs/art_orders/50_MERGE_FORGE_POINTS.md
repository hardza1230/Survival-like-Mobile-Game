## ระบบในเกม (อ้างอิง)
- **Merge:** เลือกของหลัก 1 ชิ้น + ของช่องเดียวกันระดับเดียวกัน 2 ชิ้น → ของหลักขึ้นระดับ Common → Rare → Epic → Legend · หน้าจอ: การ์ด MAIN + การ์ดวัตถุดิบ 2 ใบ (มี "+" คั่น) → กล่อง RESULT → แถว "เลือกเก็บ 1 mod" → ตารางวัตถุดิบ → ปุ่ม "🔗 Merge → Epic"
- **Forge Points:** ของแต่ละชิ้นมีแต้มตี 🔨 (8/14/20/26 ตามระดับ) · เลือก mod เอง → Add / Swap / ⭐ Star up / Remove · 15% "🍀 Lucky!" ไม่เสียแต้ม
- สีระดับในเกม: Common `#8bd3a0` เขียว · Rare `#ffcf5a` ทอง · Epic `#c9a3ff` ม่วง · Legend `#ff8f3a` ส้ม
