# 13 — บอสเฉพาะ Endgame ชั้น 10 และ 20 (Mochi Delve) · batch `delve_bosses`

ตอนนี้บอสในถ้ำ Delve ยืมบอสจากด่านเนื้อเรื่องมาเพิ่มเลือดเฉย ๆ ใบสั่งนี้คือบอสใหม่ 2 ตัวที่**มีเฉพาะใน endgame**
อ่าน `00_STYLE_GUIDE.md` และกติกาประหยัดโควต้าใน `NEXT_BATCH_REQUEST.md §0` ก่อนเริ่มทุกครั้ง

**สร้างภาพทั้งหมด 3 ครั้ง** (บอสตัวละ 1 แผ่น + ของประกอบรวม 1 แผ่น)

---

## บอส A — ชั้น 10 · "The Jelly Warden" · key `boss_delve10`

ผู้คุมประตูชั้นแรกของ Delve เป็นเจลลี่ใสก้อนยักษ์ มีขนมที่ถูกกลืนลอยอยู่ข้างใน สวมหมวกผู้คุมเรือนจำ
ถือพวงกุญแจลูกอมไว้ในตัวเจลลี่

- **โทนสี:** เขียวมิ้นต์ใส `#7fe0c0` · ชมพู `#ff9bd0` (ขนมข้างใน) · ทอง `#ffd166` (กุญแจ)
- **อารมณ์:** ตลก อ้วนกลม แต่ดูหนักและอันตราย

**กลไกในเกม:** ฝั่งโค้ดจะทำเองจากภาพ
- กระโดดทับ แล้วทิ้งแอ่งเจลลี่ไว้บนพื้น ผู้เล่นที่เดินผ่านจะช้าลง
- พอเลือดเหลือ 50% จะแตกออกเป็นเจลลี่ลูก 3 ก้อน

**ชีตอนิเมชัน** 4×2 = 8 เฟรม · ช่องละ 320×320 · แผ่น 1280×640 · PNG พื้นโปร่งใส
| เฟรม | ท่า |
|---|---|
| 0 | ยืนนิ่ง (idle) |
| 1 | หายใจ (ยุบตัวลง) |
| 2 | ย่อตัวเตรียมกระโดด |
| 3 | ลอยอยู่กลางอากาศ |
| 4 | กระแทกพื้น (ตัวแบน + มีเจลลี่กระเด็น) |
| 5 | โดนตี |
| 6 | คลั่ง (ตัวแดงขึ้น + มีรอยร้าว) |
| 7 | แตกกระจาย (ท่าตาย) |

## บอส B — ชั้น 20 · "Madame Candlewick" · key `boss_delve20`

เชฟเทียนหลอมเหลวในชุดเชฟสูง ตัวทำจากเทียนวันเกิดที่ละลายย้อย บนหัวมีเปลวไฟ 3 ดวงแทนผม
ถือทัพพีที่ข้างในเป็นขี้ผึ้งร้อน

- **โทนสี:** ครีม `#fff1d6` · ส้มไฟ `#ff8a3d` · ม่วงเงา `#4a2a5a`
- **อารมณ์:** สง่า น่ากลัวแบบน่ารัก

**กลไกในเกม:**
- จุดเทียนรอบสนาม เทียนที่ติดไฟจะปล่อยวงไฟออกมาเป็นระยะ ผู้เล่นต้องตีเทียนดับ
- พอเลือดเหลือ 40% จะเป่าไฟทั้งสนามดับ ทั้งจอมืด เห็นแค่รอบตัวผู้เล่นกับรอบเทียน

**ชีตอนิเมชัน** 4×2 = 8 เฟรม · ช่องละ 320×320 · แผ่น 1280×640 · PNG พื้นโปร่งใส
| เฟรม | ท่า |
|---|---|
| 0 | ยืนนิ่ง (idle) |
| 1 | เปลวไฟบนหัวไหว |
| 2 | ยกทัพพีขึ้น |
| 3 | สาดขี้ผึ้ง |
| 4 | ชี้นิ้วจุดเทียน |
| 5 | โดนตี |
| 6 | เป่าไฟให้ดับ (แก้มป่อง) |
| 7 | ละลายลงพื้น (ท่าตาย) |

## แผ่นของประกอบ · 4×2 · ช่องละ 256×256 · แผ่น 1024×512
| ช่อง (แถว,คอลัมน์) | key | สิ่งที่วาด |
|---|---|---|
| 0,0 | `delve10_minijelly` | เจลลี่ลูก (หน้าตาเดียวกับบอส A แต่ตัวเล็ก) |
| 0,1 | `delve10_puddle` | แอ่งเจลลี่บนพื้น มองจากด้านบน |
| 0,2 | `delve10_keyring` | พวงกุญแจลูกอม (ไอคอนรางวัล) |
| 0,3 | `delve10_cage` | กรงเจลลี่ (ของตกแต่งสนาม) |
| 1,0 | `delve20_candle_lit` | เทียนสูงที่ติดไฟอยู่ |
| 1,1 | `delve20_candle_out` | เทียนเดียวกันแต่ไฟดับแล้ว มีควันลอย |
| 1,2 | `delve20_wax_pool` | แอ่งขี้ผึ้งร้อนบนพื้น มองจากด้านบน |
| 1,3 | `delve20_flame_ring` | วงไฟที่ขยายออก มองจากด้านบน (วงบาง ตรงกลางโล่ง) |
