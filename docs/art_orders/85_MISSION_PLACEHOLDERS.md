## ระบบในเกม (อ้างอิง)
- **Frozen Pantry:** เปิดโหลน้ำตาล → เวลาหยุด → กองทัพโมจิแช่แข็งเป็นหมู่ (มี Captain 👑 ต่อหมู่ + Frost General) และ **ลังแช่แข็ง** วางระหว่างหมู่ · ผู้เล่นเดินผ่านเพื่อ "ทาสีพาสเทล" → พอเวลาเดิน ลังที่ทาสีแล้วแตกออกเป็นของ ลังที่ไม่ได้ทาสีแตกหายไป
- **Light the Mirror Path:** เงามืด (Shade) เดินมายืนบังลำแสงระหว่างกระจกกับคริสตัล
- **Hold the Last Light:** ผีเสื้อกลางคืนบินมาขโมยแสงจากโคม · วิญญาณแสงโผล่มาให้เดินเก็บ (เติมโคม)
- **Vault Altar / Sugar Crown Trial:** แผ่นหินคำสาปบนพื้น 2 แบบใหม่ (Hungry Ghosts · Quake Lines)
- **Siege of the Hunger (Delve):** Sapper วิ่งเข้ามาระเบิดกองน้ำตาลในวง · ลังเสบียงตกลงในวง
- **Hunger Herald:** Herald ตีไม่ได้ ยิง **ลำแสงสีฟ้า-ม่วงเส้นเดียว** ใส่มอนให้เก่งขึ้น (มอนที่ถูกบัฟมีออร่าม่วง) · ลูกน้องพิเศษ 3 แบบ: ตัวฮีล · ตัวบัฟ · ตัวสิง

## ข้อห้าม
- ห้ามมีตัวหนังสือ ตัวเลข โลโก้ ลายน้ำ
- รูปปั้น Captain/General และ Shade/Sapper **ห้ามสว่างหรืออิ่มสีกว่าตัวผู้เล่น** (กฎ style guide) · รูปปั้นวาดโทนเกือบขาว เพราะโค้ดย้อมสี
- ลัง 5 แบบต้องแยกออกตั้งแต่ขนาด 60px ด้วยของข้างในและสีขอบ (ฟ้า / ทอง / ส้ม / ม่วง / เหลือง)
- เฟรมขนาดเท่ากัน เรียงซ้าย→ขวา บน→ล่าง ไม่มีช่องว่าง · loop ต้องต่อกันเนียน
- ไฟล์พื้นดำ (wisp, beam, aura) ห้ามมีเงาหรือพื้นอื่นนอกจาก #000
