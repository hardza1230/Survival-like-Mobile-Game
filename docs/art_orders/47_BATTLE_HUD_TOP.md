## ข้อห้าม
- ห้ามมีตัวหนังสือ ตัวเลข "Lv" "Wave" "x2" ในภาพ — โค้ดเขียนเองทั้งหมด
- แผงต้องอ่านง่ายบนพื้นด่านที่ลายเยอะ (ดิน/หิน/คริสตัลเรืองแสงในภาพอ้างอิง) → ทึบพอ ไม่โปร่งใสเกิน 15%
- ห้ามสูงเกินขนาดที่บอก (HUD ห้ามกินพื้นที่เล่นเพิ่ม) · ไม่ใส่ลายประดับหนัก ๆ กลางแผง
- กลางชิ้น 9-slice ต้องเรียบ ยืดแล้วไม่เบี้ยว · ระบุ `nineSlice` ทุกชิ้นใน A
- สีที่โค้ดย้อม (เนื้อหลอดภารกิจ, จุดเวฟเฟรมบอส) ให้วาดเป็นโทนขาว/ครีม

## โน้ตฝั่งโค้ด
- แพ็ก 50% WebP → `assets/art/hud/` · โหลดพร้อมด่าน (ใส่ใน `STAGE_SHEETS` ทุกด่านแบบ `PLAY_UI_KEYS`) ห้ามโหลดตอนบูต
- 9-slice ใช้ `TEMPLE_UI` + `tuPanel` (canvas-safe) · เฟรมใช้ `tuFrames` / `tuImg`
- `drawCombatHUDPanels`: แผงหัว → `hud_top_panel` (10,8,w−20,54), การ์ดภารกิจ → `hud_mission_card` (10,68,w−20,สูงตามแถว), แผ่นบอส → `hud_boss_plate`
- `drawBars`: หลอด EXP (bx 78, bw W−218, y pad+1, สูง 11) → frame/fill · `lvlTxt` วางบน `hud_level_badge`
- `killTxt` / `runSugarTxt` → `hud_counter_pill` + ไอคอน B (แทน "KOs"/🍬)
- `drawWavePips` → `hud_wave_pips` · `waveObjBg/waveObjBar` → `hud_mission_bar_*` (ย้อมสีเดิม) · `bossBgW/bossBar` → `hud_boss_bar_*`
- `speedBtn`/`pauseBtn`/`muteBtn` (วงกลม r16 ที่ cbY) → `hud_round_btn` เฟรม 1/2 (เร่ง >x1 = เฟรม 2) · กดค้าง = เฟรม 3 · `speedTxt` ยังเขียน x1–x4 · `hud_speed_ring` เฟรมตามระดับ · ปุ่มเร่งรองรับ x1/x2/x3/x4
- ทุกชิ้นยังมีของเดิม (กราฟิกโค้ด) เป็น fallback ถ้าไฟล์ไม่มา · ไม่เปลี่ยนตำแหน่งแตะ/ขนาด hit ของปุ่ม
