## ข้อห้าม
- ห้ามตัวหนังสือ/ตัวเลข/โลโก้ในภาพ
- ห้ามเปลี่ยนหน้า ผม สีตา สัดส่วน หรือท่า — เปลี่ยนแค่ชุด (ผู้เล่นต้องจำฮีโร่ได้ทันที)
- ห้ามชุดโป๊/เซ็กซี่ (ตัวละครเป็นเด็ก chibi) · ชุดว่ายน้ำของ Yuzu ให้เป็นชุดฤดูร้อนมิดชิด
- ในด่าน: ห้ามใช้แดงสด/ม่วงเรืองแสงเป็นสีหลัก (สีกระสุนศัตรู) · ห้ามชิ้นยื่นใหญ่ (ผ้าคลุมยาว ปีกกว้าง) ในชีตด่านเกินกรอบตัวเดิม เพราะบังมอน
- ห้ามเฟรม "สั่น" (boil): ลายชุดต้องอยู่ตำแหน่งเดียวกันทุกเฟรม ขยับตามท่าเท่านั้น
- ภาพต้นฉบับ ห้ามเลียนแบบชุดของเกม/อนิเมะเรื่องอื่น

## โน้ตฝั่งโค้ด
- ข้อมูลใหม่ `SKINS=[{id,hero,name,price,icon:['skin_icons69',i]}]` · ราคาเสนอ 1200 ด้าย/สกิน · ช่อง Wardrobe ใหม่ `skin` (แท็บแรก) แสดงเฉพาะสกินของฮีโร่ที่เลือก + ปุ่มสลับฮีโร่
- `Save.data.cos.skin[hero]=id` · ฟังก์ชันกลาง `heroTex(key)`: ถ้าฮีโร่ใส่สกินและมี `key+'__'+skin` ใช้ตัวนั้น ไม่งั้นใช้ key เดิม → ใช้ทุกจุดที่โหลด/สร้าง sprite ของ `char_*`, `card_*`, `roster_*`
- โหลดแบบ lazy: ชีตสกินโหลดตอนเริ่มด่านพร้อมชีตเดิมของฮีโร่ (stage class) เฉพาะสกินที่ใส่ · card/roster โหลดแบบ menu · ไอคอน/แบนเนอร์โหลดตอนเปิด Wardrobe
- ไม่มีภาพ = ใช้ภาพเดิม (fallback) · ฉากเล่าเรื่องไม่เรียก heroTex
- ของที่เลิกขาย: ปีก 5 / ฮาโล 3 / วงใต้เท้า 3 → ซ่อนจากร้าน · ใครเป็นเจ้าของแล้วคืนด้ายเต็มราคาอัตโนมัติครั้งเดียว · กลุ่ม G แทนภาพสัตว์เลี้ยงใน `lobbyCos` (คีย์ `cos_pet_*_hd`, ไม่ขยายเกิน 1 เท่า)
- pack script: `scripts/pack-skins69.py` (WebP, ชีตด่านคงขนาดเฟรม 128, card ลด 50% เป็น 384×512 ตามชุดเดิมถ้าเดิมถูกลด)
