## แนวคิด
แยกภาพพื้นหลังเดิมเป็น **ชั้น (layer)** + **ชิ้นส่วนตัวละครแบบหุ่นเชิด (puppet)** ให้โค้ดขยับด้วย tween (หายใจ / แกว่ง / ลอย) แทนการทำแอนิเมชันเต็มเฟรม เพราะ
1. ภาพเต็มจอหลายเฟรมกินหน่วยความจำมือถือมาก (ตอนบูตเหลือที่ว่างไม่ถึง ~15 MB)
2. ชิ้นส่วนแยกขยับได้ลื่น 60fps ทุกเครื่อง และปรับความแรงในโค้ดได้ภายหลัง
3. **ประกอบชั้นทั้งหมดกลับแล้วต้องได้ภาพเหมือนพื้นหลังเดิม** (ตำแหน่ง/ท่า/แสงเดียวกัน) — ผู้เล่นไม่รู้สึกว่าเปลี่ยนภาพ แค่ภาพ "มีชีวิต"

เสริมด้วย VFX flipbook เล็ก ๆ (ประกายไม้เท้า, แสงหน้าต่าง, ธงปลิว, กลีบดอก, แสงวิ่งบนโลโก้/ปุ่ม)

## กฎเหล็กของชุดนี้
1. **ห้ามมีตัวหนังสือในภาพ** (โลโก้ MOCHI MAYHEM ใช้ของเดิม)
2. ชั้นภาพ/ชิ้นส่วน = **PNG32 พื้นโปร่งใสจริง** · ขอบคม ไม่มี halo · **ส่วนที่ถูกชั้นหน้าบังต้องวาดต่อให้ครบ** (เช่น ปราสาทหลังตัวโมโม่ ผมใต้แขน) เพราะเวลาขยับจะเห็นช่องโหว่
3. VFX (หมวด C) = **พื้นดำสนิท #000** (โค้ดแปลง alpha จากความสว่าง)
4. ทุกชั้นใช้ **ผืนผ้าใบเดียวกัน 1080×1920** เป็นพิกัดอ้างอิง แต่ **ส่งไฟล์ตัดเฉพาะกรอบของชิ้นนั้น** (crop) แล้วระบุ `x, y` มุมซ้ายบนบนผืน 1080×1920 ใน MANIFEST
5. ชิ้นส่วนที่หมุน/แกว่ง ต้องระบุ **จุดหมุน (pivot)** เป็น px ในไฟล์ของชิ้นนั้น เช่น หัวไหล่ของแขน โคนเปีย
6. **งบหน่วยความจำ:** ไฟล์ใหม่ทั้งชุด (กว้าง×สูง×4 byte) รวมไม่เกิน **~40 MB ที่ขนาดส่ง** (โค้ดย่อเหลือ ~87% และถอดชั้น A1 แทนพื้นหลังเดิม) · ชิ้นใหญ่สุดคือ A1 · VFX ทุกตัวเฟรมเล็กตามตาราง
7. สไตล์/แสงเหมือนภาพเดิมทุกประการ: กลางคืนโทนม่วงชมพู · ไฟหน้าต่างทองอุ่น · ดวงจันทร์ · ประกายชมพู

## MANIFEST.json (ต่อไฟล์)
```json
{ "key": "hub_momo_arm", "file": "hub_momo_arm.png", "width": 420, "height": 760,
  "canvasX": 610, "canvasY": 40, "pivotX": 70, "pivotY": 690, "z": 9,
  "columns": 1, "rows": 1, "frameWidth": 420, "frameHeight": 760, "frameCount": 1,
  "background": "transparent", "loop": false, "sha256": "...", "bytes": 0 }
```
- `canvasX/canvasY` = มุมซ้ายบนของไฟล์บนผืน 1080×1920 · `pivotX/pivotY` = จุดหมุนในไฟล์ (ใส่ `null` ถ้าไม่หมุน) · `z` = ลำดับชั้น
- VFX ใส่ `"background": "#000000"` และ `anchorX/anchorY` บนผืน 1080×1920 ถ้ามีตำแหน่งตายตัว (C2 หัวไม้เท้า, C3 ยอดธง)
