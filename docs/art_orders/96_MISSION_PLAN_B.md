- ด่าน C2–C3 มี "วัตถุภารกิจรอง" วางในแมพ ผู้เล่นเดินไปเหยียบ = เริ่มภารกิจ (ตอนนี้เห็นเป็นอีโมจิ 27px) · แสดงจริงกว้าง **72px** วางบนพื้น

- Creeping Roots: ตัวเปิดคือดอกไม้เหี่ยวน่ากลัว → รากค่อย ๆ งอกออกมา

- ห้ามตัวหนังสือ ตัวเลข สัญลักษณ์ตัวอักษร ในทุกภาพ

- พื้นดำ #000 เฉพาะไฟล์ที่ระบุ (fx96_wisp_fly, fx96_pot_dust, fx96_vault_ring) · ที่เหลือ alpha จริง

## โน้ตฝั่งโค้ด
- A: `placeChapterSideObjects` (`src/24-game-missions.js`) เรียก `artSpr(def.key, x, y+22, 72)` · ใส่ key ใน `C2_SIDE_MISSIONS[].key` (`src/00-config.js`) · Shake Trees / Vault / Golem ใช้ภาพเดิม (`msn71_tree`, `ult_altar`, `gg_oven`) · ไม่มีภาพ = อีโมจิเดิม
- B: `fx96_wisp_fly` เล่นใน `v83MissionStart('cleanAir')` ก่อนหมอก (UI layer, `heroFx`/`spawnFxAnim` + มืดจอ) · `fx96_root_grow` เล่นตอนเริ่ม `creepingRoots` ที่ตำแหน่งดอก
- C: `fogShadeTick` ใช้ `e96_shade_walk` แทนการ tint ตัว `fast` (ยังใช้ hitbox เดิม)
- D: `g2Drop` / `g2OvenOpen` ใช้ `gp96_parts` เฟรม (tier-1)*5+kindIndex แทนอีโมจิ · panel/slot แทน graphics · ลำดับชนิดตาม `G2_KINDS`
- E: `fx96_pot_dust` แทนวงฝุ่นวาดด้วยโค้ดใน `startChapterSideEvent` · `fx96_vault_ring` แทนวงใน `ultCursePopup`
- โหลดแบบ lazy (stage) เท่านั้น ห้าม boot · เก็บภาพสำรอง/โค้ดเดิมเป็น fallback
