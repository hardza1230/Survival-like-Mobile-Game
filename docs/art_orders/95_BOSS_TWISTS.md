## ข้อห้าม
- ห้ามตัวหนังสือ ตัวเลขในภาพ
- เฟรมขนาดเท่ากัน เรียงซ้าย→ขวา บน→ล่าง · loop ต่อกันเนียน · พื้นดำ #000 สนิทในไฟล์ที่ระบุ
- ต้องอ่านง่ายท่ามกลางกระสุนบอส: เมล็ด/ผลไม้ต้องมีขอบเข้มชัด ห้ามกลืนกับพื้นด่าน C2 (เขียว) หรือ C3 (เทาเถ้า/แก้ว)
- ห้ามสว่างกว่าตัวฮีโร่ · ออร่าเงา E ห้ามบังตัว Elite จนมองไม่เห็น
- `tw95_dark_vignette` กลางจอต้องโปร่งใส ผู้เล่นต้องเห็นตัวเองกับบอส

## โน้ตฝั่งโค้ด
- โค้ดอยู่ที่ `bossTwistStart` / `bossTwistRun` / `bossTwistEnd` / `bossTwistShadows` (v8.2.83 · ค่าต่าง ๆ อยู่ที่ `BOSS_TWIST_*`)
- **A:** `T.kind==='roots'` ตอนนี้วาด `lineBetween` + `fillCircle` ทุกเฟรม → ใช้ `tw95_root_tile` (TileSprite หมุนตามมุม) + `tw95_root_tip` ที่ปลายราก
- **B:** `T.seeds` → เกิดใหม่เล่น `tw95_seed_drop` แล้ว `tw95_seed_idle` · เหยียบแตกเล่น `tw95_seed_pop` · ฟักเล่น `tw95_seed_hatch` · วงนับถอยหลังยังวาดด้วยโค้ด
- **C:** `spawnHazard` ของ fruit → วาง `tw95_fruit_fall` ตรงวงเตือน จบที่ `tw95_fruit_splat` ตอนระเบิด (เวลาและดาเมจคงเดิม)
- **D:** สี่เหลี่ยมดำ `fillAlpha .42` → `tw95_dark_vignette` · มอนใน `T.buffed` ใส่ `tw95_frenzy_aura` (ทำ pool จำกัด 20 ตัว)
- **E:** `bossTwistShadows` → `tw95_shadow_summon` ที่ตัวบอส + `tw95_shadow_aura` ตามตัว Elite
- **F:** `showBanner` ตอนเริ่มลูกเล่น → เพิ่มแถบ `tw95_chip` + ไอคอน ค้างไว้บนจอตลอด 15 วิ พร้อมเวลาที่เหลือ
- stage-lazy (ด่าน 6–15) ห้าม boot · เก็บภาพที่โค้ดวาดไว้เป็น fallback
- MANIFEST ต่อแถว: `key`, `file`, `bytes`, `sha256`, `width`, `height`, `frameWidth`, `frameHeight`, `frameCount`, `columns`, `loop`, `anchor`, `background` · `tw95_chip` ระบุ `nineSlice` [l,t,r,b]
