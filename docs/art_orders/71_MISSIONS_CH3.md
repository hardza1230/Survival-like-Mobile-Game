## ระบบในเกม (อ้างอิง)
- ภารกิจเกิดในสนามระหว่างสู้ (มอนเยอะ) → ของภารกิจต้อง **อ่านออกทันทีที่ขนาดบนจอ** และไม่กลืนกับพื้น

- ของที่ "ใช้งานแล้ว/ดับ" โค้ดทำให้จาง (alpha) เอง ไม่ต้องวาดแยก ยกเว้นที่ระบุ

## ข้อห้าม
- ห้ามตัวหนังสือ/ตัวเลข/สัญลักษณ์ UI ในภาพ
- ห้ามสีแดงสด/ม่วงเรืองแสงจัดเป็นสีหลัก (ซ้ำกับกระสุนศัตรู) ยกเว้นแท่น Overcharge ให้ชมพู-ม่วงอ่อน
- ของบนพื้น (rift, pads, shrines) ต้องโปร่งตรงกลางพอให้เห็นตัวละครที่ยืนบน
- ห้ามเงาทอดยาว (โค้ดวาดเงาเอง)

## โน้ตฝั่งโค้ด
- คีย์ทั้งหมด `msn71_*` → `scripts/pack-missions71.py` → `assets/art/missions71/*.webp` · โหลดแบบ stage-lazy (เฉพาะด่านที่มีภารกิจนั้น; F/G ทุกด่าน Ch2–3 ยกเว้น supply crate/captain ทุกด่าน)
- `sigSetup` (game.js): แทน `sigText`/วงกราฟิกด้วย sprite ตามชนิด · rift = scale ตาม `S.curR` · tree เฟรม 1 เมื่อ `t.done` · mirror เฟรม 1 เมื่อ `m.lit` · crystal blast เล่นตอน `S.blast` (ADD blend) · lantern → lantern_out เมื่อ `!L.alive`
- `missionArm` / `overchargeOffer`: วงกราฟิก + ✨/⚡ → sprite pad (เก็บวงกราฟิกไว้เป็นวงชาร์จ)
- `seasonShrineTick` / `seasonDropPetal` / `cleanAirBubbles` / `surviveSupply` (กล่องตก) / `spawnObjectiveElite` (captain → texture `msn71_stalker_captain`)
- ไม่มีภาพ = ใช้ของชั่วคราวเดิม (fallback)
