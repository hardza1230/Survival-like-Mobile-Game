# 12 · Biome: Spicy Depths (🌶️)

ตอนนี้ในเกมใช้ placeholder ที่วาดด้วยโค้ดอยู่ ถ้าใส่ไฟล์ด้วย key ตามตารางนี้ใน `ASSET_IMAGES` เกมจะใช้ภาพจริงแทนเองอัตโนมัติ

| key | ขนาด | รายละเอียด |
|---|---|---|
| `biome_spicy_floor` | 1024×1024 ทึบ ต่อกันได้ทุกด้าน (seamless) | หินภูเขาไฟสีแดงเข้ม มีรอยแตกลาวาส้มเรือง ๆ ใช้โทนเข้มเพื่อให้ตัวละครเด่น ห้ามมีจุดเด่นซ้ำที่ทำให้มองออกว่าปูภาพซ้ำ |
| `biome_spicy_vent` | 256×256 โปร่งใส มองจากด้านบน | ปล่องลาวาทรงพริก/หม้อ มีขอบหิน (ตอนนี้ใช้อีโมจิ 🌋) |
| `biome_spicy_ember` | 128×128 โปร่งใส | กองไฟเล็ก ๆ บนพื้น สำหรับรอยไฟที่มอน Ember ทิ้งไว้ |
