## กฎเหล็กของชุดนี้
1. **ห้ามมีตัวหนังสือหรือตัวเลขในภาพ** (ไม่มี "Paused", "Resume", "Normal", "415" ฯลฯ) — โค้ดเขียนเอง
2. ชิ้น UI = **PNG32 พื้นโปร่งใสจริง (alpha)** · ขอบคม ไม่มี halo · เงาตกไม่เกิน 12px
3. กรอบที่ยืดได้ = **9-slice**: มุมมีลายได้ · ขอบกลางและพื้นกลาง **เรียบ/ซ้ำได้** (ยืด 0.6–2.2 เท่าไม่เพี้ยน) · ระบุ `[left, top, right, bottom]` เป็น px ใน MANIFEST
4. สไตล์ตามภาพอ้างอิง: ม่วงเข้ม `#2a1830` / `#21172b` + ขอบทองอุ่น `#e8c27a` + ชมพูแคนดี้ `#ff7aa8` + มินต์ `#5fe3c0` · ขอบนูนมีแสงสะท้อน · ประกายดาวทองสี่แฉกที่ปลายแถบ · ลายเถาทองบางที่มุมแผง — **เข้าชุดกับใบ 21 (Temple) และใบ 23 (Level Up)**
5. วาดที่ **2× ของขนาดบนจอ** ตามตาราง (โค้ดย่อลง) · บนจอเป้าหมายกว้าง 412px (มือถือแนวตั้ง)
6. ทุกพื้นที่ที่มีข้อความต้อง **มืดเรียบ** ให้ข้อความขาว 9–14px อ่านได้
