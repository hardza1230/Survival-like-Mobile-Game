## รูปแบบนี้เรียกว่าอะไร
**Motion Comic** (ภาพการ์ตูนขยับ) หรือ **2D Cut-out Cutscene** — ไม่ใช่ภาพนิ่งภาพเดียว แต่แยก **ฉากหลัง / ตัวละคร / ของ / เอฟเฟกต์** เป็นชิ้น ๆ แล้วให้โค้ดขยับแต่ละชิ้น (เลื่อน ตก ซูม สั่น แสงวาบ ฉากตัด) เหมือนหุ่นกระดาษ แบบที่เกมมือถือหลายเกมใช้ในฉากเปิดเรื่อง

ตัวอย่างที่เจ้าของเล่า (ฉากตกลงไปเจอเมล็ด): โมจิสตรอว์เบอร์รี **ตกจากบนลงล่าง + เส้นความเร็วเป็นขีด ๆ** → **ตัดฉาก** → ภาพใกล้ตอนเจอเมล็ด เมล็ดเรืองแสง → **วาบขาว** → กลายร่างเป็นคน

## กติกาไฟล์ (ทุกฉาก)
- **ขนาดผืน:** 1080×1920 (แนวตั้ง) · โค้ดย่อเหลือ 50% ตอนแพ็ก
- **พื้นที่ข้อความ:** เว้น 28% ล่างของจอ (กล่องคำพูด Ruby) ให้ไม่มีสิ่งสำคัญ
- **ฉากหลังซ้อนกันได้ 3 ชั้น (parallax):** `far` (ไกล ขยับช้า) · `mid` · `fg` (ใกล้ ขยับเร็ว ของบังหน้า) · ฉากหลังทึบเฉพาะ `far` · `mid`/`fg` โปร่งใส · **กว้างกว่าจอ 15%** ให้เลื่อนกล้องได้
- **ตัวละคร/ของ:** แยกไฟล์ต่อท่า · ตัดชิดขอบ + เว้นขอบ 24px · ระบุจุดยึด (pivot) ใน MANIFEST เช่นเท้า หรือกลางตัว
- **เอฟเฟกต์ (FX):** sprite sheet แนวนอน เฟรมเท่ากัน · พื้นดำสนิท (ใช้ ADD) หรือโปร่งใสจริง — ระบุใน MANIFEST
- **ชื่อไฟล์:** `cs_<ฉาก>_<ชั้น>_<ชื่อ>.png` เช่น `cs_s01_far_nest.png`, `cs_s01_chr_mochi_fall.png`
- **ภาพกลางที่ใช้ซ้ำทุกฉาก** ขึ้นต้น `cs_pup_` (ตัวละคร) และ `cs_fx_` (เอฟเฟกต์) — วาดครั้งเดียว

## คำศัพท์การขยับ (ใช้ในตารางฉาก · โค้ดเป็นคนทำ ไม่ต้องวาดเป็นเฟรม)
| คำ | ความหมาย |
|---|---|
| **ตก** | ชิ้นเลื่อนจากบนลงล่างเร็ว + `cs_fx_speedlines` |
| **เด้ง** | ลงพื้นแล้วยุบ-ยืด (squash) |
| **ซูมเข้า / ถอย** | กล้องขยาย/ย่อช้า ๆ |
| **แพน** | กล้องเลื่อนข้าง ฉากหลัง 3 ชั้นเลื่อนต่างความเร็ว |
| **สั่น** | จอสั่นสั้น ๆ |
| **วาบ** | จอขาว/สีทอง 0.2 วิ ใช้ตอนตัดฉากหรือเปลี่ยนร่าง |
| **ตัด** | เปลี่ยนเป็นภาพใหม่ทันที (มักตามหลังวาบ) |
| **ลอย** | ขึ้นลงเบา ๆ วนไป |
| **เรือง** | แสงรอบชิ้นกะพริบช้า |
