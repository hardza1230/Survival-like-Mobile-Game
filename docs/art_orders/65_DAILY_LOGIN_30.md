## โน้ตฝั่งโค้ด
- โค้ดอยู่ที่ `loginPopup()` (game.js) · ตอนนี้ใช้ `login_panel` / `login_cell` / `login_stamp` / `login_glow` / `day_reward` จากใบ 51 (`MENU_ORDER_ART` · `assets/art/menu_orders/`) → เปลี่ยนเป็นคีย์ `l30_*` ชุดนี้ โดยเก็บของเดิมเป็นภาพสำรองถ้าโหลดไม่สำเร็จ
- แพ็กเป็น WebP ที่ `assets/art/login30/` (สคริปต์ `scripts/pack-login30.py` copy แบบ pack-*.py เดิม) · โหลดแบบ menu-lazy ตอนเปิดป๊อปอัป (`ensureGroup(k=>/^l30_/...)`) ห้าม boot
- ช่องวันใช้เฟรม 3 สำหรับวัน 7/14/21/28 (`LOGIN_CAL[j].k==='gold'`) · วันที่ 30 (`r.big`) ใช้ `l30_cell30`
- ไอคอน: sugar n<600 → 0 · sugar n≥600 → 1 · thread → 2 · cur → 3 · silver → 4 · gold → 5 · วันที่ 30 → `l30_reward30`
- ปุ่ม `l30_button` แทน graphics ปุ่มส้มเดิม · `l30_claim_burst` เล่นครั้งเดียวที่ช่องที่รับ
- `l30_ruby` วางมุมขวาบนป๊อปอัป ห้ามบังช่องวันแถวบน (ถ้าจอแคบ < 340 ให้ซ่อน)
- MANIFEST ต่อแถว: `key`, `file`, `bytes`, `sha256`, `width`, `height`, `frameWidth`, `frameHeight`, `frameCount`, `columns`, `loop`, `background`, `nineSlice` [l,t,r,b] (panel/button)
