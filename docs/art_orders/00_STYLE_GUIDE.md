# 00 — Style Guide (อ่านก่อนทุกชุด)

อ้างอิงหลัก: `docs/ART_BIBLE.md` (ละเอียด) · `docs/LORE.md` (โลก Mochitopia) · `docs/ART_MASTER_BRIEF.md`

## โลกและอารมณ์
- **Mochi Mayhem** = โลกขนมหวานน่ารัก (Mochitopia) ที่ถูก "ความหิว" กลืนกิน · ตัวเอกเป็นโมจิผลไม้/ขนม
- น่ารักแต่มีมิติ: เส้นนุ่ม สีพาสเทลอิ่ม แสงเรืองแบบเวทมนตร์ ศัตรูหน้าบึ้งตลก ๆ ไม่น่ากลัวจริงจัง
- **Chapter 1** ครัว/รังมด สว่างอบอุ่น · **Chapter 2** ป่าหมัก/เห็ด/รังผึ้ง/เรือนกระจกสี่ฤดู/บัลลังก์ราก เขียวอมฟ้า-ม่วง ลึกลับ · **Chapter 3** ดินแดนเมล็ดพันธุ์แรก ขี้เถ้า/สวนผลไม้กลวง/เรือนกระจกแก้วพัง/ห้องนิรภัยเมล็ด/บัลลังก์ — โทนหม่นกว่า มีแสงทอง-ม่วงของ "Crown Seed" · **Endgame** Midnight Kitchen ม่วงเข้ม+ทอง

## มุมมองและสัดส่วน (สำคัญต่อ gameplay)
- เกมมองจาก **บนลงล่างเฉียงเล็กน้อย (¾ top-down)** · ตัวละคร/ศัตรูวาดแบบเห็นหน้า ยืนบนพื้น
- **จุดยืน (ground line) = กึ่งกลางล่างของเฟรม** เว้นขอบล่าง ~8% · วัตถุอยู่กลางเฟรมเสมอ
- ต้องอ่านรูปทรงออกเมื่อย่อเหลือ ~40–70px บนมือถือ → silhouette ชัด คอนทราสต์สูง รายละเอียดเล็กน้อยไม่จำเป็น
- ตัวละครผู้เล่นโดดเด่นที่สุดบนจอ → **ศัตรู/ของตกแต่งห้ามสว่างหรืออิ่มสีเกินตัวเอก** · พื้นยิ่งต้องหม่นกว่า

## เส้นและสี
- เส้นขอบเข้ม (ไม่ใช่ดำสนิท — ใช้สีเข้มของโทนนั้น) หนาพอดีเมื่อย่อ · ไล่เฉดนุ่ม 2–3 ระดับ + ไฮไลต์วาวแบบขนม
- ไม่มีตัวหนังสือ/โลโก้/ลายน้ำ/ลายเซ็นในภาพ

## กฎเทคนิค (ทุกชุด)
| หัวข้อ | กฎ |
|---|---|
| ฟอร์แมต | PNG 32-bit (RGBA) · พื้นหลังทึบอนุญาต WEBP |
| โปร่งใส | alpha **จริง** — ห้ามพื้นหมากรุก/พื้นเทา/พื้นขาวฝังในภาพ · ขอบไม่มีฮาโลขาว |
| ขนาด | ตามตารางในใบสั่ง **เป๊ะ** (สี่เหลี่ยมจัตุรัสถ้าไม่ระบุ) |
| ชื่อไฟล์ | `<key>.png` ตัวพิมพ์เล็ก ตรงตาราง |
| Sprite sheet | เฟรมขนาดเท่ากัน เรียงซ้าย→ขวา บน→ล่าง ไม่มีเส้นคั่น ไม่มีช่องว่าง · ตัวอยู่ตำแหน่งเดียวกันทุกเฟรม |
| VFX | พื้นดำสนิท (#000) ถ้าเป็นเอฟเฟกต์แสง — ฝั่งโค้ดแปลง alpha เอง |
| เงา | เงานุ่มใต้วัตถุฝังในภาพได้ (ยกเว้นตัวละคร/ศัตรู — เกมวาดเงาเอง) |
