## ระบบในเกม (อ้างอิง)
- **Grandma's Golem** (C1-5 เตาอบมงกุฎ · โทนม่วงเข้ม-ส้มเตาไฟ): Elite "ผู้ถือรส" ถือชิ้นส่วนโกเลมคนละชิ้น → ฆ่าแล้วชิ้นส่วนตก เดินเก็บ → ยืนที่เตาอบของคุณยาย 2 วินาที = อบโกเลมขนมออกมาสู้ · ชิ้นส่วน 5 แบบ แต่ละชิ้นให้สกิล: 🍰 หัวเค้ก (ยิงแยม) · 🥨 แขนเพรทเซล (ทุบพื้น) · 🥖 ขาบาแก็ต (วิ่งเร็ว) · 🍭 หางอมยิ้ม (เรียกลูกน้อง) · 💗 หัวใจเยลลี่ (ฟื้นเลือด)
- **Siege of the Hunger** (ห้องพิเศษใน Delve · ฉากถ้ำ/ทุกโทน): วงทองให้ยืน 45 วินาที ประตู 5 บานรอบวงปล่อยมอนเป็นระลอก · อาจมี **Hunger Warlord** บุกเข้ามากลางทาง · ประตูใช้ภาพ `hh_gate` จากใบ 72 (ไม่ต้องวาดใหม่)
- **Memory Book** (หน้า Bestiary): ปลดขั้นมอน = ได้ 💭 Memory · ใช้ Memory อัป Codex ของมอนแต่ละตัว Lv 1–5 (ดาเมจใส่มอนตัวนั้นเพิ่ม) · ปุ่ม `📖 Codex Lv x → y · 💭n` ในหน้ารายละเอียด
- Lore: ชาวเมืองถูกสาปเป็นโมจิ ความทรงจำ = รสชาติ · คุณยายเป็นหัวหน้าครัวหลวงผู้เขียนตำรา Battle Recipes (โกเลมคือสูตรหนึ่งในตำรา)

## ข้อห้าม
- ห้ามตัวหนังสือ/ตัวเลข/สัญลักษณ์ UI ในภาพ
- ห้ามน่ากลัว/เลือด · โกเลมและ Warlord ต้องสไตล์มอนขนมน่ารักเดียวกับศัตรูเดิม
- ศัตรู (gg_golem, hs_warlord) ไม่ต้องมีเงาในภาพ · loop ทรงหลักคงที่ ขยับแค่รายละเอียด (ไม่ "เดือด" แบบใบ 34)
- ของบนพื้น (hs_circle) ต้องโปร่งตรงกลาง · ห้ามม่วงเรืองจ้าเป็นสีหลัก (ซ้ำกระสุนศัตรู)

## โน้ตฝั่งโค้ด
- pack: `scripts/pack-league73.py` → `assets/art/league73/*.webp` · A/B โหลด **stage-lazy** (C1-5 = gg_* · Delve ทุกชั้น = hs_*) · C โหลดกลุ่มเมนู `bestiary` (regex เดิม `^(skills|bestiary)$`)
- ไม่มีภาพ = ใช้ของชั่วคราวเดิม (fallback อีโมจิ/วงกราฟิก/ย้อมสีศัตรูเดิม) ทุกจุด
- Golem (`ggSetup`/`ggCarrier`/`ggDropPart`/`ggSpawnGolem`): `S.oven` 🔥 → `gg_oven` anim · ป้ายบนหัว Elite + ชิ้นที่ตก + รายการ `S.list` → `gg_parts` เฟรมตาม `GOLEM_PARTS` (head 0 · arms 1 · legs 2 · tail 3 · heart 4) · โกเลม (elite ย้อม 0xffc38a) → overlay/แทน texture ด้วย `gg_golem`
- Siege (`hsSetup`/`hsTick`): `S.ring` → `hs_circle` (เก็บวงกราฟิกเป็น fill จาง) · ประตู `G.t` 🌀 → `hh_gate` (ใบ 72) · Warlord (`e._hsWarlord`, ย้อม 0xff9b6a) → `hs_warlord`
