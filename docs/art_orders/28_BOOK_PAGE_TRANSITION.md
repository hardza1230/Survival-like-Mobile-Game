# 28 — Transition เปิดหนังสือ / พลิกหน้า · ใบสั่งงานอาร์ต

สถานะ: 🟥 รอผลิต (19 ต.ค. 2026 · runtime v7.9.7)
ส่งไฟล์ที่ `assets/incoming/book_transition/` พร้อม `MANIFEST.json`, `PROMPTS.json`, `QA_REPORT.json` (รูปแบบเดียวกับใบ 21–27)

## ภาพอ้างอิง
- `docs/art_orders/ref/27_equipment_ref.webp` และ `docs/art_orders/ref/27_forge_ref.webp` — หน้ากระดาษหนังเก่าในปกหนัง (ใบ 27) เป็น **หน้าหนังสือที่จะถูกพลิก**
- ทิศทางที่เจ้าของต้องการ: เมนูทั้งเกมรู้สึกเหมือน **สมุดบันทึกนักผจญภัย** — เปิดหน้าใหม่ = พลิกกระดาษ

## ตอนนี้เป็นยังไง (ใบ 26, `menuTransition`)
ม่านผ้าม่วง `tr_curtain` (tile) + ขอบประกาย `tr_edge` เลื่อนข้ามจอ + ตรา `tr_emblem` หมุนหด + ฝุ่น `vfx_tr_puff` · ใช้เวลา 340ms · โหลดตอนบูต · ไปข้างหน้า = เลื่อนจากขวา, ย้อนกลับ = กลับด้าน (flipX)

## สิ่งที่ต้องการ
1. **พลิกหน้า (ใช้ทุกครั้งที่สลับหน้าเมนู):** มุมขวาล่างของหน้ากระดาษยกขึ้นแล้วพลิกไปทางซ้าย เผยหน้าใหม่ด้านล่าง · ย้อนกลับ (Back) = พลิกจากซ้ายกลับมาขวา (โค้ด flipX ภาพเดียวกัน)
2. **เปิดปกหนังสือ (เฉพาะครั้งแรกตอนเข้าเมนูหลังโหลดเกม หรือกลับจากด่าน):** ปกหนังน้ำตาลเย็บด้ายพร้อมตราประจำเกมตรงกลาง เปิดออกไปทางซ้าย เผยหน้ากระดาษ

## กฎเหล็กของชุดนี้
1. **ห้ามมีตัวหนังสือ/โลโก้ตัวอักษรในภาพ** (ตราบนปกเป็นสัญลักษณ์ได้ เช่น โมจิ + ใบไม้ + ดาว)
2. เฟรมอนิเมชัน = **PNG32 โปร่งใสจริง** (พื้นที่นอกกระดาษต้องโปร่ง เพราะเห็นหน้าใหม่ข้างใต้) · เฟรมขนาดเท่ากันทุกเฟรม · เรียงซ้าย→ขวา บน→ล่าง
3. **งบหน่วยความจำ:** งบ GPU บูตเต็มแล้ว ชุดนี้จะ **โหลดหลังเข้าเมนู (lazy)** แล้วใช้ม่านเดิมของใบ 26 เป็นตัวสำรองจนกว่าจะโหลดเสร็จ · ขนาดรวมหลังแพ็ก WebP ไม่ควรเกิน ~1.5 MB / decode ไม่เกิน ~24 MB
4. สไตล์และสีเดียวกับใบ 27: กระดาษ `#f1e3c4` ลายเส้นใย · ขอบหนัง `#5a3826` เย็บด้าย · เงาตอนพลิกเป็นน้ำตาลอุ่นโปร่ง (ไม่ใช่ดำ)
5. อนิเมชันต้อง **อ่านรู้เรื่องที่ 6 เฟรม** (โค้ดเล่น ~300–380ms) และไม่บังหน้าจอนานเกินไป

## จังหวะที่โค้ดจะเล่น (ให้ศิลปินทำเฟรมให้รองรับ)
- **พลิกหน้า (ไปหน้าถัดไป):** 0ms สร้างหน้าใหม่ไว้ใต้ + ภาพหน้าเก่า (snapshot) ซ้อนบน → 0–60ms A3 fade in → 0–320ms เล่น A1 ①→⑥ + A2 ตามเฟรม (snapshot หน้าเก่าจางตามเฟรม ①–③) → 280ms A4 ที่สัน → 360ms ลบทุกชิ้น
- **ย้อนกลับ (Back):** ภาพชุดเดียวกัน `flipX` + สันย้ายไปขวา
- **เปิดปก:** B1 ทึบ 0–150ms + B3 เรือง → 150–550ms เล่น B2 ①→⑤ → หน้าเมนูโผล่ใต้ (ครั้งเดียวต่อการเปิดเกม / กลับจากด่าน · กดแตะเพื่อข้ามได้)
- เจ้าของตั้งค่าลดการเคลื่อนไหว (`prefers-reduced-motion` / ตัวเลือก VFX ต่ำ) → ใช้ fade 120ms แทน
