สถานะ: 🟥 รอผลิต (19 ต.ค. 2026 · runtime v7.9.7)
ส่งไฟล์ที่ `assets/incoming/journal_gear_ui/` พร้อม `MANIFEST.json`, `PROMPTS.json`, `QA_REPORT.json` (รูปแบบเดียวกับใบ 21–26)

## ภาพอ้างอิง (mood / layout เป้าหมายที่เจ้าของเลือก)
- `docs/art_orders/ref/27_equipment_ref.webp` — หน้า Equipment แบบสมุดกระดาษหนังเก่า
- `docs/art_orders/ref/27_forge_ref.webp` — หน้า Affix Forge ชุดเดียวกัน ("Enchanted Journal")

ภาพอ้างอิงเป็น **ภาพจำลองทั้งหน้า** ห้ามส่งแบบนั้นกลับมา เพราะเกมเขียนชื่อไอเทม ตัวเลข mod เลเวล และรายการกระเป๋าเองแบบสด
งานนี้คือการ **แยกเป็นชิ้นส่วน** (พื้นหน้ากระดาษ กรอบ ช่อง แถว ปุ่ม ชิป ไอคอน ลายประดับ) ให้โค้ดประกอบได้ทุกขนาดจอ
**ทั้งสองหน้าใช้ชิ้นชุดเดียวกันให้มากที่สุด** (ช่องไอเทม ปุ่ม แถว แผง) — ชิ้นเฉพาะหน้า Forge มีแค่หมวด F

## ตอนนี้หน้าตาเป็นยังไง (v7.9.7)
- **Equipment (`buildGear`)**: พื้นหลัง `screen_equipment` + แผงม่วงเข้มวาดด้วยโค้ด · แถบชื่อ + ATK/DEF · ช่องสวมใส่ 6 ช่องแถวเดียว · หัวกระเป๋า (ชื่อช่องที่กรอง ✕ · ปุ่ม Set · จำนวน · ♻ · ⚡) · กระเป๋า 5×2 + ปุ่มเปลี่ยนหน้า · การ์ดเทียบ 2 คอลัมน์ (EQUIPPED | THIS ITEM) หรือการ์ดเดี่ยว + ไอคอนกุญแจ · แผง MODS (บรรทัดเดียวต่อ mod + ดาวสี) · คำเตือนตีบวก · ปุ่ม Equip/Enhance + Craft/Salvage
- **Forge (`_buildCraftBenchRaw`)**: ใช้อาร์ต `fg_ui_*` ชุดม่วง (forgeChrome) · แถบช่องสวมใส่ 6 ช่อง · การ์ดสรุปไอเทม + Equip · แผง "Choose a mod" (implicit ล็อก + 3 แถว Power/Sustain/Utility) · รายการ mod ที่สุ่มได้ (แตะ = ✓ เป้าหมาย, % โอกาส, ดาว) + เปลี่ยนหน้า · ปุ่มหลัก Roll / Auto until ✓ (มีจำนวนสกุลเงินบนปุ่ม) + Tier +1

## กฎเหล็กของชุดนี้
1. **ห้ามมีตัวหนังสือหรือตัวเลขในภาพ** (ไม่มี "Equipment", "Roll", "Lv25", "19%" ฯลฯ) — โค้ดเขียนเอง
2. ชิ้น UI = **PNG32 พื้นโปร่งใสจริง (alpha)** ยกเว้นพื้นหน้ากระดาษ A1 ที่ทึบ · ขอบคม ไม่มี halo · เงาตกไม่เกิน 10px
3. กรอบที่ยืดได้ = **9-slice**: มุมมีลายได้ · ขอบกลางและพื้นกลาง **เรียบหรือซ้ำได้** (ยืด 0.6–2.4 เท่าไม่เพี้ยน) · ระบุ `[left, top, right, bottom]` เป็น px ใน MANIFEST
4. **สไตล์ตามภาพอ้างอิง**: กระดาษหนังเก่าสีครีม `#f1e3c4` / `#e6d2a8` ลายเส้นใยจาง ๆ · ขอบหนังน้ำตาลเข้ม `#5a3826` เย็บด้าย · ปุ่มหลักเขียวป่า `#2f5a3c` ขอบทอง `#c9a35a` · สีเน้นแดงไวน์ `#7a1f2b` (ช่องที่เลือก/แถวที่เลือก) · ใบไม้เถา ดอกไม้ขาว-ม่วงเล็กที่มุม · หมึกน้ำตาลเข้ม `#3b2416` สำหรับตัวหนังสือ
5. **ข้อความในเกมจะเป็นสีหมึกเข้มบนกระดาษสว่าง** (กลับจากเดิมที่เป็นตัวขาวบนม่วง) — ทุกพื้นที่วางข้อความต้องสว่างเรียบพอให้หมึก 11–14px อ่านง่าย ลายประดับห้ามวิ่งผ่านพื้นที่ข้อความ
6. วาดที่ **2× ของขนาดบนจอ** ตามตาราง (โค้ดย่อลง) · จอเป้าหมายกว้าง 360–412px แนวตั้ง · **ทั้งหน้าต้องพอดีจอไม่ต้องเลื่อน** (เจ้าของไม่ชอบหน้าที่ต้อง scroll)
7. สีเกรด/ดาวยังใช้ของเกมเดิม: ★1 ขาว/ครีม · ★2 เขียว · ★3 ฟ้า · ★4 ม่วง · ★5 ส้ม — ชิ้นที่ต้องมีสีเกรดให้ทำ **เป็นเทาขาว (tint-ready)** ให้โค้ดย้อมเอง ยกเว้นที่ระบุว่าทำหลายสี
