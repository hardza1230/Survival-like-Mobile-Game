## กฎเหล็กของชุดนี้
1. **ห้ามมีตัวหนังสือ ตัวเลข อีโมจิ หรือสัญลักษณ์ตัวอักษรในภาพ** (ไม่มี "LEVEL UP", "RELIC", "Lv", "Tap to choose", "✦") — โค้ดเขียนเอง
2. ชิ้น UI = **PNG32 พื้นโปร่งใสจริง (alpha)** · ขอบคม ไม่มี halo สีพื้น · เงาตกไม่เกิน 12px
3. VFX (หมวด E) = **พื้นดำสนิท #000** (โค้ดแปลง alpha จากความสว่าง เหมือนใบ 20/22)
4. กรอบที่ยืดได้ = **9-slice**: มุม 4 มุมมีลายได้ · **ขอบกลางและพื้นกลางต้องเรียบ/ซ้ำได้** · ระบุ `[left, top, right, bottom]` เป็น px ใน MANIFEST
5. การ์ดต้องยืดได้ **ทั้งแบบกว้าง** (มือถือแนวตั้ง: บนจอ ~384×150) **และแบบสูง** (แนวนอน: ~178×220) จากไฟล์เดียว → มุมต้องเล็กกว่าครึ่งของด้านสั้นสุด (บนจอ ≤ 40px)
6. **ชิ้นที่มีคำว่า "ย้อมสีได้" ให้วาดเป็นขาว-เทาอ่อน** (ไม่มีสีของตัวเอง) เพราะโค้ดย้อมด้วยสีประจำสกิล — การ์ดโจมตีมีสีเฉพาะสกิลอยู่แล้วหลายสิบสี ทำไฟล์แยกทุกสีไม่ไหว
7. สไตล์: ร้านขนมแฟนตาซีโทนเดียวกับหน้า Temple (ใบ 21) — ม่วงเข้ม `#21172b` / `#2a1830` + ขอบทองอุ่น `#e8c27a` + ไฮไลต์ครีม · นุ่ม มน น่ารัก · **พื้นกลางการ์ดต้องมืดเรียบ** ให้ข้อความขาว 9–16px อ่านได้
8. วาดที่ **2× ของขนาดบนจอ** ตามตาราง (โค้ดย่อลง)
