# Latest delivery: v8.3.11 — game.js split into src/ (23 parts)

- **Code now lives in `src/NN-*.js`** (map: `src/README.md`). `game.js` is generated by `scripts/build-game.mjs` (`npm run build:game`), which joins the parts in name order.
  - The split is byte-identical, so the game does not change.
  - Files 20–29 are slices of `class Game`.
- **Guards:**
  - `npm run check`, `ci-checks.sh` and the deploy-push hook fail when `game.js` ≠ `src/`.
  - `build:game` refuses to overwrite a directly edited `game.js` (`--force` to discard).
  - `build:www` checks sync first.
  - android/pages workflows also trigger on `src/**`.
- `bump-version.mjs` now edits `src/00-config.js` (GAME_VERSION) + `src/01-changelog.js` (CHANGELOG) and rebuilds.
- `game.js` stays committed, so all 260+ tests, pack scripts, compress-assets and asset scans read it unchanged.
- Docs: CLAUDE.md §3, wire-art + release skills, HANDOFF.
