# Latest delivery: v8.3.24 — C2–C3 side missions as map objects, Escort in C2-1, Shake Trees by touch
Owner plan 27 Nov, phase A slice 2. `C2_SIDE_MISSIONS` (`src/00-config.js`) lists the full missions that now live as walk-onto side objects in continuous C2–C3 runs: Escort the Wisp (`purge`, C2-1 only), Hunt and Hunger Crack (generic from C2-1), Clear the Fog (from C2-2), Creeping Roots (from C2-3), Shake the Hollow Trees (from C3-2). `c1SideDeck(i)` for i≥5 returns the stage's own mission first, then shuffled met ones (2 objects); the C1 light deck moved to `c1SideDeckC1`. Walking onto an object calls `stackStart(mission)` (the existing side-mission stack: own HUD line, full rewards); one at a time; in `_v83Run` the stack lasts the mission's full `MISSION_WAVE_DUR` and survives wave changes (pauses during the miniboss), ending only on boss/reward. Shake Trees: ring hidden, touching a tree shakes it (0.45 s) and `stTreeFoes` releases 3+stage/3 monsters either all at once ("Ambush!") or one every 0.35 s, plus the old loot/surprise. Creeping Roots monsters get ×1.6 HP and ×1.12 size in continuous runs. Tests: `c1-situations-8312` (C2 deck rules), `scamper-8228` (stack end rule).
