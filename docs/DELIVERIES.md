# Latest delivery: v8.3.28 — Fix: C2–C3 side missions really run; Fog shadow monsters
Bug found while finishing phase A: v8.3.24/8.3.26 started Escort the Wisp, Hunt, Hunger Crack, Clear the Fog and (Root Lure) Lure the Crown Root through the side-mission stack, but those are base objectives that only run as the main `waveObjective` (the stack only drives `SIG_MISSIONS`), so they showed a timer and did nothing. Now `chapterSideObjectStart` sends SIG missions to the stack and base ones to `v83MissionStart(type)` (`src/24-…`): `setupWaveObjective(w,{forceType,dur})` with `MISSION_WAVE_DUR`, tracked in `_v83Mission`. It survives wave changes (`clearWaveObjective(force)` skips it unless forced; the wave-end auto-complete/expire skip it), the wave timer keeps running in continuous runs (`_timed` includes `_v83Run`), `tickV83Mission` ends it at its own deadline ("slipped away") or when the boss arrives, completion pays Sugar + mission loot + mission reward via a `completeWaveObjective` branch, and situation HUD text yields to it. Root Lure uses the same path. Clear the Fog gets its own shadow monsters (`fogShadeTick`: 2 every 5 s, max 6, ×1.3 speed, dark tint). Tests: `c1-situations-8312` contracts.

# Previous delivery: v8.3.27 — Grandma’s Golem as a Metamorph-style system
Owner design 27 Nov + approved defaults. New run system `g2*` in `src/24-…` with constants in `src/00-config.js` (`G2_KINDS` acid/drain/chili/frost/oven from the five C1 bosses, tiers Common/Rare/Epic, `G2_DROP_MOB=.03`, `G2_SLOTS=3`, `G2_MAX_INV=12`, pickup radius 40, life 30 s). Whenever a continuous run has an oven side object (C1-5 own event `g2:true`; C2–C3 generic `C2_SIDE_MISSIONS` entry), kills drop parts as ground pickups (no magnet): mobs 3% Common random kind, minibosses 1 Rare random kind, bosses 2 Epic of the stage's boss kind. Parts persist in `Save.data.g2parts`. Walking into the oven opens a frozen-time popup (bag chips with counts, 3 slots, tap to add/remove, Bake / Later). Baking spends the parts and spawns a tank golem (HP ×(4+1.2·power), scale ×1.8, `gg_golem` art follow, label with kind icons): the most-used kind picks its minions (2 every 6 s, max 6: shooter/fast/dasher/tank/basic) and each kind adds a skill (acid 5-shot fan /3 s, drain pull 1.4 s /6 s, chili 3 fire pools /5 s, frost 10-shot ring with a gap /4 s, oven 130 px slam /5 s). Killing it pays Sugar (10+3·stage)·power and a Gear box at power ≥6 (Epic-leaning at ≥8). Phase A of the 27 Nov mission plan is complete. Test: `c1-situations-8312` contracts.
