# Latest delivery: v8.3.31 — Boss Rage off, single loading screen, no stage ambience, New Discovery fix
Owner 27 Nov. (1) Boss Rage removed everywhere: `BOSS_RAGE_ON=false` (`src/00-config.js`) keeps `bossRageInfo` at the Normal tier, so bosses no longer gain HP/damage/speed from stage kills (C1-1 boss stays 4,293 HP / 35 contact instead of ~5.2k–6.4k / 39–43); boss rewards use the Normal tier; the boss name and warning banner drop the rage label. (2) Bug: entering a stage showed the loading screen again after the card deal and reloaded stage art up to 3× in the menu. `codeGenericTex` replaces some VFX files (vfx_ring, vfx_glow, vfx_line, lvl_sparkle_sheet, …) with code-drawn canvases, which `realTex` counted as missing, so `battleArtReady` / `prepareStageEncounter` kept reloading them; `realTex` now treats `_codeTex` textures as ready (one loading screen, ~4 s faster in headless). (3) Stage and boss ambience loops removed (`STAGE_AMBIENT_ON=false`: `tickA23Audio` stops any loop, `a23StageKeys` no longer loads them). (4) Bug: after C1-2 the New Discovery popup popped and closed repeatedly — art loads rebuilt the Lobby on top of the open reveal; `buildMenuScreen` now waits while a reveal is on screen. Tests: `owner-8331`, `audio-a23-living-battlefield`.

# Previous delivery: v8.3.30 — C1 side missions: full league versions at half time and target
