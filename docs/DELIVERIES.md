# Latest delivery: v8.2.21 — ➕ Side missions stack on the main mission (phase B)

Owner 19 Nov approved phase B. From Chapter 2 (`STACK_FROM` 5), in a timed Story mission wave, `STACK_AT` 18 s in and with ≥`STACK_MIN_LEFT` 45 s left, there is a `STACK_CHANCE` 70% roll (once per wave) for one ➕ side mission. It is drawn from `STACK_POOL` (Seed Rift, Shake the Trees, Mirror Path, Last Light, Hunger Herald, Creeping Roots, Grandma's Golem, Grandma's Pot — all keep their state in `_sig`) and never shares a group with the main mission (`STACK_CAT`: zone / roam / hunt); a main mission in the global group (Frozen Pantry, Hunger's Mouth, Vault Altar, Trial, Siege, Domain, Season Storm) gets no side mission. **Context swap:** `stackRun` swaps `waveObjective` / `_sig` / `objNodeG` (its own graphics layer) to the side mission only while it sets up, ticks (`sigTick`) and hears kills (`sigOnKill` forwards each kill), then restores the main one; `completeWaveObjective` called inside the swap goes to `stackComplete` (full Sugar bonus + mission reward + league currency, the wave keeps going). Its own timer (`MISSION_WAVE_DUR`, capped to the wave), a small line under the main HUD (`➕ emoji name · x/y · Ns`); time up → ≥50% half Sugar, else missed; it also ends when the wave ends (`waveclear`). If the main mission finishes first, the wave waits for the side mission's time. Known limits: no arrow for the side mission yet; when the main mission's cleanup runs first it can clear shared monster flags (e.g. root lane walkers) and follow-art. Bots: missions s7/s10/s12, 0 errors. Tests: new mission-stack-8221; wave-timed-8220 updated.

# Previous delivery: v8.2.20 — ⏱️ Waves end by time (phase A), untouchable Herald that empowers monsters, louder Momo shot

Owner 19 Nov approved phase A (+ B next). **Timed waves (`WAVE_TIMED`):** in Story (not replay meter / Delve / tutorial) a mission wave now has its own timer — `waveTimedSetup` sets `waveDur` to `MISSION_WAVE_DUR[type]` (default 90 s; Frozen Pantry 100, Golem/Pot 120, Herald 60, Vault 150, Trial 200 …; time-goal missions `MISSION_TIMED_GOAL` get goal+25 s); `tickStage` counts down when `_waveTimed`. Finish early = full reward as before, then the wave wraps up in `WAVE_WRAP` 8 s (`completeWaveObjective` `_wrap`); timer runs out = `expireWaveObjective`: ≥`MISSION_HALF_AT` 50% done → half the Sugar bonus (no item), less → no mission reward (partial EXP). `storyCanSpawn` keeps ≥8 monsters on the field while a timed wave runs (`timedNeedsFoes`). Survive / mini / boss waves unchanged. **Hunger Herald rework (owner):** the Herald is no longer a monster — an untouchable sprite that orbits the player in view (`HH_ORBIT` 260, catches up if you outrun it; fixes "spawned in the far corner"); every `HH_BEAM_CD` 2.6/2 s it locks a single blue-purple beam on a monster within 560 px and after 0.55 s empowers it (`hhEmpower`: HP ×1.6, speed ×1.2, damage ×1.25, bigger, purple + pulsing ring). Gates stay open the whole mission (sealing removed). Special minions (`HH_MINIONS`, max 4, from the gates): 💚 Healer (heals monsters within 170 px 4%/s), 🎺 Booster (empowers a neighbour every 6 s), 👻 Possessor (runs into a monster and empowers it). Ends when time runs out (`o._timedGoal`, `hhFinish`): Sugar + 2–7 per empowered kill (`powKills`), ≥8 → Gear box. Arrow points at the nearest empowered monster / minion. **Feedback:** Momo shot (`sfx_strawberry_soft_shot`) +7 dB (limiter) and volume .34→.62; C1-1 ant shots smaller (`ANT_SHOT_C11` acid .8, shooter 1.0). Tests: new wave-timed-8220; sig-missions Herald block rewritten; audio-a12, vfx78, motion77, missions71-74, mission-template, owner-round822 updated.
