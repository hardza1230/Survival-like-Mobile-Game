# Previous delivery: v8.2.21 — ➕ Side missions stack on the main mission (phase B)

Owner 19 Nov approved phase B. From Chapter 2 (`STACK_FROM` 5), in a timed Story mission wave, `STACK_AT` 18 s in and with ≥`STACK_MIN_LEFT` 45 s left, there is a `STACK_CHANCE` 70% roll (once per wave) for one ➕ side mission. If the main mission finishes first, the wave waits for the side mission's time. Known limits: no arrow for the side mission yet; when the main mission's cleanup runs first it can clear shared monster flags (e.g. root lane walkers) and follow-art.
