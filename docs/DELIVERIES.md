# Latest delivery: v8.3.18 — APKs signed with one fixed key (install over the old app)
Owner: the Store APK 8.3.17 would not install over 8.3.16 ("package conflicts with an existing package"). Cause: `android.yml` cached `~/.android/debug.keystore`, but that path never existed on the runner (log: "Cache not found" on restore, "Path Validation Error … no cache is being saved" on save), so every build signed with a fresh random debug key. Fix: a fixed test key `android-signing/ci-debug.keystore` (debug-only, password `android`, not the Play upload key) is committed; `scripts/set-android-version.mjs` adds a `signingConfigs.debug` pointing at it to `android/app/build.gradle`, so both the live-update debug APK and the Store APK use the same key from now on. Removed the useless cache steps; the SHA-1 print now reads the fixed key (store job prints it too): `E8:36:41:F5:47:94:C7:64:E9:33:ED:15:C8:80:67:04:E2:92:73:1F` — native Google login needs this SHA-1 in the Android OAuth client. One-time: phones must uninstall the old APK once (save: log in to cloud first). Test: new `tests/apk-signing-8318.test.cjs`.
