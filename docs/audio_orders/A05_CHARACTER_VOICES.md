# A05 — เสียงพึมพำตัวละคร (Ruby · ฮีโร่ใน Lobby · บอสตอนพูด) · ใบสั่งเสียง

สถานะ: 🟡 รอเสียง · เขียน 25 ต.ค. 2026 · ส่งที่ `assets/incoming/audio_voices/`
กติการ่วมดู `A00_README.md` · SFX mono · **ไม่มีคำพูดจริง** — เป็นเสียงพึมพำ/อุทาน (แบบเกมน่ารักทั่วไปที่ตัวละครพูดเป็นเสียงบี๊บมีอารมณ์) เพื่อให้แปลภาษาได้และไม่ต้องอัดเสียงนักพากย์

## ตอนนี้เป็นยังไง (ตรวจจากโค้ด v8.0.33)
- Ruby คุยกับผู้เล่นบ่อยมาก (บทสอน, เคล็ดลับในด่าน, เรื่องเล่า) แต่ **เงียบ** หรือใช้ `Sfx.select`
- ฮีโร่ใน Lobby มีบอลลูนคำพูดเอง และแตะ/จิ้ม 5 ครั้งได้ → ได้แค่เสียงปุ่ม
- บอสพูด (`bossSay` ตอนเปิดฉาก/ระหว่างสู้/ตอนแพ้) **เงียบ**

## รายการเสียง
### A — Ruby (วิญญาณแยมทับทิม เสียงเด็กหญิงตัวจิ๋ว ใส ร่าเริง)
| key | ความยาว | เสียง |
|---|---|---|
| `vo_ruby_blip` | 4 ไฟล์ `_1…_4` 60–90 ms | พยางค์ไร้ความหมายสั้น ๆ ("มี", "ปุ", "รู", "บี") — โค้ดสุ่มเล่นตามตัวอักษรที่พิมพ์ |
| `vo_ruby_happy` | 400 ms | หัวเราะคิกคักสั้น |
| `vo_ruby_alert` | 350 ms | "เอ๊ะ!" ตกใจ (ไม่มีคำ) |
| `vo_ruby_sad` | 450 ms | ถอนหายใจเบา ๆ "อืออ" |
| `vo_ruby_cheer` | 500 ms | "เย้!" แบบไม่มีคำ กระโดดดีใจ |

### B — ฮีโร่ใน Lobby (5 ตัว × 3 = 15 ไฟล์ · **ไม่รวม Sesame** ที่ยังพัฒนาอยู่)
| ฮีโร่ | นิสัย / น้ำเสียง | `vo_<hero>_greet` (500 ms) | `vo_<hero>_tap` (250 ms) | `vo_<hero>_poke` (500 ms) |
|---|---|---|---|---|
| `momo` (Strawberry) | สดใส กล้าหาญ ซุ่มซ่ามนิด ๆ | ทักทายร่าเริง | "อึ๊บ" เด้ง | "อ๊ะ! พอแล้วว" งอน ๆ |
| `mint` | เย็นชา ใจดีข้างใน เสียงต่ำนุ่ม | "หืม" สั้นสุภาพ | ถอนหายใจเบา | "...จริงจังหน่อย" เสียงพึมพำเย็น ๆ |
| `cocoa` | หมีช็อกโกแลตบึกบึน เสียงทุ้มหัวเราะง่าย | "โฮ่!" ทักทายดัง | "ฮึ" เบ่ง | หัวเราะลั่นแล้วจาม |
| `taro` | สายฟ้า ไฮเปอร์ พูดเร็ว | "ซี้ด" ไฟฟ้า + ดีใจ | "ปริ๊บ" ช็อตเบา | พึมพำเร็วรัว + ช็อตไฟ |

### C — บอสตอนพูด (พึมพำตามบท 3 แบบ ใช้ทุกบอสในบทนั้น)
| key | ความยาว | เสียง |
|---|---|---|
| `vo_boss_c1_blip` | 3 ไฟล์ 80–120 ms | ครัว/รังมด: พึมพำขี้บ่น กรอบแกรบ ทุ้มกลาง |
| `vo_boss_c2_blip` | 3 ไฟล์ 80–120 ms | ป่าหมัก/เห็ด/ผึ้ง: พึมพำชื้น ๆ หึ่ง ๆ ทุ้มต่ำ |
| `vo_boss_c3_blip` | 3 ไฟล์ 90–140 ms | ไร่ร้าง/มงกุฎ: พึมพำโบราณ ก้อง ลึกลับ (ไม่สยอง) |
| `vo_boss_defeat` | 700 ms | ร้อง "อ๊ากก" การ์ตูนแบบยอมแพ้ ตลก ไม่เจ็บปวด |

## ข้อห้าม
- ห้ามคำพูดภาษาใดภาษาหนึ่งจริง (ต้องเป็นพยางค์ไร้ความหมาย) · ห้ามเลียนเสียงตัวละครจากเกม/การ์ตูนที่มีอยู่
- ห้ามเสียงเจ็บปวด/กรีดร้อง · เสียง blip ต้องสั้นมากและเบา (เล่นถี่ตามตัวอักษร)
- Ruby ต้องฟังเป็นตัวเดียวกันทุกไฟล์ (น้ำเสียงเดียวกัน)

## โน้ตฝั่งโค้ด
- `rubyNext`/`rubyTalk`/`showCoachIntro`/ฉากเรื่องที่ Ruby พูด → `vo_ruby_blip` สุ่มทุก 2–3 ตัวอักษรตอนพิมพ์ (≤ 8 ครั้ง/วินาที) + เสียงอารมณ์ตาม mood (`rubyReact`)
- `startLobbyVoice` → `vo_<hero>_greet` ตอนบอลลูนแรก · `lobbyHeroTap` → tap / 5 ครั้ง = poke
- `bossSay` ตอนพิมพ์ → `vo_boss_c<บท>_blip` · ประโยคตอนแพ้ (`bossLine(1)`) → `vo_boss_defeat`
- ทั้งหมดผ่านสไลเดอร์ SFX · มีปุ่มปิดเสียงพูดแยกใน Settings (แนะนำ เพราะบางคนไม่ชอบ)
