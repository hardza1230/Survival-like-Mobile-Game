# P2 — เลือดและแม่เหล็กที่มีความหมาย (v6.55.88)

ใช้กับ Story ทั้ง 15 ด่าน รวม replay โดยคงฝูง/โควต้า Swarm และ EXP ที่หาได้จริงจาก P1 การฆ่ามอนยากยังให้ EXP มากกว่า และการจบเควสไม่มีการเติมเลเวลขั้นต่ำ

| ระบบ | กติกา Story |
|---|---|
| หัวใจ | ฟื้น 18% max HP × โบนัสไอเทมฮีล สูงสุด 35% max HP และไม่เกิน HP ที่ขาด |
| แหล่งหัวใจ | Mini รับประกันเมื่อยังมีโควต้า/ช่อง; Elite 18%; ลัง 20%; มอนธรรมดาไม่ดรอป |
| จำกัดหัวใจ | ค้างสนามสูงสุด 2 ชิ้น ดรอปสูงสุด 4 ชิ้นต่อด่าน เว้น 25 วินาที; Mini ข้ามเวลาได้แต่ข้ามเพดานไม่ได้ |
| หัวใจเมื่อใช้ไม่ได้ | HP เต็ม/ไอเทมฮีลถูกปิด: คงไว้ ไม่เล่นเสียงหรือกระตุ้น recipe heal; ไม่สร้างหัวใจใหม่เมื่อไอเทมฮีลถูกปิด |
| แม่เหล็ก | ค้างสนามสูงสุด 1 ชิ้น ดรอปสูงสุด 3 ชิ้นต่อด่าน เว้น 35 วินาที รวมจากลังและการฆ่า |
| จากการสู้ | ต้องมีออร์บอย่างน้อย 6 เม็ด หรือ EXP บนพื้นรวม ≥20; kill สะสมแต้มธรรมดา 1/Elite 4/Mini 8 |
| โอกาสแม่เหล็ก | ธรรมดาเริ่มสุ่ม 2% เมื่อแต้ม ≥25; Elite 15% เมื่อแต้ม ≥10; แต้ม ≥70 รับประกันเมื่อมี EXP และเงื่อนไขช่อง/เวลา/โควต้าผ่าน |
| หลัง Mini | ไม่แจกแม่เหล็กแน่นอน เพราะ P1 รวบออร์บที่หาได้ก่อนเปลี่ยนเวฟอยู่แล้ว; แต้มสะสมยังเพิ่ม |
| ลัง | แม่เหล็กยังสุ่ม 7% แต่ใช้เพดานร่วม; EXP/อุปกรณ์/Sugar เดิม |
| การเก็บแม่เหล็ก | ดึงเฉพาะออร์บ EXP ที่มีอยู่ ไม่สร้าง EXP ไม่ฮีล ไม่ดูดไอเทมอื่น; ถ้าไม่มีออร์บคงแม่เหล็กไว้ |
| การฮีลจาก kill | lifesteal กับ lifeOnKill รวมกันได้ไม่เกิน 3% max HP ต่อช่วง 1 วินาทีของเวลาเล่น; lifeOnKill ยังเว้น 0.45s |

ช่วงเวลาคิดจากเวลา active gameplay (`elapsed`) จึงไม่หมดขณะหยุดเลือกการ์ด ไม่รีเซ็ตข้อจำกัดทุกเวฟ ไอเทมที่เหลือค้างไปเวฟถัดไป เข้า stage ใหม่ล้างสนามและรีเซ็ตจำนวน/เวลา/แต้ม การสร้างไอเทมล้มเหลวไม่หักโควต้าและไม่ล้างแต้มสะสม

ตรวจแหล่งฮีลแล้ว: การฟื้นจาก kill เคารพ noheal และ pact; Hungry Pact ระบุว่าปิด **ไอเทม** ฮีล จึงยังใช้ passive recovery ได้ โบนัส healEffect ใช้กับหัวใจและ lifeOnKill โดย lifesteal คงจำนวนเดิมก่อนเพดานร่วม การ regen เดิมมีเพดาน 3% max HP/s พร้อม noheal/Unique no-regen/pact; recipe kill-heal มีเพดานเฉพาะเดิม ไม่มีการเปลี่ยนสกิลฮีลของตัวละครหรือรางวัล Recovery/Crossroads ในรอบนี้

Recipe/Rift/Boss Rush/Endless/Tutorial ใช้ความถี่ดรอปเดิมและหัวใจเดิม 18%+6 การรักษาหัวใจไว้เมื่อ HP เต็มหรือฮีลไม่ได้เป็นการปรับร่วม ส่วนเพดานดรอป แม่เหล็ก และ passive kill-heal ใหม่เป็น Story เท่านั้น

## ตรวจสอบ

`tests/field-pickups.test.cjs` เรียกเมธอดจริง ตรวจ HP เต็ม/ห้ามฮีล/โบนัส/HP ที่ขาด, โควต้าและเวลาแชร์ทุกแหล่ง, mini exception, pool allocation failure/reuse, แม่เหล็กดึง earned EXP เท่านั้น, empty pickup, bad-luck protection, dense kills, stage reset wiring และการแยก special modes; เพิ่มใน `npm run check` แล้ว

`npm run check` และ `npm run build:www` ผ่าน การเล่นจริง/มือถือ/ความรู้สึก/สมดุลรอเจ้าของทดสอบ โดยเน้นด่าน 1–2 เดิม, ด่าน 3 มิ้น, Swarm ช่วงท้าย, Hunt C1-5 wave 4, หัวใจเก็บสำรองและแม่เหล็กช่วงเก็บออร์บลำบาก ค่าเพดานเป็นค่าเริ่มต้นสำหรับ feedback ไม่ใช่สมดุลที่พิสูจน์จากผู้เล่นแล้ว

P3 ภารกิจหลายขั้นและ kill-to-Elite, P4 build/card/boss และ P5 ขยายผลจากการเล่นยังรอ ไม่รวมใน P2
