# 🍡 ใบสั่งงานอาร์ต — โมจิ 3D (แทนสาวสตรอว์เบอร์รี)

> **สถานะ:** ใบสั่งงานสำหรับส่ง AI อาร์ต (ChatGPT) · ยังไม่แตะโค้ด — รออาร์ตกลับมาก่อน แล้ว Claude ค่อยตัด/เสียบเข้าเกม
> **สรุปการตัดสินใจของเจ้าของ:** เลิกใช้ตัวละครสาวสตรอว์เบอร์รี → เปลี่ยนเป็น **"โมจิก้อน" สวมชุด/ธีม** (mascot) · ลุค **3D render** (ปั้น 3D แล้วเรนเดอร์เป็นภาพ 2D เข้าเกม)

---

## 0. ทำไมต้อง "เรนเดอร์เป็น 2D"
เกมเป็น **Phaser 2D** เล่นไฟล์ 3D จริงในสนามไม่ได้ → ให้ ChatGPT **ปั้น/วาดให้ดูเป็น 3D (มีมิติ แสงเงานุ่ม glossy)** แล้ว **ส่งออกเป็น PNG พื้นโปร่งใส** เราเอาเข้าเกมเป็นสไปรต์ ตัวละครจะดู "3D มีมิติ" แต่เป็นภาพแบน (เหมือนเกมมือถือดัง ๆ หลายตัว) — **ทุกเฟรมต้องมุมกล้อง/สเกล/แสงเดียวกันเป๊ะ** ไม่งั้นเล่นแล้วจะกระตุก

---

## 1. คอนเซปต์ตัวละคร (Momo — ตัวเริ่มต้น)
- **แกนหลัก:** โมจิก้อนกลมนุ่ม (mochi blob) สีครีม–ชมพูพาสเทล ผิวเนียนวาว (glossy) แก้มอมชมพู ตากลมวาวแบบการ์ตูนน่ารัก
- **ธีม/ชุด (จุดขายใหม่):** โมจิ **สวมชุด/ท็อปปิ้งตามธีมสตรอว์เบอร์รี** — เช่น มีสตรอว์เบอร์รีลูกเล็กเป็นหมวก/ติดหัว + ผ้าคลุมหรือผ้ากันเปื้อนสีแดง–ขาวเล็ก ๆ (แต่ **ตัวยังเป็นก้อนโมจิชัดเจน** ไม่ใช่คนใส่ชุด)
- **บุคลิก:** ร่าเริง กวน ๆ นักสู้ตัวจิ๋วใจใหญ่
- **หัวใจสำคัญ:** มองแล้วรู้ทันทีว่า "นี่คือโมจิ" ไม่ใช่มนุษย์

> ตัวละครอื่นอีก 4 (Mint/Cocoa/Taro/Sesame) ใช้ใบสั่งงานเดียวกัน เปลี่ยนแค่ **สี + ธีมท็อปปิ้ง** (มิ้นต์=เขียวใบมิ้นต์, โกโก้=น้ำตาลช็อกโกแลต, ทาโร่=ม่วง, งาดำ=เทาเข้ม/งา) — ทำ Momo ให้ผ่านก่อน แล้วขยายที่เหลือ

## 2. สเปกเทคนิค (สำคัญห้ามพลาด — เกมหั่นตามนี้)

### 2.1 ชีตท่าทาง (Action Sheet) — ไฟล์หลัก
- **ชื่อไฟล์:** `char_momo_fighter_sheet.png` (คงชื่อเดิมเพื่อเสียบทับได้เลย)
- **พื้น:** โปร่งใส (transparent PNG) — **ไม่มีพื้นหลัง ไม่มีเงาพื้น ไม่มีกรอบ**
- **ขนาดเฟรม:** **128 × 128 px ต่อเฟรม เป๊ะ**
- **จำนวน/การเรียง:** **8 เฟรม เรียงเป็นแถวเดียวแนวนอน (8 คอลัมน์ × 1 แถว) = ภาพรวม 1024 × 128 px**
- **ลำดับเฟรม (ห้ามสลับ!):**

| ช่อง | ท่า | อธิบาย |
|---|---|---|
| 0 | **idle** | ยืนปกติ หน้าตายิ้มสดใส (ท่ามาตรฐาน) |
| 1 | **blink** | เหมือน idle แต่ **หลับตา/กะพริบ** |
| 2 | **squash** | ย่อตัวแบนลง (ตอนลงพื้น) กว้างขึ้น–เตี้ยลง |
| 3 | **stretch** | ยืดตัวสูงขึ้น (ตอนพุ่ง/กระโดด) ผอม–สูง |
| 4 | **cheer** | ดีใจ ยกมือ/เด้ง หน้าตาปลื้ม (ตอนผ่านเวฟ) |
| 5 | **hurt** | เจ็บ หน้าตกใจ/หลับตาแน่น (ตอนโดนตี) |
| 6 | **ko** | สลบ ตา×× ล้ม (ตอนตาย) |
| 7 | **cast** | ร่ายสกิล/อัลติ ยกมือเปล่งพลัง หน้าฮึด |

- **จุดกึ่งกลาง:** ทุกเฟรมให้ตัวละคร **อยู่กึ่งกลางเฟรม เท้า/ฐานอยู่แนวเดียวกันทุกช่อง** (ยืนบนเส้นเดียวกัน) และ **สเกลตัวเท่ากันทุกเฟรม** (ยกเว้น squash/stretch ที่ตั้งใจย่อ–ยืด) — สำคัญมาก ไม่งั้นตัวจะเด้งไปมาเวลาเล่น
- **หันหน้า:** หันเข้าหากล้อง/เฉียง 3/4 เล็กน้อย (มองเห็นหน้าเต็ม) — เกมจะ flip ซ้าย–ขวาเอง
- **เรนเดอร์ 2× (retina) ความละเอียดสูง** แสงนุ่มฟุ้ง มีไฮไลต์วาวบนตัว (glossy)

### 2.2 ชีตวิ่ง (Run Atlas) — ไฟล์รอง (ทำหลังชีตท่าทางผ่าน)
- **ชื่อไฟล์:** `char_momo_run_sheet.png`
- **พื้น:** โปร่งใส · **ขนาดเฟรม 128 × 128 px**
- **การเรียง:** **12 เฟรม = 4 คอลัมน์ × 3 แถว (512 × 384 px)** เป็นวงจรวิ่ง (run cycle) ต่อเนื่องลูปได้เนียน (เฟรมสุดท้ายต่อเฟรมแรกได้)
- ตัวโมจิเด้ง–ย่อตามจังหวะวิ่ง (มุมกล้อง/สเกล/แสงเดียวกับชีตท่าทาง)

---

## 3. กฎเหล็ก 3 ข้อ (ย้ำ ChatGPT ทุกครั้ง)
1. **พื้นโปร่งใส (transparent) เท่านั้น** — ห้ามพื้นสี ห้ามเงาพื้น ห้ามกรอบ/เส้นขอบช่อง
2. **เฟรมครบ + เรียงตามลำดับเป๊ะ** (8 ช่องแถวเดียว) — เฟรมว่าง/สลับ = ในเกมเพี้ยน
3. **ขนาด 128×128 ต่อเฟรม + ตัวอยู่กึ่งกลาง ฐานเท้าแนวเดียวกัน สเกลเท่ากันทุกเฟรม**

## 4. เทมเพลตข้อความส่ง ChatGPT (ก๊อปวางได้เลย)

```
คุณคือศิลปินเกมมือถือ ช่วยออกแบบตัวละครหลักของเกม survival-like ธีมขนมน่ารักชื่อ "Mochi Mayhem"

ตัวละคร: "Momo" — โมจิก้อนกลมนุ่ม (ไม่ใช่คน) ผิวครีม-ชมพูพาสเทลวาว (glossy) แก้มอมชมพู
ตากลมวาวการ์ตูน สวมธีมสตรอว์เบอร์รี (สตรอว์เบอร์รีลูกเล็กติดหัวเป็นหมวก + ผ้ากันเปื้อนแดง-ขาวเล็ก ๆ)
ยังต้องดูเป็น "ก้อนโมจิ" ชัดเจน บุคลิกร่าเริงกวน ๆ นักสู้ตัวจิ๋วใจใหญ่

สไตล์: เรนเดอร์ให้ดูเป็น 3D มีมิติ แสงเงานุ่ม ผิววาว (เหมือน 3D mascot ของเกมมือถือ)
แต่ส่งออกเป็นภาพ PNG พื้นโปร่งใส (จะเอาไปใช้เป็นสไปรต์ 2D)

ต้องการ: Action sheet 1 ไฟล์
- PNG พื้นโปร่งใสสนิท (ไม่มีพื้นหลัง ไม่มีเงาพื้น ไม่มีเส้นกรอบ)
- 8 เฟรม เรียงเป็นแถวเดียวแนวนอน (8 คอลัมน์ × 1 แถว) เฟรมละ 128×128 px ภาพรวม 1024×128 px
- ทุกเฟรม: ตัวอยู่กึ่งกลางเฟรม เท้า/ฐานอยู่แนวเดียวกัน สเกลเท่ากัน หันหน้าเข้ากล้อง (เฉียง 3/4 ได้)
- ลำดับเฟรม (ห้ามสลับ): [0]ยืนยิ้ม [1]กะพริบตา(หลับตา) [2]ย่อตัวแบน(squash) [3]ยืดตัวสูง(stretch)
  [4]ดีใจยกมือ(cheer) [5]เจ็บตกใจ(hurt) [6]สลบตากากบาทล้ม(ko) [7]ร่ายพลังยกมือ(cast)
- เรนเดอร์ 2× ความละเอียดสูง

ส่งกลับเป็น PNG พร้อมบอกขนาดจริงและจำนวนเฟรม
```

## 5. ขั้นตอนหลังได้ภาพ
1. เจ้าของอัปโหลดไฟล์ลง **`assets/incoming/characters/`** (ผ่าน GitHub มือถือ) แล้วบอก Claude "วางงานโมจิใหม่แล้ว"
2. Claude ตรวจ/ตัด/ปรับ alpha → เสียบทับ `assets/char_momo_fighter_sheet.png` (+ run sheet) → เทส → commit
3. โค้ดไม่ต้องแก้ (key `char_momo` + สเปก 128px/8เฟรมเดิม) — เสียบแล้วเล่นได้ทันที
