## 1. 🧃 Juice — feedback ให้ทุกการกระทำ "ฟินมือ" *(ทำก่อน คุ้มสุด)*
**ทำอะไร:** เติม feedback เล็ก ๆ ตอนตี/ตาย/โดน ให้รู้สึกกระทบจริง
- **ตัวเลขดาเมจเด้ง (damage number pop):** ทุกครั้งที่ `damage()` โดน → ลอยตัวเลขขึ้น + จางหาย · คริติคอลตัวใหญ่สีทอง (มี `popDmg` อยู่แล้วบางส่วน — ทำให้ครบทุก hit)
- **Hit-stop:** ตอนฆ่าตัวใหญ่/บอสโดนหนัก freeze เสี้ยววิ (ระวัง `setGameSpeed` กลับด้าน — ใช้ค่ามาก = freeze จริง ดูหมายเหตุใน CLAUDE.md)
- **ศัตรูกระเด็น (knockback) + แฟลชขาว** ตอนโดนตี (มี `e.knock` อยู่แล้ว — เพิ่มแฟลช `setTintFill(0xffffff)` 60ms)
- **Screen shake ตามน้ำหนัก:** ฆ่า elite/บอส = สั่นแรงกว่าฆ่าตัวเล็ก
**แก้ตรงไหน:** `damage()`, `killEnemy()`, `hurtPlayer()`, `cameras.main.shake()`
**แรง:** เล็ก (ครึ่งวัน) · **บอทเช็ค:** รันแล้วดู 0 error + FPS ไม่ตก (เพิ่ม metric FPS ในบอท)

## 2. ⚡ Power Spike — ทำ Awaken/Evolution ให้ "พีคจริง"
**ทำอะไร:** ตอนปลด Awaken หรือถึง milestone ให้เป็น "โมเมนต์" ที่ผู้เล่นจำได้
- ตอนรับการ์ด Awaken (`awk` ใน pickCardAt/apply) → จอสว่างวาบ + zoom กระแทกเบา ๆ + เสียงพิเศษ + แบนเนอร์ใหญ่ "⚡ AWAKENED!"
- นัดแรกหลัง Awaken ให้ยิงชุดใหญ่พิเศษ (visual burst) ให้เห็นความต่างทันที
- เพิ่ม "screen-clear moment": ทุก 5 เลเวล ปล่อย nova ฟรีเคลียร์จอ 1 ครั้ง (reward ความรู้สึกทรงพลัง)
**แก้ตรงไหน:** `pickCardAt` (สาขา awk), `castSkill` (aw branch), `awakenSpark()`
**แรง:** กลาง · **บอทเช็ค:** force skills ถึง awaken แล้วดูไม่มี error (มี probe.mjs เป็นต้นแบบ)

## 3. 🔢 ตัวเลขขึ้นถี่ — hook ผู้เล่นใน 30 วินาทีแรก
**ทำอะไร:** ช่วงต้นเกมต้องได้เลเวลอัพถี่ ๆ (เลือกการ์ดบ่อย = dopamine ถี่)
- เทียบจริง: ใน 30 วิแรกควรได้เลือกการ์ด **3-5 ครั้ง** · ถ้าน้อยกว่านั้นลด `xpNext` เริ่มต้น หรือเพิ่ม EXP ช่วงต้น
- ทำ EXP bar ให้ "เกือบเต็มแล้วน่าลุ้น" (glow ตอนใกล้เต็ม)
**แก้ตรงไหน:** `xpNext` เริ่มต้น (ปัจจุบัน 7 ×1.20+3) ใน startRun, `drawBars()`
**แรง:** เล็ก (จูนตัวเลข) · **บอทเช็ค:** บอทนับจำนวน levelup ใน 30 วิแรก (เพิ่ม counter) แล้วรายงาน

## 4. 🎰 รางวัลสุ่ม — เพิ่ม "จังหวะลุ้น" (variable reward = เสพติดสุด)
**ทำอะไร:** เปลี่ยนการเปิดหีบ/กล่องจาก "ได้เลย" เป็น "ลุ้นแล้วเผย"
- เปิดหีบ 🎁 → เอฟเฟกต์สั่น/หมุน 0.5 วิ → หยุด → เผยของ (rarity flash: ขาว/ฟ้า/ม่วง/ทอง ตามความหายาก)
- เพิ่ม "แจ็คพอต" หายาก (~2%) ที่ให้ของโคตรดี + เอฟเฟกต์พิเศษ (ทำให้ผู้เล่นกรี๊ด/อยากเปิดอีก)
- gacha (`gachaRoll`) เพิ่มอนิเมชันหมุนก่อนเผยผล
**แก้ตรงไหน:** `breakCrate()`, `openChest`/`_chestReward` flow, `gachaRoll`, `rollStageReward`
**แรง:** กลาง · **บอทเช็ค:** เปิดหีบซ้ำ ๆ ดูไม่ crash + rarity กระจายถูก

## 5. 🧪 Build Discovery — โชว์ให้ผู้เล่นรู้ว่าเพิ่งค้นพบอะไรเจ๋ง
**ทำอะไร:** ตอนปลดคอมโบ/synergy ให้ประกาศชัด ให้รู้สึกฉลาด
- ปลดคอมโบ (`checkCombos`) → แบนเนอร์ใหญ่ "ปลดล็อก: [ชื่อคอมโบ]!" + ไอคอน
- การ์ดเลเวลอัพ hint ว่า "ใบนี้ + สกิลที่มี = ปลดคอมโบ X" (ล่อให้เลือก)
- หน้าคัมภีร์โชว์คอมโบที่ยัง "ยังไม่เคยปลด" (collection incentive)
**แก้ตรงไหน:** `checkCombos()`, `drawReadableChoiceCard()`, `buildSkillArchive()`
**แรง:** กลาง · **บอทเช็ค:** ให้บอทถือสกิลคู่คอมโบแล้วดูแบนเนอร์ทำงาน

## 6. 😰→😌 Tension & Relief — ความตื่นเต้นตอนใกล้ตาย
**ทำอะไร:** ทำให้ช่วง HP ต่ำ "รู้สึก" อันตราย แล้วปลดปล่อยเมื่อรอด
- HP < 30% → ขอบจอเต้นแดง (vignette pulse) + เสียงหัวใจเต้น + BGM ตึงขึ้น
- เก็บ ❤️ ตอน HP ต่ำ → เอฟเฟกต์ฟื้นเด่น (แสงเขียว + เสียงโล่ง)
- "Last stand": โดนดาเมจที่จะตาย ครั้งแรกในด่าน รอดที่ HP 1 (1 ครั้ง/ด่าน) = ลุ้นสุด
**แก้ตรงไหน:** `hurtPlayer()`, `update()` (เช็ค HP%), `collectHeal()`, `Sfx.bgmIntense`
**แรง:** เล็ก-กลาง · **บอทเช็ค:** ปิด god-mode ให้บอทเจอ HP ต่ำ ดูไม่ error

## 7. 🌊 Spectacle — ความมันตาแบบอ่านออก
**ทำอะไร:** จอเต็มฝูง + เอฟเฟกต์ แต่ยังแยกออกว่าอะไรอันตราย
- เพิ่มความหนาแน่นฝูงช่วงพีค (มี maxLive เพดานแล้ว) แต่คุมให้ readable
- อันตราย (hazard/กระสุนบอส) ต้องสีตัดชัด + telegraph ชัด ไม่จมกับ VFX สกิลเรา
- "harvest moment": หลังเคลียร์ฝูงใหญ่ → ออร์บ EXP ทั้งจอบินเข้าตัวรวด (แม่เหล็ก) = ฟิน
**แก้ตรงไหน:** `setupSpawnRates()`, `spawnHazard()`/`foeShot()` สี, `collectOrb`/vacuum
**แรง:** กลาง · **บอทเช็ค:** FPS ตอนฝูงเยอะ (เพิ่ม FPS metric) + 0 error

## 8. 🔁 Meta Progression — ให้เห็น "ได้อะไรกลับไป" ทุกครั้ง
**ทำอะไร:** แม้แพ้ก็ต้องรู้สึกคืบหน้า
- หน้าสรุป (`showStageSummary`/หน้าตาย) โชว์ชัด: Sugar ที่ได้ + "พอซื้ออัพเกรด X ได้แล้ว!"
- Progress bar ไปยัง unlock ถัดไป (ตัวละคร/gear/rank) ให้เห็นว่าใกล้แล้ว
- แสดง "power rating เพิ่มขึ้นเท่าไหร่" หลังอัพเกรด
**แก้ตรงไหน:** `showStageSummary()`, `die()`, `buildUpgrade()`, `Save.power()`
**แรง:** กลาง · **บอทเช็ค:** จบด่าน/ตาย แล้วดูหน้าสรุปเรนเดอร์ถูก

# ➕ 4 ข้อใหม่ (เพิ่มตามที่ขอ)

## 9. 🎓 Onboarding & First-Run Wow — 60 วินาทีแรกต้อง "ว้าว"
**ทำอะไร:** ผู้เล่นใหม่ต้องรู้สึกเก่ง+เข้าใจเกมทันที ไม่งงและไม่ตายง่ายในรอบแรก
- **Tutorial แฝงในด่าน 1 เวฟแรก:** ป็อปอัปสั้น ๆ สอนจอยสติ๊ก/dash/อัลติ (แตะปิดได้) — ครั้งเดียว (เก็บ flag ใน Save)
- **รอบแรกการันตีพลัง:** ด่าน 1 ครั้งแรกให้ EXP เยอะ + การ์ดแรงหน่อย ให้ผู้เล่นรู้สึก "เทพ" (first-time user experience)
- **First kill / first levelup / first boss = เอฟเฟกต์ฉลองพิเศษ** (ครั้งเดียว จำได้)
**แก้ตรงไหน:** `startRun()` (เช็ค `Save.data.tutorialDone`), เพิ่ม overlay tutorial, `openLevelUp` (first-time)
**แรง:** กลาง · **บอทเช็ค:** รันด้วย Save เปล่า (localStorage clear) ดู tutorial โผล่ + ปิดได้ไม่ค้าง
**ทำไมสำคัญ:** ผู้เล่นตัดสินใจใน 1-2 นาทีแรกว่าจะเล่นต่อไหม — จุดนี้คือ retention สูงสุดสำหรับเกมมือถือ

## 10. 📅 "อีกรอบเดียว" Loop — ให้เหตุผลกลับมาเล่นทุกวัน
**ทำอะไร:** ระบบที่ทำให้ session สั้น + มีเหตุผลกลับมา (retention/DAU สำหรับ Play Store)
- **Daily reward:** เข้าเกมวันละครั้งได้ Sugar/gacha ticket (streak เพิ่มรางวัล — พลาดวันรีเซ็ต = FOMO)
- **Daily challenge:** ด่านสุ่มมี modifier พิเศษ + รางวัลพิเศษ (เล่นได้วันละครั้ง)
- **Run สั้นลงได้:** ให้ผู้เล่นเลือกความยาว/ความยากด่าน (quick run 3 นาที vs long run)
- **จบ run เร็ว → เห็น reward → อยากกดเริ่มใหม่ทันที** (ลด friction หน้าเมนู)
**แก้ตรงไหน:** `Save` (เพิ่ม lastDailyClaim/streak), `buildHub()` (ปุ่ม daily), หน้าเลือกด่าน
**แรง:** กลาง · **บอทเช็ค:** claim daily 2 ครั้งในวันเดียว (ครั้งที่ 2 ต้องกันได้) — mock วันที่
**ทำไมสำคัญ:** เกม survival-like ขายที่ "เล่นซ้ำ" — daily loop = คนกลับมา = โฆษณา/IAP มีคนเห็น

## 11. 🎵 Dynamic Audio — เสียง/เพลงที่ตอบสนองสถานการณ์
**ทำอะไร:** ยกระดับ BGM สังเคราะห์ให้ "มีชีวิต" ตามเกม (เสียงคือ dopamine ที่คนมองข้าม)
- **Layered music:** เพิ่ม layer เมื่อฝูงเยอะ/ใกล้บอส (เพิ่ม intensity ตามจำนวนศัตรู/HP บอส) — มี `bgmIntense` อยู่แล้ว ขยายเป็นหลายชั้น
- **Boss stinger:** ตอนบอสโผล่/ตาย มี motif เด่นเฉพาะ
- **Combo/kill-streak audio:** ฆ่าต่อเนื่องเร็ว → เสียง pitch สูงขึ้นเรื่อย ๆ (satisfying streak)
- **Rarity sound:** ของหายาก = เสียงต่างระดับ (ขาว→ทอง เสียงหรูขึ้น)
**แก้ตรงไหน:** `Sfx` object (startBgm/bgmIntense), `killEnemy` (streak counter), `rollStageReward`
**แรง:** กลาง · **บอทเช็ค:** เสียงเช็คด้วยหูไม่ได้ผ่านบอท แต่เช็คว่า Web Audio ไม่ throw error
**ทำไมสำคัญ:** เสียงตอบสนอง = สมองหลั่ง dopamine โดยไม่รู้ตัว · ต้นทุนต่ำ (สังเคราะห์เอง ไม่มีไฟล์)

## 12. ⚖️ Risk/Reward Agency — ให้ผู้เล่น "เลือกเสี่ยง" เพื่อรางวัล
**ทำอะไร:** เพิ่มการตัดสินใจที่มีน้ำหนัก (agency = ผู้เล่นรู้สึกเป็นเจ้าของ build)
- **การ์ดสาป (Cursed cards):** การ์ดเลเวลอัพบางใบ "แรงมากแต่มีข้อเสีย" (เช่น +ดาเมจ 50% แต่ -HP 20%) — เลือกเองว่าจะเสี่ยงไหม
- **ห้องท้าทาย (Elite challenge):** ประตูเสริมกลางด่าน "เข้าไปเจอศัตรูโหด แต่รางวัลดีเว่อร์" (เลือกข้ามได้)
- **Greed mechanic:** อยู่ในเวฟนานขึ้น = รางวัลดีขึ้น แต่เสี่ยงตายมากขึ้น (ล่อให้โลภ)
- **Sacrifice altar:** จ่าย HP/Sugar แลกพลังชั่วคราวในรอบ
**แก้ตรงไหน:** `rollUpgrades()` (เพิ่ม cursed pool), เพิ่ม optional room ใน stage flow, `rollStageReward`
**แรง:** กลาง-ใหญ่ · **บอทเช็ค:** force เลือกการ์ดสาปแล้วดู stat apply ถูก + ไม่ crash
**ทำไมสำคัญ:** การตัดสินใจเสี่ยง = ความตื่นเต้น + build หลากหลาย + คุยกันในคอมมูนิตี้ ("เธอกล้าหยิบใบสาปไหม")

## 🤖 หมายเหตุการเทส
- ทุกข้อ: รัน `npm run bot` ก่อน push (จับ crash/error) — แต่ **บอทไม่ตัดสินความสนุก** ต้องเล่นจริงจูน "ความรู้สึก"
- ควรเพิ่ม metric ในบอท: FPS เฉลี่ย, จำนวน levelup ใน 30 วิแรก, texture ของกระสุน (กันบั๊กแบบ sprinkle awaken)
- จูนตัวเลขบาลานซ์บนเครื่องจริงเสมอ — ค่าที่เขียนในนี้เป็นทิศทาง ไม่ใช่ค่าตายตัว
