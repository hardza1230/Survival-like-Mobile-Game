# 📥 assets/incoming — โฟลเดอร์รับงานอาร์ตดิบ

วางภาพที่ได้จาก AI อาร์ต (ChatGPT) ลงในโฟลเดอร์ย่อยตามประเภท แล้วบอก Claude มาตัด/ใส่โค้ด/เทสต่อ

| โฟลเดอร์ | ใส่อะไร |
|----------|---------|
| `characters/` | สไปรต์ชีต/run atlas/การ์ดตัวละคร (`char_*`, `card_*`) |
| `enemies/` | ศัตรูธรรมดา (`e_*`) |
| `bosses/` | บอสใหญ่ + มินิบอส (`boss*`, `mb*`) |
| `vfx/` | เอฟเฟกต์ flipbook พื้นดำ (`fx_*_sheet`) |
| `icons/` | ไอคอนสกิล/พร (`ic_*`) |
| `backgrounds/` | ฉากพื้นหลัง 5 โซน (`bg*`) |
| `items_props/` | ไอเทม/กระสุน/props (`chest`,`crate`,`vac`,`proj_*`,`p_*`) |
| `ui/` | กรอบการ์ด/พาเนล |
| `cutscenes/` | ภาพประกอบเนื้อเรื่อง |

**ขั้นตอน:** อัปโหลดไฟล์ (ตั้งชื่อตามสเปกใน `docs/ART_MASTER_BRIEF.md`) → บอก Claude "วางงาน X ในโฟลเดอร์ Y แล้ว" → Claude ตัดลง `assets/` ตัวจริง + wire เข้า `game.js` + เทสด้วยบอท + commit

> ไฟล์ในนี้เป็น "งานระหว่างทาง" — เมื่อ Claude ประมวลผลเข้า `assets/` แล้ว อาจลบทิ้งได้
