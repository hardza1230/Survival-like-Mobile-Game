# Source-art QA proofs

Six stage SVGs embed the EXACT runtime floor WebP bytes plus actual generated warning frames converted using the existing order22 max-channel alpha/unpremultiply pipeline. All four warning frames are shown at128px; Counter frames are44px. Pinnacle uses floor_c35. SVGs are self-contained; open/download in a browser that supports embedded WebP. These are source-art compositions, not game screenshots. Browser execution and phone readability/FPS have not been run in this offline environment.

Twelve seam PNGs repeat the first source frame three times, with no gutter. Exact edge-column differences are recorded per frame in QA_REPORT.json. These images reveal discontinuities that a matching pixel alone would not catch.
