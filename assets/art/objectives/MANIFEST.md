# Wave objective art · v6.0.13

Generated with built-in ImageGen as transparent candy fantasy cutouts; grouped by Wisp/Core/Nectar, four seasons, Cache/Courier, and Hunt/Root. Each asset is alpha cropped, scaled and centered for mobile readability.

| Key | Size | In-game use |
|---|---:|---|
| objective_wisp | 128×128 | Escort the Wisp sprite |
| objective_cursed_core | 128×128 | Escort purification target |
| objective_nectar_flower | 128×128 | Defend Nectar flower |
| objective_spring, objective_summer, objective_autumn, objective_winter | 64×64 each | Season sanctuary markers |
| objective_cache, objective_courier | 72×72 each | Optional event markers |
| objective_hunt_mark | 48×48 | Hunt target marker |
| objective_root_anchor | 128×128 | Sever Roots target |

Runtime keeps existing circle, text or atlas art as a fallback when a new image fails to load. The Clean Air and Capture objectives keep their animated rings because those show live area and progress.
