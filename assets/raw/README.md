# assets/raw — ที่วางไฟล์อาร์ตต้นฉบับ (ยังไม่ตัด)

โฟลเดอร์นี้ใช้รับไฟล์อาร์ตดิบจากเจ้าของ (อัตลาส/สไปรต์ชีต/กราฟิก AI)
ก่อนที่ AI จะตัดเฟรม/ตัดพื้น แล้วประมวลผลลง `assets/` ตัวจริง

## ทำไมต้องมีโฟลเดอร์นี้
บางครั้งรูปที่ส่งผ่านแชทเป็น "ภาพให้ดู" เฉยๆ ไฟล์จริงไม่ถึงเครื่อง AI
(โดยเฉพาะรูปใหญ่หลาย MB) → ตัดเฟรมไม่ได้
ทางที่ชัวร์คืออัปโหลดไฟล์เข้ามาที่นี่ผ่าน GitHub

## วิธีอัปโหลดบนมือถือ (GitHub เว็บ)
1. เปิด github.com บนเบราว์เซอร์มือถือ → เข้า repo `Survival-like-Mobile-Game`
2. กดเข้าโฟลเดอร์ `assets` → `raw`
3. กดปุ่ม **Add file** → **Upload files**
4. เลือกรูปอัตลาสจากเครื่อง (เลือกได้หลายไฟล์)
5. ตั้งชื่อ commit อะไรก็ได้ → **Commit changes** (ลง branch `claude/vampire-survival-mobile-game-yo9e8w`)
6. บอก AI ว่าอัปแล้ว — AI จะ `git pull` มาตัดเฟรมทำอนิเมชันต่อ
